# immutable_workstation2 — Флешка сисадмина на базе Ventoy

Репозиторий — **точное зеркало структуры и наполнения флешки сисадмина**.
Что лежит на флешке, то описано здесь; чего нет здесь, того не должно быть на флешке.

- Ветка работы: `arena/6bb077ac-immutable-workstation2`
- Актуальная версия Ventoy на момент создания: **v1.1.17**
- Язык документации: русский, имена файлов и каталогов — латиница без пробелов
- План работ: [PLAN.md](PLAN.md)
- Правила наполнения и формат заглушек: [CONVENTIONS.md](CONVENTIONS.md)

## 1. Физическая схема флешки

Носитель: внешний USB, 468.75 ГБ, модель `CUSUSD400`, S/N `201503310007F`, GPT.

| № | Раздел | Метка | ФС | Размер | Содержимое |
|---|--------|-------|----|--------|-----------|
| 0 | Ventoy | `Ventoy(...)` | exFAT | 340.72 ГБ | `ISO/` (образы), `ventoy/` (конфиг), `builds/` (станционные сборки), `backup/` |
| 1 | VTOYEFI | `VTOYEFI` | FAT16 | 32 МБ | EFI-загрузчики Ventoy. **Не изменять** |
| 2 | Tools | `Tools_SD400(...)` | NTFS | 128.00 ГБ | Утилиты, скрипты, модули, документация |

Раздел Ventoy создаётся утилитой `Ventoy2Disk` и **пересоздаётся** при обновлении
или переустановке Ventoy — поэтому всё ценное с него бэкапится. Раздел `Tools`
не затрагивается операциями с Ventoy и имеет NTFS, что даёт поддержку ACL и
больших файлов (VHDX, образы).

## 2. Отображение «флешка → репозиторий»

```
Флешка                          Репозиторий
────────────────────────────    ────────────────────────────────
[Раздел 0] VENTOY/              ventoy-partition/
  ├── ISO/                        ├── ISO/          (*.iso.md — заглушки)
  ├── ventoy/                     ├── ventoy/       (конфиг как есть, текстом)
  ├── builds/                      ├── builds/        (станционно-специфичное)
  ├── backup/                     ├── backup/       (дампы MBR/GPT как есть)
  └── <крупные файлы>             └── ...           (*.md-заглушки)

[Раздел 1] VTOYEFI/             не зеркалится (служебный, FAT16)

[Раздел 2] TOOLS/               tools/
  ├── <Группа>/<Подкатегория>/    ├── <Группа>/<Подкатегория>/
  │     └── <Утилита>/            │     └── <Утилита>/
  │           ├── README.md       │           ├── README.md
  │           └── prog.exe        │           └── prog.exe.md   ← заглушка

Исследовательская база            research/
```

**Правило заглушек:** бинарные и крупные файлы (`.iso`, `.exe`, `.msi`, `.7z`, `.vhd`,
`.wim`, `.img`, `.dat`) в git **не** попадают. Вместо `<имя>.<расширение>` создаётся
текстовый файл `<имя>.<расширение>.md` с URL источника, SHA256, размером, версией и
назначением. Скрипт `scripts/check-flash` сверяет фактическое содержимое флешки с
заглушками и манифестом.

## 3. Структура репозитория

```
.
├── README.md              Этот файл
├── PLAN.md                Поэтапный план наполнения (Этапы 1–10)
├── CONVENTIONS.md         Соглашения: именование, шаблоны README, правила git
├── manifest.csv           Единый реестр образов и утилит (машинально проверяемый)
├── .gitignore             Что не попадает в git
├── research/              Исследовательская база: запросы, паттерны, реестры
├── ventoy-partition/      Зеркало раздела 0 (VENTOY)
│   ├── ISO/               Заглушки образов по категориям
│   ├── ventoy/            ventoy.json, autoinstall/, persistence/, script/, theme/
│   ├── builds/             Станционно-специфичные сборки
│   └── backup/            Дампы первых секторов диска
├── tools/                 Зеркало раздела 2 (TOOLS)
│   ├── _templates/        Шаблоны README для утилиты / скрипта / модуля
│   └── <Группа>/<Подкатегория>/...
├── scripts/               Автоматизация: каждая задача в двух версиях (.ps1 + .sh)
│   └── csv-check.py       разбор manifest.csv с учётом кавычек
└── docs/                  Регламенты, чек-листы, заметки по эксплуатации
```

## 4. Быстрый старт

```bash
# Linux: проверить репозиторий на соответствие соглашениям
bash scripts/repo-validate.sh

# Создать каркас новой утилиты
bash scripts/new-tool.sh --group diagnostics --subgroup disk --name Victoria

# Создать заглушку под ISO
bash scripts/new-iso-stub.sh --group windows --file Win11_24H2_x64_RU.iso \
     --url https://... --sha256 <hash> --size 6442450944 --version 24H2
```

```powershell
# Windows: то же самое
powershell -ExecutionPolicy Bypass -File scripts\repo-validate.ps1
powershell -ExecutionPolicy Bypass -File scripts\new-tool.ps1 -Group diagnostics -Subgroup disk -Name Victoria
```
