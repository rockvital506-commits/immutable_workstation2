## Расхождение по лицензированию, записано 2026-10-16

Windows 11 IoT Enterprise LTSC 2024 **в розницу не продаётся**. Легальных пути
три: OEM-поставка с устройством, корпоративное лицензирование (KMS или MAK),
подписка CSP либо IoT-дистрибьютор — `tools/os/windows/activation/README.md`.

При коммерческом профиле это было рабочим допущением: система ставилась тому,
у кого лицензия есть. С 2026-10-16 профиль некоммерческий — домашняя
лаборатория, и ни одного из трёх путей, как правило, нет. Расхождение стало
прямым.

**Решение владельца от 2026-10-16: билд оставить как есть, расхождение
записать.** Основание — технические преимущества редакции, которые не зависят
от канала лицензирования:

| Факт | Значение |
|---|---|
| Поддержка до 09.10.2029, IoT LTSC — до 10.10.2034 | Единственный образ Windows во всём наборе с живой поддержкой |
| Требования по уровню Optional: 2 ГБ, 16 ГБ HDD, BIOS, TPM не нужен | Ставится на «зоопарк» железа без обхода `LabConfig` |
| Win11 Pro 24H2 | Поддержка **истекла 13.10.2026**, ESU для Home/Pro не существует |
| Win10 Pro 22H2 | Поддержка истекла 14.10.2025 |
| Win10 IoT Enterprise LTSC 2021 | Тоже не продаётся в розницу и только до 12.01.2027 |
| Linux Mint 22.3 Cinnamon | Лицензионных препятствий нет, поддержка до 04.2029 |

То есть переход на любой другой Windows-образ ухудшает положение: либо
поддержка уже истекла, либо розничный канал недоступен так же.

**Что это значит практически.** Алгоритм, файлы ответа, GPO и скрипты в этом
билде остаются рабочими и описывают установку корректно. Не решён только
вопрос права на установку — он вынесен за рамки репозитория и остаётся на
владельце. Шаг 12 алгоритма описывает ввод ключа и не утверждает, что ключ
имеется.

По `research/18-os-choice-criteria.md` выбор образа — факты, а не предписание;
факты приведены выше, решение принято владельцем.

## Цель

Полная миграция: чистая, оптимизированная, защищённая от восстановления мусора
и от избыточного износа накопителя система.

## Аппаратные особенности, влияющие на алгоритм

| Особенность | Следствие |
|-------------|-----------|
| RAM 8 ГБ распаяна | Pagefile **не отключать**; фиксированный размер 2048–4096 МБ |
| SSD 256 ГБ | Держать 10–15% свободными; `powercfg /hibernate off`; TRIM проверить |
| Intel 12-го поколения | Возможна невидимость NVMe в установщике: нужен драйвер **Intel IRST/VMD** либо отключение VMD в BIOS |
| Встроенная графика | Драйвер Intel Graphics обязателен для корректного разрешения и яркости |
| Wi-Fi 6 AX211 | Драйвер сети **до** любых онлайн-шагов; иначе алгоритм встанет |
| Bluetooth (Realtek, USB) | Отдельный драйвер, не входит в пакет Wi-Fi |

## Подтверждённый состав драйверов

| Компонент | Hardware ID | INF |
|-----------|-------------|-----|
| Intel Wi-Fi 6E AX211 | `PCI\VEN_8086&DEV_51F0` | `netwtw08.inf` / `netwtw6e.inf` |
| Realtek Bluetooth | `USB\VID_0BDA&PID_D723` | `rtkfilter.inf` |
| Realtek Audio (SmartSST) | `INTELAUDIO\FUNC_01&VEN_10EC&DEV_0256` | `hdxsstmsi.inf` |
| Intel DTT / IPF | `PCI\VEN_8086&DEV_461D` | `ipf_cpu.inf` |
| Intel GNA | `PCI\VEN_8086&DEV_464F` | `gna.inf` |
| Intel Chipset (Alder Lake) | `PCI\VEN_8086&DEV_4601` | `alderlakesystem.inf` |
| Intel IRST / VMD | — | **критично для установщика** |

Первичный источник — экспорт из текущей рабочей ОС:
`DISM /Online /Export-Driver /Destination:<флешка>\builds\MSI_B12M-211RU_Win11_LTSC_IoT_24H2\drivers\export`
