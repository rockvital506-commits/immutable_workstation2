# ventoy/ — каталог конфигурации Ventoy

Каталог **обязан** находиться в корне первого раздела рядом с ISO и не иметь
подкаталога-посредника: `ventoy.json` лежит строго как `/ventoy/ventoy.json`.
Имена каталогов и файлов чувствительны к регистру. Кодировка `ventoy.json` — UTF-8.

## Состав

| Путь | Назначение | Этап |
|------|-----------|------|
| `ventoy.json` | Единый конфиг всех плагинов Ventoy | 1 ✅ |
| `autoinstall/` | Шаблоны автоустановки: `autounattend.xml`, kickstart, preseed | 6 |
| `persistence/` | `persistence.dat` (заглушка) + `image_conf.json` | 6 |
| `script/` | Пользовательские grub2-скрипты (plugin menu extension) | 6 |
| `theme/` | Тема оформления загрузочного меню (`theme.txt` + шрифты `.pf2`) | 2 |

## Что настроено в `ventoy.json` сейчас

| Опция | Значение | Почему |
|-------|----------|--------|
| `VTOY_MENU_LANGUAGE` | `ru_RU` | Русское меню; клавиша `L` в меню меняет язык |
| `VTOY_DEFAULT_MENU_MODE` | `1` | TreeView — видно структуру каталогов ISO |
| `VTOY_TREE_VIEW_MENU_STYLE` | `1` | Без префикса каталога и размера — меню компактнее |
| `VTOY_FILT_DOT_UNDERSCORE_FILE` | `1` | Скрывает мусор `._*` после копирования через macOS |
| `VTOY_DEFAULT_SEARCH_ROOT` | `/ISO` | Ищем образы только в `/ISO` — иначе Ventoy сканирует весь диск, включая `backup/` |
| `VTOY_MENU_TIMEOUT` | `0` | Автозагрузки нет: на чужом железе лишняя секунда стоит переустановки |
| `VTOY_SECONDARY_BOOT_MENU` | `1` | Вторичное меню (normal / wimboot / memdisk / grub2) включено |
| `VTOY_SECONDARY_TIMEOUT` | `15` | Через 15 с автоматически выбирается normal mode |
| `VTOY_WIN11_BYPASS_CHECK` | `1` | Обход TPM/RAM/SecureBoot/CPU при установке Windows 11 |
| `VTOY_WIN11_BYPASS_NRO` | `1` | Обход требования онлайн-учётки Microsoft (нужен отключённый сетевой кабель) |
| `VTOY_WIN_UEFI_RES_LOCK` | `3` | Разрешение UEFI не ниже 1024×768 — иначе WinPE рисуется обрезанным |
| `VTOY_SECURE_BOOT_POLICY` | `0` | Обход проверки Secure Boot; если на целевых машинах SB включён и нужен MOK — см. открытый вопрос №3 в `PLAN.md` |

`menu_alias` задаёт человекочитаемые названия категорий в загрузочном меню.
Каталоги перечислены по плану Этапа 2; пока образов нет, пункты просто пусты.

## Проверка конфига

1. В меню Ventoy нажать **F5 → Tools menu → Check plugin json configuration (ventoy.json)**.
   Ventoy покажет, какие блоки распознаны, а какие — нет.
2. Альтернатива — GUI-конфигуратор **VentoyPlugson** (идёт в архиве Ventoy):
   `VentoyPlugson.exe` (Windows) или `VentoyPlugson.sh` (Linux) → откроется веб-интерфейс.
3. Синтаксическая проверка JSON локально:
   `python3 -m json.tool ventoy-partition/ventoy/ventoy.json`

## Ограничения парсера Ventoy (важно)

- Комментарии в JSON **не поддерживаются** — не добавлять `//` и `/* */`.
- Парсер простой: не строить глубоко вложенные структуры.
- Блок `control` — это **массив объектов с одним ключом**, а не объект. Ошибка
  `{ "control": { "VTOY_MENU_TIMEOUT": "10" } }` ломает весь конфиг молча.
- Значения в `control` — **строки в кавычках**, даже числовые: `"10"`, а не `10`.

## Резервное копирование

Каталог `ventoy/` целиком текстовый (кроме темы) и полностью воспроизводится из
этого репозитория. Единственный нетекстовый файл — шрифты `.pf2` и картинки темы:
они хранятся заглушками и скачиваются из архива темы.
