## Версия и источник

| Поле | Значение |
|------|----------|
| Версия | 22.3 «Zena», выпуск 2026-01-13, на базе Ubuntu 24.04 |
| Поддержка | до 04/2029 |
| Официальный сайт | https://linuxmint.com/ |
| Зеркало загрузки | https://mirrors.edge.kernel.org/linuxmint/stable/22.3/ |
| SHA256 | `a081ab20…9bd4` — ожидаемая, источник ниже |
| Размер | 0 байт — не заполнен, причина ниже |

**Откуда ожидаемая сумма.** Зеркало публикует `sha256sum.txt` рядом с образами,
и именно оно указано источником. Сверить значение с ним из рабочей среды
нельзя: запрос к `mirrors.edge.kernel.org` 2026-10-16 вернул `000`
(`SSL_ERROR_SYSCALL`) — и на каталог выпуска, и на `sha256sum.txt`. Поэтому
проверено иначе: сторонний каталог `MuNeNiCK/os-iso-catalog`
(`docs/v1/amd64.json`, запись `mint-22.3-cinnamon`), прочитанный через
`api.github.com`, несёт то же значение суммы и тот же URL файла. Это
подтверждение, а не установление происхождения: каталог сторонний, значение в
манифест появилось раньше. Перед записью образа сумму сверить с
`sha256sum.txt` на зеркале.

**Почему строка остаётся `planned`.** Сумма известна, а размер — нет:
`mirrors.edge.kernel.org` вне белого списка рабочей среды, а каталог
`os-iso-catalog` поля размера не содержит вовсе. Заполнять `size_bytes` числом
без источника §4 запрещает, поэтому строка остаётся `planned` с этой причиной.
Размер появится после скачивания образа — вместе со сверкой суммы.
