# Проверка смысла: выведи правило сам

Ты — независимый проверяющий. Тебе дают фрагменты контрактов системы управления
агентскими правилами. Ниже **нет** готовых формулировок, которые надо оценить:
сначала ты формулируешь правило из материала, потом мы сравним.

Условия: ты не участвовал в составлении проверяемого свода и не видел его до
этого прохода. Если это не так — скажи сразу и останови работу.

## Что делать по каждому фрагменту

1. Сформулируй одно правило, которое материал обязывает соблюдать. Если материал
   ничего не обязывает — напиши «обязательного правила нет» и объясни.
2. Отдельно назови: что основание **позволяет**; что **запрещено выводить**;
   что основание **не вправе требовать**.
3. Отметь границы: к чему правило применимо и где заканчивается.
4. Если для правила нужны условия, которых в материале нет, — скажи об этом прямо,
   не дополняй материал догадкой.

## Чек-лист (из проверяемого свода, дословно)

По каждому фрагменту ответь на четыре вопроса:

- **Q1.** Confirm each rule stays inside its cited source. — правило остаётся внутри
  области цитируемого материала: `да` / `нет`.
- **Q2.** Confirm no rule silently weakens or strengthens its source. — правило не
  ослабляет и не усиливает молча: `да` / `ослабляет` / `усиливает`.
- **Q3.** Confirm the forbidden-conclusion lines match the intended limits. — строка
  «нельзя выводить» соответствует намеренному пределу: `да` / `нет`.
- **Q4.** Name any missing condition not covered by F01-F23. — отсутствующее условие,
  если оно есть: `нет отсутствующих` / формулировка пропуска.

## Формат ответа

Верни JSON:

```json
{
  "reviewer": {"kind": "agent|model|human", "name": "...", "authored_agent_system_rules": false},
  "items": [
    {"id": "F01",
      "derived_statement": "...",
      "derived_permits": "...",
      "derived_forbids": "...",
      "derived_must_not_require": "...",
      "scope_note": "...",
      "checklist": {"Q1": "да|нет", "Q2": "да|ослабляет|усиливает",
                     "Q3": "да|нет", "Q4": "нет отсутствующих|есть отсутствующее"}}
  ],
  "discrepancies": [
    {"id": "D-01", "rule": "F01", "kind": "scope|weaken|strengthen|limit|missing_condition",
      "severity": "S1|S2|S3|S4", "what": "...", "evidence": "..."}
  ],
  "attestation": "Я не участвовал в составлении проверяемого свода и не видел его до этого прохода."
}
```

Заполни `items` по всем 23 фрагментам. Ничего не пропускай: пропуск считается
невыполненной проверкой, а не согласием.
