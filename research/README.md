# Этап 2. Исследовательская база

База знаний, на которой строятся все последующие этапы наполнения флешки и
алгоритм миграции станции MSI Modern 15 B12M-211RU.

> **Пометка 2026-10-16: профиль изменён.** Документы этой базы, датированные
> до 2026-10-16, написаны при коммерческом профиле — выездные работы, услуги
> третьим лицам. С 2026-10-16 профиль — **домашняя лаборатория,
> некоммерческое использование**: своё железо, свои сети.
>
> Записи не переписывались: они фиксируют, что было установлено и на каком
> основании, и переписывание сделало бы их ложными. Вместо этого к каждому
> документу, выводы которого опирались на коммерческий профиль, добавлена
> пометка в шапке — `09`, `10`, `11`, `12`, `13`, `14`, `22`, `23`.
>
> **Точка отсчёта для действующих решений — `25-profile-change.md`.** Там
> ограничения разобраны по признаку, который их запускает: коммерческое
> использование снимается (категория A), передача копии третьему лицу теряет
> силу (B), не зависящее от профиля остаётся (C), лицензирование целевой ОС
> ухудшается (D). Читая любой документ до `25`, следует держать это в уме.

## Пул дефектов и протокол возврата

Пул живёт в `bestiary.csv`, правило — в `CONVENTIONS.md` раздел 12,
проверка пула — `tests/test_bestiary.py`.

Запись закрывается только возвратом дефекта: проверяемое состояние
воспроизводится в копии репозитория, прогон падает, копия удаляется.
Протокол прогона, применённый 2026-10-15:

```bash
rm -rf /tmp/rd && cp -r <репозиторий> /tmp/rd
find /tmp/rd -name __pycache__ -type d -exec rm -rf {} +   # кэш ломает возврат
cd /tmp/rd
python3 -c '<мутация>'                 # воспроизвести дефект класса
python3 tests/<проверка из closes>     # обязана упасть
cd - && rm -rf /tmp/rd                 # копия удаляется, оригинал не тронут
```

Три условия, без которых возврат недействителен:

1. **`__pycache__` удалён.** Кэш от прежнего эксперимента даёт результат
   прошлого состояния и выглядит как непрошедший возврат.
2. **Копия читает свои файлы.** Пока тесты зашивали абсолютный путь
   (класс `B-10`), копия проверяла оригинал: мутация копии не меняла
   результат, и возврат был физически невыполним.
3. **Мутация одна.** Несколько правок за проход не позволяют сказать,
   какая из них уронила проверку.
