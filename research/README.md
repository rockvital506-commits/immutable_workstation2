# Этап 2. Исследовательская база

База знаний, на которой строятся все последующие этапы наполнения флешки и
алгоритм миграции станции MSI Modern 15 B12M-211RU.

## Состав

| Файл | Содержание |
|------|-----------|
| `01-research-index.md` | 46 поисковых запросов в 13 кластерах, карта покрытия, методология |
| `02-findings.md` | Результаты исследований: факты с источниками |
| `03-patterns.md` | Выделенные паттерны, методологии, архитектурные конструкты |
| `04-software-inventory.md` | Софт: обязательный против заменяемого своей реализацией |
| `05-garbage-vectors.md` | Векторы инициализации мусора: триггеры, службы, реестр, GPO |
| `06-services-blocklist.md` | Службы и процессы с приоритетами «инициатор >> инициализируемый» |
| `07-blocking-mechanisms.md` | Механизмы блокировки: IFEO, GPO, hosts, firewall, ACL, wrapper |
| `08-settings-attack-vectors.md` | Векторы отмены применённых настроек (A1–A12), разбор сценария audit mode → GPO → блокировка WU, рекомендации R1–R6 |

## Профиль целевой инфраструктуры (фиксируется как константа)

| Параметр | Значение |
|----------|----------|
| Классы объектов | Домашние ПК, малый бизнес, «зоопарк» железа, домашние роутеры и сеть |
| Тип работ | Выездной мастер, **без вскрытия станций** |
| Диапазон задач | Программный ремонт, установка, оптимизация, бэкап, настройка, автоматизация развёртывания, отключение встроенного мусора ОС и вендоров материнских плат и механизмов его самовосстановления |
| Домен/AD | Отсутствует — только локальные GPO (`LGPO.exe`) |
| Сеть у клиента | Недетерминирована: каждый шаг алгоритма обязан декларировать требуемое состояние сети |
