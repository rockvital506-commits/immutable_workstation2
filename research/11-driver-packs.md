## A. Цель

Закрыть задачу из `PLAN.md`, Этап 4, п. 6: **паки драйверов и
онлайн-установщики**. Практический смысл: после установки ОС на станцию
владельца сеть, звук и накопитель должны заработать, причём часто до того, как
появился интернет.

Ограничения:

- профиль **коммерческий** — лицензия утилиты важна так же, как на Этапе 4.5;
- носитель не резиновый: раздел Ventoy 340,72 ГБ, раздел Tools 128,00 ГБ, а
  офлайн-паки драйверов — это десятки гигабайт;
- работы ведутся **без вскрытия станций**, то есть подбирать драйвер по
  наклейке на плате не получится.

## B. Что уже есть в Strelec 2026.02.05

Источник — `tools/diagnostics/strelec-tools.md`.

| Утилита | Версия | Что делает |
|---------|--------|------------|
| `Double Driver` | 4.1.0 | Резервное копирование установленных драйверов |

**И всё.** Средств установки и подбора драйверов в сборке нет. Ни DriverPack,
ни Snappy, ни аналогов.

## C. Что уже наработано по станции MSI B12M-211RU

Этап 4.3 оставил готовую карту железа в
`ventoy-partition/builds/MSI_B12M-211RU_Win11_LTSC_IoT_24H2/`:

| Устройство | HWID | Драйвер |
|------------|------|---------|
| Intel Wi-Fi 6E AX211 | `PCI\VEN_8086&DEV_51F0` | `netwtw08.inf` / `netwtw6e.inf` |
| Bluetooth | — | Realtek |
| Накопитель | — | Intel IRST/VMD, если VMD включён в BIOS |

Там же зафиксировано: Intel 12-го поколения может не показать NVMe
установщику — нужен драйвер IRST/VMD либо `Enable VMD controller = Disabled`,
и драйвер Wi-Fi ставится **до** любых онлайн-шагов, иначе алгоритм встанет.

Это меняет постановку задачи: для целевой станции нужен не «пак на все
случаи», а **четыре конкретных драйвера**. Пак — для зоопарка прочих машин.

## D. Разбор инструментов

### D1. DriverPack Solution — не рекомендовать

| Свойство | Значение |
|----------|----------|
| Лицензия | Ad-Supported, не открытый код |
| Офлайн-пак | 20–45 ГБ по разным источникам |
| Побочное ПО | **Да, по умолчанию**: Opera, Firefox, Yandex, Avast, 360 Security |
| Реакция антивирусов | Помечается как PUP |
| Удаление | Собственного деинсталлятора нет |

Ключевая фраза из разборов: «default mode does not give you that choice» —
отвязать побочное ПО можно только в Expert Mode, а не в режиме по умолчанию.
Для выездного мастера, который ставит софт на чужую коммерческую машину, это
неприемлемо: риск поставить владельцу браузер и антивирусную подписку, которых
он не просил. **Исключить.**

### D2. Snappy Driver Installer Origin (SDIO) — рекомендовать

| Свойство | Значение |
|----------|----------|
| Лицензия | **GNU GPL v3.0** — коммерческое использование разрешено |
| Побочное ПО | Нет. Прямо: no ads, no bundled software, no tracking |
| Размер программы | около 7 МБ, ZIP, портативная |
| ОС | Windows XP — 11 |
| Офлайн-режим | Да, но паки ~25 ГБ |
| Онлайн-режим | Да, достаточно скачать только индексы |
| Поддержка | Win XP–11, портативная, не требует установки |

**Развилка, которую нельзя перепутать.** Есть два проекта:

- `Snappy Driver Installer` (SDI), автор samlab-ws, версия по каталогам 1.26.1;
- `Snappy Driver Installer Origin` (SDIO), автор **Glenn Delahoy**, форк с
  2017 года, версия 2.0.4.887.

Независимые обзоры прямо рекомендуют Origin: «SDIO is the best version to
use». Брать нужно SDIO.

### D3. Средства ОС — основной слой

| Задача | Команда |
|--------|---------|
| Поставить драйвер из INF | `pnputil /add-driver <путь>\*.inf /subdirs /install` |
| Перечислить установленные сторонние | `pnputil /enum-drivers` |
| Найти проблемные устройства | `pnputil /enum-devices /problem` |
| Удалить драйвер | `pnputil /delete-driver oem<NN>.inf /uninstall` |
| Выгрузить драйверы из работающей ОС | `DISM /Online /Export-Driver /Destination:<путь>` |
| Выгрузить из образа | `DISM /Image:<путь> /Export-Driver /Destination:<путь>` |
| Добавить драйвер в образ | `DISM /Image:<путь> /Add-Driver /Driver:<путь> /Recurse` |
| Проверить, что Windows сам поставит | Центр обновления → необязательные обновления |

`export-drivers` на Этапе 2 уже построен вокруг `DISM /Export-Driver`, то есть
половина этой подкатегории в репозитории есть.

### D4. Вендорские установщики

`Intel Driver & Support Assistant`, `MSI Center`, `Dell Command | Update`.
Устанавливаются на станцию владельца, требуют интернета, лицензии по каждому
не проверены. Для разовой выездной работы избыточны: нужный драйвер проще
положить на флешку.

## E. Систематизация: что реально нужно на флешке

Три разных задачи, и смешивать их нельзя.

| Задача | Чем закрывается | Объём на флешке |
|--------|-----------------|-----------------|
| Целевая станция MSI B12M | Четыре конкретных драйвера: AX211 Wi-Fi, Realtek BT, Intel IRST/VMD, чипсет | десятки МБ |
| Прочие машины, интернет есть | SDIO в онлайн-режиме: только индексы | ~7 МБ |
| Прочие машины, интернета нет | Либо SDIO с паками, либо `pnputil` из заранее собранного каталога | 25 ГБ или меньше, если отбирать |

**Вывод по объёму.** Полный офлайн-пак на 25 ГБ класть на раздел Ventoy
нецелесообразно: он съест 7 % раздела ради сценария, который закрывается
онлайн-режимом. Разумный вариант — SDIO с индексами плюс curated-каталог
драйверов под ходовое железо, который пополняется по мере выездов.

## F. Паттерны для внедрения

1. **Сначала `pnputil`, потом пак.** Средство ОС не имеет лицензионных
   ограничений, не ставит ничего лишнего и работает офлайн. Пак — только когда
   устройство неизвестно.
2. **Драйвер Wi-Fi — первый.** Пока нет сети, онлайн-режим не работает, а
   скачать что-то на станции нельзя. Это уже зафиксировано в `algorithm.md`
   станции.
3. **Не ставить драйвер, который Windows поставит сам.** Лишний драйвер —
   лишний повод для конфликта. Проверять `pnputil /enum-devices /problem`: если
   проблемных нет, делать нечего.
4. **Побочное ПО недопустимо.** Критерий отбора пака — не размер базы, а
   отсутствие предустановок. По этому критерию DriverPack исключается.
5. **Выгружать драйверы с рабочей станции до переустановки.** `DISM
   /Export-Driver` на живой ОС даёт набор, который гарантированно работал на
   этом железе. Это надёжнее любого пака.
6. **Curated-каталог вместо полного пака.** Хранить не 25 ГБ, а то, что
   реально встречалось, с HWID в имени каталога.

## G. Черновая структура группы

| Подкатегория | Что закрывает | Кандидаты |
|--------------|---------------|-----------|
| `packs/` | Подбор и установка по неизвестному железу | `SDIO` (GPLv3) |
| `online/` | Онлайн-установщики вендоров | Intel DSA, MSI Center — по решению |
| `export/` | Выгрузка и установка INF средствами ОС | `pnputil`, `DISM` — утилит не нужно |
| `catalog/` | Отобранные драйверы под ходовое железо | свои файлы, не утилита |

Пересечение с `backup/initial_backup/export-drivers` намеренное: там выгрузка в
бэкап, здесь — установка. Ссылки должны быть в обе стороны.

## H. Что сделать не удалось

- **Подтвердить версию SDIO первоисточником нельзя.** Официальный хостинг —
  SourceForge, он недоступен из рабочей среды. На GitHub официального
  репозитория нет: поиск API GitHub по «snappy driver installer origin» даёт
  только форки и темы (`Flygenring/sdio-theme`,
  `FarmhouseNetworking/SnappyDriverInstallerOrigin-AutoInstall` и т.п.),
  исходного репозитория среди них нет. Версия 2.0.4.887 подтверждается двумя
  независимыми каталогами (MajorGeeks 2026-09-14, Softpedia 2026-09-15) и
  Chocolatey, но это не первоисточник.
- Проверить фактический размер и состав паков SDIO.
- Проверить лицензии вендорских онлайн-установщиков: сайты Intel и MSI
  недоступны.
- Убедиться, что драйвер Intel AX211 из curated-каталога подойдёт к IoT
  Enterprise LTSC 2024: в LTSC-редакциях состав компонентов отличается.
