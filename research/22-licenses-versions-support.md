# Исследования вне GitHub: лицензии, версии, сроки поддержки

Дата: 2026-10-15. Исследование по требованию «веб-исследования вне GitHub».
Источники — страницы вендоров, журнал Sysinternals на `learn.microsoft.com`,
страница выпуска Ventoy, обзоры лицензий. GitHub намеренно не использовался:
по нему данные уже были сняты через `api.github.com` в `research/21`.

Контекст: профиль работ **коммерческий** (выездной мастер, малый бизнес),
поэтому лицензия проверяется не на «можно ли скачать», а на «можно ли
применять у заказчика за деньги».

### 1.3. Сроки поддержки Windows

Поддержка **Windows 11 24H2 Home и Pro прекращена**: последнее обновление
безопасности вышло во вторник 13.10.2026, страница жизненного цикла
Microsoft указывает окончание 14.10.2026 06:59 по тихоокеанскому времени.
**Программы ESU для Windows 11 24H2 Home и Pro не существует** — в отличие от
Windows 10, где платное продление есть. Enterprise и Education того же выпуска
24H2 поддерживаются до 13.10.2027.

Windows 11 25H2 — до 13.10.2027 для Home/Pro. Windows 11 26H2 вышел
29.09.2026 и ставится на 24H2 пакетом включения; для Home/Pro заявлена
поддержка до октября 2029.

### 1.4. Ventoy 1.1.18

Выпуск от 09.10.2026. Содержательное для нашего набора:

- **Исправлен сбой проверки версии Secure Boot для Windows/WinPE.** Наша
  пара WinPE Strelec + Windows ставилась именно на этот механизм.
- **ISO-раздел сделан монтируемым для Clonezilla** (#3274). У нас Clonezilla
  грузится с той же флешки, что и образы.
- Имя device-mapper для ISO-раздела стало стабильным: `/dev/mapper/VentoyPart`.
- VentoyPlugson получил проверку записей Boot Conf Replace.
- На SourceForge рядом с файлами выпуска лежит **`sha256.txt`** (276 байт),
  то есть контрольные суммы Ventoy публикуются официально.

### 1.5. Где брать контрольные суммы, когда сайт вендора их не даёт

Найден рабочий приём: пакетные менеджеры публикуют хэш вместе с манифестом.
Пример — scoop-бакет NirSoft хранит для WifiInfoView:

```
64bit https://www.nirsoft.net/utils/wifiinfoview-x64.zip
      e9d0ee4d941764eace0ea34d2299714d38393d030a6019b08e14df2533ff8c12
32bit https://www.nirsoft.net/utils/wifiinfoview.zip
      4262b7a2020235baf4fd471aae236ca9ab9d357ec727b7e4e23b2245e11c132c
```

Это сторонний каталог, поэтому такое значение допустимо только с пометкой об
источнике — правило уже принято для контрольных сумм из сторонних каталогов.
Приём обобщается: Ventoy — `sha256.txt` на SourceForge, NirSoft — бакет scoop,
GitHub — ассеты выпуска, Microsoft — журнал Sysinternals и страница загрузки.

## 2. Находки

### N8. Свободная редакция DMDE не разрешает коммерческое использование

`tools/rescue/data_recovery/DMDE/README.md` описывает ограничение в 4000
файлов и называет лицензию «Shareware: freeware-режим с ограничениями», но не
говорит главного: свободный режим предназначен для личного некоммерческого
применения, а право восстанавливать данные клиентам даёт только Professional.
Профиль работ коммерческий, значит утилита в текущем виде не пригодна для
выезда без покупки лицензии.

В `research/` нет ни одной записи о лицензии DMDE: разбор лицензий на Этапах
4.1–4.7 её не касался.

Источники: страница загрузки DMDE и обзоры лицензий 2026 года.

`fix_target = decision`: купить Professional, либо заменить утилиту, либо
оставить с явной пометкой «только для личной диагностики мастера».

### N9. Версии трёх утилит Sysinternals не записаны или устарели

`ProcessExplorer` указан как `4.19` при актуальной **v17.14** от 10.09.2026 —
расхождение на тринадцать мажорных номеров. `Autoruns` и часть записей
помечены `unversioned` при актуальной **v14.3** от 17.06.2026. Для Autoruns
разница содержательная: с v14.2 видны упакованные приложения.

Источники: журнал «What's New» на `learn.microsoft.com/sysinternals`, обзоры
выпусков Sysinternals Suite 2026.8 и 2026.9.

`fix_target = state`.

### N10. Поддержка Win11 24H2 Home/Pro описана как будущая, хотя она прекращена

`tools/docs/compatibility.md` в четырёх местах пишет «поддержка истекает
14.10.2026»; `tools/docs/CHANGELOG-flash.md` повторяет это. Дата прошла:
последнее обновление вышло 13.10.2026.

Второе расхождение содержательнее даты: в документе нет того, что **ESU для
Windows 11 24H2 Home и Pro не существует**. Читатель, который помнит платное
продление для Windows 10, сделает неверный вывод, что станцию можно оставить
на 24H2 за деньги. Оставить нельзя — только переход на 25H2 или 26H2 либо
смена редакции.

Источники: страница жизненного цикла Microsoft, сообщения о прекращении
поддержки от 13.10.2026.

`fix_target = state`.

### N11. Ventoy 1.1.18 закрывает два наших сценария, а документация этого не отражает

Рекомендуемая версия 1.1.18 в `tools/docs/flash-update.md` названа, но что
именно она меняет для нашего набора — не записано. Из выпуска 09.10.2026:
исправлена проверка версии Secure Boot для Windows/WinPE и сделан монтируемым
ISO-раздел для Clonezilla. Первое относится к загрузке Strelec и установщика
Windows при включённом Secure Boot, второе — к снятию образа той же флешкой.

Дополнительно: официальная публикация `sha256.txt` на SourceForge — это
источник контрольной суммы для строки Ventoy, которой в manifests сейчас нет.

`fix_target = state`.

### N12. Приём получения контрольных сумм из пакетных менеджеров не записан

Правило «контрольные суммы из сторонних каталогов допустимы с пометкой об
источнике» принято, но где именно брать суммы, когда сайт вендора их не
публикует, нигде не записано. Прием существует и проверен на двух случаях:
`sha256.txt` выпуска Ventoy на SourceForge и манифест scoop-бакета NirSoft с
хэшами WifiInfoView. Без записи каждый раз поиск начинается заново.

`fix_target = doc`.

## 4. Что не проверялось

- Условия лицензии DMDE не читались в оригинальном тексте лицензионного
  соглашения: выводы сделаны по странице загрузки и обзорам 2026 года.
- Версия TCPView не подтверждена отдельно от версии набора: в журнале она не
  названа, указана только принадлежность к Sysinternals Suite 2026.8.
- Версии `CrystalDiskInfo`, `MemTest86Plus`, `Prime95`, `Nmap`, `Wireshark`,
  `iperf3`, `SDIO` в этом исследовании не сверялись.
- Наличие платной лицензии DMDE у заказчика не выяснялось — это вопрос к нему.
