# R6 — квалификация готовности точного кандидата

## 1. Что оценивалось и чем это не является

Предмет: [текст правил v2](57-agent-system-portable-rules-text-v2.md), SHA256
`15338d93103875dff2dad53218a827d9c2f26f8aa6ac8bd7af338529ac99cd85`, статус `owner_accepted_text_v2_not_registered`.

Оценено: покрывает ли текст 16 обязательных способностей (G01–G07, W01–W09) и
9 условий выпуска (C02–C10), и на каком уровне доказательств каждое из них
подтверждено **сейчас**.

Не оценено и не заявляется: реализация способностей, поведение агента,
совместимость с какой-либо средой, полнота перечня относительно внешнего
стандарта. Текст — свод правил, а не работающая система; матрица это не
скрывает.

## 2. Уровни доказательств

| Уровень | Что означает |
|---|---|
| L0 | текст правила (статическое чтение) |
| L1 | структурная проверка артефакта (хеши, полнота, отсутствие шаблонов) |
| L2 | модель/симуляция с проверяемыми переходами |
| L3 | ограниченное исполнение в изолированном контуре |
| L4 | изолированный перенос в отдельную среду |
| L5 | реальное подключение и наблюдение поведения |

Уровень назначается каждой строке отдельно. «Структурно проверено» — значит, что
тест репозитория утверждает свойство артефакта, а не поведение системы.

## 4. Итог

| Показатель | Значение |

| Текст покрывает полностью | 22 |

| Требование покрыто текстом не полностью | 0 |
| Достигают требуемого уровня доказательств | **3 из 25** |
| Подтверждено на уровне поведения | 0 |
| Строк с поведенческим доказательством | 0 |

**Выпуск не готов.** Как кандидатный текст свод состоятелен: 22 из 25
требований покрыты полностью, остальные три названы честно. Как совместимый
выпуск — нет: ни одна способность не подтверждена на уровне, который нужен для
такого утверждения.

Причины, ни одна из которых не снимается количеством документов или зелёных
тестов:

- нет утверждённой ревизии (Q1 — не регистрировать), поэтому нечего выпускать нормативно
- нет независимой семантической проверки (B4)
- нет поведенческих доказательств ни по одной способности
- нет обследования среды (B5) и адаптеров, поэтому применимость не установлена

## 5. Текстовые пробелы

- **W03** — нет отдельного правила об отборе паттернов с основанием; F10/F18 покрывают только границы вывода
- **W08** — нет правила о версионируемой очереди отложенного; F10/F23 покрывают неизвестное и историю, но не условие возврата
- **G05** — правило требует разбирать неизвестное, но механизм адаптации отсутствует; это граница текста, а не дефект формулировки

Это не дефекты формулировок, а отсутствующие пункты. Закрывать их можно только
новым правилом с цитатой-основанием и новым решением владельца — правка текста
аннулирует принятие v2 так же, как предыдущая аннулировала принятие v1.

## 6. Что изменило бы вердикт

1. закрыть B4 независимой проверкой 23 правил
2. закрыть текстовые пробелы W03 и W08 либо решением владельца признать F10/F18/F23 достаточными
3. получить поведенческие доказательства хотя бы на согласованном сценарии (L3+)
4. отдельное решение владельца об утверждении точной ревизии, если выпуск нужен в нормативной форме

Порядок не произвольный: независимая проверка (B4) дешевле и полезнее
поведенческих испытаний, а утверждение ревизии — отдельное решение владельца,
которое агент не запрашивает и не подразумевает.

## 8. Честность оценки

- Сопоставление «требование → правило» сделано автором
  (`author_classification_not_independent`); другая классификация может дать
  иные границы, особенно для W03, W05 и G05.
- Статусы не повышены ни по одному пункту: старые G01–G07, W01–W09 и C02–C10
  не объявлены закрытыми.
- Ближайшие по смыслу правила подбирались по тексту, а не по удобству: там, где
  связь слабая (W03, W08), это записано как частичное покрытие, а не как
  «покрыто».
- Полномочия не выданы: выпуск, экспорт, активация, совместимый выпуск и новая
  среда — `false`; реестр не изменён.

## 9. Следующий шаг

Закрытие B4 — независимая проверка 23 правил по списку из [53](53-agent-system-condition-rules.md) —
и ваше решение по W03/W08: либо новые пункты правил, либо явное признание, что
F10/F18/F23 достаточно. До этого R4 actual claim и экспортёр остаются
преждевременными.
