# 04. Реестр софта: обязательный и заменяемый

Критерий разделения:

- **ОБЯЗАТЕЛЬНЫЙ** — без него задача не решается либо своя реализация заметно
  дороже/ненадёжнее (нет штатной замены в ОС).
- **ЗАМЕНЯЕМЫЙ** — штатные средства ОС или собственный скрипт решают задачу на
  том же уровне; внешний софт держим только как удобство/второе мнение.

Все позиции хранятся на флешке заглушками `<имя>.<расширение>.md` и строкой в
`manifest.csv`.

---

## 1. ОБЯЗАТЕЛЬНЫЙ софт

### 1.1 Загрузка и развёртывание

| Софт | Назначение | Почему обязателен |
|------|-----------|-------------------|
| **Ventoy** v1.1.17 | Мультизагрузчик | База всей флешки; уже установлен |
| **Ventoy VHD Boot Plugin** (`ventoy_vhdboot.img`) | Загрузка VHDX с Windows | Единственный штатный способ «Windows с сохранением изменений» на Ventoy (B2) |
| **Ventoy Wimboot Plugin** (`ventoy_wimboot.img`) | Загрузка `.wim` Strelec напрямую | Ускоряет вход в WinPE, грузит ядро без ISO-обёртки (B7) |
| **VentoyPlugson** | GUI-настройка `ventoy.json` | Снижает риск сломать конфиг вручную |

### 1.2 Образы (ISO)

| Образ | Роль | Статус |
|-------|------|--------|
| `en-us_windows_11_iot_enterprise_ltsc_2024_x64_dvd_f6b14814.iso` | Основная целевая ОС станции | **обязателен** (задан заказчиком) |
| Windows 10 IoT Enterprise LTSC **21H2** x64 | **Вторая равноправная целевая ОС** (решение заказчика): старый парк и случаи, где Win11 не проходит | **обязателен** |
| Windows 10 Pro / Windows 11 Pro | Для заказчиков без IoT-лицензии | **обязателен** (задан заказчиком) |
| WinPE 11-10 Sergei Strelec | Аварийная среда: разметка, бэкап, восстановление | **обязателен** (задан заказчиком) |
| Linux Mint (Xfce/Mate) | Live-среда с персистентностью: сеть, браузер, файлы | **обязателен** (задан заказчиком) |
| Clonezilla Live | Образы дисков и разделов | **обязателен** — см. 1.3 |

### 1.3 Диагностика и образы дисков

| Софт | Назначение | Почему не заменяем своим |
|------|-----------|--------------------------|
| **Clonezilla Live** | Снятие/восстановление образов диска, partclone, MBR/GPT | Своя реализация = писать partclone-обвязку; ненадёжно (G1, G3) |
| **CrystalDiskInfo** | SMART, здоровье SSD, TRIM-поддержка | Быстрый визуальный отчёт для заказчика |
| **Victoria** | Тест поверхности, ремап, паспорт накопителя | Низкоуровневый доступ, которого нет у штатных средств |
| **MemTest86** | Проверка RAM | Работает до загрузки ОС — незаменимо при «зоопарке железа» |
| **HWiNFO64 Portable** | Инвентаризация: точные модели, ревизии, температуры | Источник Hardware ID для подбора драйверов |

### 1.4 Драйверы станции

| Позиция | Источник | Комментарий |
|---------|----------|-------------|
| Экспорт драйверов текущей ОС | `DISM /Online /Export-Driver /Destination:...` | **Первичный источник** «чистых драйверов» (H1) |
| Intel Wi-Fi 6E AX211 | Intel / MSI | `PCI\VEN_8086&DEV_51F0` (F1) |
| Realtek Bluetooth RTL8822 | Realtek / MSI | `USB\VID_0BDA&PID_D723` (F1) |
| Realtek Audio (SmartSST) | Realtek / MSI | `INTELAUDIO\FUNC_01&VEN_10EC&DEV_0256` (F1) |
| Intel DTT / IPF | Intel / MSI | `PCI\VEN_8086&DEV_461D` (F1) |
| Intel GNA | Intel / MSI | `PCI\VEN_8086&DEV_464F` (F1) |
| Intel Chipset (Alder Lake) | Intel / MSI | `PCI\VEN_8086&DEV_4601` (F1) |
| **Intel IRST / VMD** | Intel / MSI | **Критично**: без него установщик может не увидеть NVMe (F2) |

### 1.5 Данные и бэкап пользователя

| Софт | Назначение |
|------|-----------|
| **7-Zip** (portable) | Архивация профилей, работа с `.wim`/`.vhd`, перепаковка ядра Strelec (B8) |
| Собственный скрипт `backup-user-profile` | Копирование `User Data` Chrome и `%APPDATA%\Code` с проверкой, что приложения закрыты (L2) |

## 2. ЗАМЕНЯЕМЫЙ софт (своя реализация не хуже)

| Софт | Что умеет | Наша замена | Решение |
|------|-----------|-------------|---------|
| **Win11Debloat (Raphire)** | Debloat через реестр/GPO, undo-файлы | Собственный PowerShell-модуль `Disable-Bloat` + `Restore-Bloat` по тем же ключам (D7, D8) | Держать как **эталон для сверки списков**, не как основной исполнитель |
| **Chris Titus WinUtil** | Debloat + установка софта + сборка ISO | Наши скрипты + `winget`-манифест | Не включать в регламент: `irm ... \| iex` с флешки — недопустимый риск (J5) |
| **Sophia Script** | 150+ твиков, обратимость | Наши скрипты покрывают нужное подмножество | Опционально, только **закреплённая** версия (конфликт J4) |
| **O&O ShutUp10++** | GUI приватности | Те же реестровые ключи в нашем модуле | Не включать |
| **Everything** | Поиск по NTFS без индекса | Замена `WSearch`, а не бэкап-инструмент | **Включить как замену WSearch** (D4) — здесь он не «заменяемый», а целевой |
| **AOMEI Backupper / Macrium Reflect** | Образы дисков из-под WinPE | Clonezilla Live покрывает задачу (G1) | Не включать: дублирование |
| **Rufus** | Запись ISO, Windows To Go в VHD | Ventoy + `diskpart`; Rufus нужен **только** для сценария B5 | Держать в TOOLS как утилиту, не в регламенте миграции |
| **NTLite / MSMG Toolkit** | Сборка кастомных ISO | Ventoy `auto_install` + `autounattend.xml` решает задачу без пересборки ISO (K1) | Не включать |
| **Schneegans Unattend Generator** | Генерация `autounattend.xml` | Наш шаблон `autounattend.xml` в `ventoy/autoinstall/` | Использовать **однократно** при создании шаблона, в состав флешки не входит |
| **DriverPack Solution / Snappy Driver Installer** | Массовая установка драйверов | `DISM /Export-Driver` + `pnputil /add-driver` | **Не включать**: источник неподписанного/чужого мусора, противоречит цели «чистые драйверы» |
| **CCleaner** | Чистка мусора | `cleanmgr`, `DISM /StartComponentCleanup`, наши скрипты | Не включать |
| **Autoruns** | Анализ автозагрузки | `Get-ScheduledTask`, `Get-Service`, чтение Run-ключей нашим аудит-скриптом | Держать как **второе мнение** при диагностике, не в регламенте |

## 3. Спорные позиции — нужно решение заказчика

| Позиция | Аргумент «за» | Аргумент «против» |
|---------|---------------|-------------------|
| **Autoruns** | Незаменим при поиске OEM-агентов | Наш аудит-скрипт даёт то же в виде отчёта |
| **Sophia Script** | 150 готовых обратимых твиков | Конфликт версий (J4), риск ложных срабатываний AV |
| **Rufus** | Нужен для Windows To Go в VHD | Используется в одном сценарии |
| **AIDA64 / HWiNFO** | Глубокая инвентаризация | HWiNFO покрывает задачу; AIDA64 — платная |
| **Dr.Web LiveDisk / Kaspersky Rescue Disk** | Лечение заражённых машин | Требует интернет для обновления баз; тяжеловесны |

## 4. Чего в составе быть не должно (явный запрет)

- Любые драйвер-паки сторонних сборщиков (DriverPack, SDI и т.п.) — источник
  чужого мусора и неподписанных драйверов.
- Скрипты, запускаемые из интернета (`irm ... | iex`) — нарушение воспроизводимости.
- Утилиты, требующие установки в систему (только portable).
- Любые «активаторы» и средства обхода лицензирования.
- Софт с телеметрией, который сам становится источником мусора.
