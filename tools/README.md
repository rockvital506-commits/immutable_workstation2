# tools/ — раздел TOOLS флешки

Второй раздел флешки, метка `TOOLS`, ФС exFAT. Здесь живут утилиты, скрипты,
модули и офлайн-документация. Раздел **не затрагивается** при обновлении или
переустановке Ventoy — это главное преимущество выноса инструментов на отдельный
раздел.

> Каталог `tools/` в репозитории = содержимое раздела `TOOLS:` на флешке.
> Точка монтирования при проверке: `check-flash.sh --tools-mount /mnt/tools`.

## Группы (утверждаются на Этапе 3)

| Группа | Подкатегории | Что внутри |
|--------|-------------|-----------|
| `os/` | `windows/`, `linux/`, `activation/`, `tweaks/` | Установка, настройка, удаление предустановленного мусора, активация |
| `rescue/` | `password/`, `data_recovery/`, `partition/`, `registry/`, `boot/` | Снятие паролей, восстановление данных, редакторы разделов, офлайн-правка реестра, восстановление загрузчика |
| `diagnostics/` | `disk/`, `memory/`, `cpu/`, `gpu/`, `temperature/`, `hwinfo/` | Проверка железа: диски, память, нагрузки, температуры, инвентаризация |
| `security/` | `antivirus/`, `audit/`, `crypto/`, `firmware-scan/` | Сканеры, аудит, шифрование, проверка прошивок |
| `network/` | `diagnostics/`, `speed/`, `scan/`, `wifi/`, `remote/`, `capture/` | Диагностика сети, iperf, сканирование, Wi-Fi, удалённый доступ, сниффинг |
| `drivers/` | `windows/`, `linux/`, `chipset/`, `network/`, `storage/` | Драйвер-паки и точечные драйверы по вендорам |
| `backup/` | `disk_image/`, `files/`, `sync/`, `cloud/` | Образы дисков, файловые бэкапы, синхронизация |
| `deployment/` | `unattended/`, `wim/`, `oem/`, `scripts/` | Подготовка и развёртывание образов |
| `scripts/` | `windows/`, `linux/`, `flash/` | Наши наработки: PowerShell, bash, обслуживание флешки |
| `docs-offline/` | `manuals/`, `cheatsheets/`, `schemas/` | Документация, читаемая без интернета, прямо с флешки |
| `_scratch/` | — | Временное на один выезд; в git не попадает |

## Устройство каталога-утилиты

```
tools/diagnostics/disk/Victoria/
├── README.md          обязателен: назначение, запуск, ключи, риски, версия, источник
├── Victoria.exe.md    заглушка бинарника (сам .exe в git не попадает)
└── ...                конфиги, словари, примеры — текстом, как есть
```

Одна утилита = один каталог. Несколько версий одной утилиты — подкаталоги
`Victoria/4.47/`, `Victoria/5.37/`, у каждой свой `README.md`.

## Шаблоны

| Файл | Для чего |
|------|----------|
| `_templates/UTILITY_README.md` | Каталог сторонней или нашей утилиты |
| `_templates/SCRIPT_README.md` | Каталог со скриптом или набором скриптов |
| `_templates/MODULE_README.md` | Составной модуль: утилита + скрипт + регламент |

Создать каркас автоматически:
`scripts/new-tool.sh --group diagnostics --subgroup disk --name Victoria`

## Что не должно лежать в TOOLS

- Образы ISO — их место в разделе VENTOY, каталог `ISO/`.
- Бэкапы клиентов и образы машин — только в `ventoy-partition/backup/` или вне флешки.
- Пароли, ключи, токены — нигде на флешке в открытом виде.
- Мусор после распаковки (`$PLUGINSDIR`, `unins000.exe`, `setup.exe` инсталляторов) —
  утилиты держим в портативном виде.
