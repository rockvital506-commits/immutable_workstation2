# RustDesk

## Назначение

Удалённый доступ к станции заказчика, передача файлов, проброс портов.
Открытый исходный код под AGPL-3.0 — единственное такое средство в нашем
наборе и единственное, где свой сервер бесплатен.

Основной инструмент мастера. TeamViewer, AnyDesk, Ammyy Admin, AeroAdmin и
Radmin из Strelec остаются как запасные.

## Когда применять

- Заказчик звонит с проблемой, станция доступна, выезжать не нужно.
- Надо забрать файл со станции или положить на неё файл.
- Надо пробросить порт роутера или NAS заказчика наружу для проверки.
- Надо работать внутри локальной сети объекта, где интернета нет.
- Надо настроить несеансовый доступ на станции, чтобы подключаться позже.

## Запуск

Портативно, без установки — основной режим:

```powershell
& "E:\tools\network\remote\RustDesk\rustdesk-1.5.0-x86_64.exe" --noinstall
```

Режим быстрой помощи, когда станцию заказчика трогать нельзя:

```powershell
& "E:\tools\network\remote\RustDesk\rustdesk-1.5.0-x86_64.exe" --quick_support
```

- Требуются права администратора: **да** для установки службы и несеансового
  доступа, **нет** для разового подключения
- Работает из-под WinPE: **да**, портативный режим
- Работает с флешки без установки: **да**, через `--noinstall`
- Требует .NET / VC++ Redist: **нет**

## Ключи и типовые сценарии

Флаги проверены по `src/core_main.rs` релиза 1.5.0, а не по документации.

| Задача | Команда |
|--------|---------|
| Портативный запуск | `--noinstall` |
| Быстрая помощь | `--quick_support` |
| Подключиться к узлу | `--connect` |
| Передать файл | `--file-transfer` |
| Пробросить порт | `--port-forward` |
| Терминал | `--terminal` |
| Подключиться к RDP-сессии | `--rdp` |
| Камера | `--view-camera` |
| Тихая установка на станцию | `--silent-install` |
| Служба несеансового доступа | `--install-service`, `--service` |
| Снять службу | `--uninstall-service`, `--uninstall` |
| Права системы | `--run-as-system` |
| Повышение прав | `--elevate` |
| Подключить свой сервер | `--import-config` |
| Версия и дата сборки | `--version`, `--build-date` |
| Виртуальный монитор | `--install-idd` |
| Удалённый принтер | `--install-remote-printer` |

Отдельно: модуль `src/lan.rs` даёт **обнаружение узлов в локальной сети без
сервера согласования**. Это то, что позволяет работать на объекте без
интернета.

## Результаты и как их читать

Журналы клиент пишет в свой каталог данных. Для отчёта заказчику достаточно
фиксировать: идентификатор узла, время сеанса, что сделано.

При подключении к своему серверу в настройках указываются адрес `hbbs`,
ключ и адрес реле `hbbr`. Проверить, что клиент смотрит на нужный сервер,
надо до первого сеанса, а не после.

## Риски и предупреждения

> Публичный сервер `rs-ny.rustdesk.com` — общая best-effort инфраструктура
> **без SLA**. Для разовой помощи годится, для регулярной коммерческой
> поддержки — нет. Ставить свой `hbbs` + `hbbr`.

> Бесплатный OSS-сервер — это реле и брокер идентификаторов, а не консоль
> управления. Веб-панели, адресной книги, групп устройств и журнала аудита в
> нём нет. Для одного мастера это заменяется файлом в каталоге станционной
> сборки.

> `--silent-install` на станции заказчика ставить только с его согласия. Это
> постоянный канал доступа к его машине.

> AGPL-3.0 требует обеспечить получателю доступ к исходникам. Файл
> `LICENSE-SOURCE.md` рядом с бинарником закрывает это требование. Бинарник
> не изменять.

> Режим `--install-idd` ставит драйвер виртуального монитора. На станции
> заказчика это изменение конфигурации, делать только при необходимости.

## Аналоги

| Утилита | Когда предпочесть |
|---------|-------------------|
| `TeamViewer 15` из Strelec | У заказчика уже стоит TeamViewer или его межсетевой экран разрешает только его |
| `AnyDesk` из Strelec | Нужен минимальный объём трафика на плохом канале |
| `Ammyy Admin` из Strelec | Совместимость со старыми станциями. Учитывать, что антивирусы помечают его как инструмент злоумышленников |
| `Radmin 3.5.2.1` из Strelec | Нужен свой сервер и работа в домене |
| `UltraVNC` / `TightVNC` из Strelec | Открытый порт VNC уже есть |
| `RustDesk Server Pro` | Не нужен: адресная книга и журнал для одного мастера заменяются файлом |
