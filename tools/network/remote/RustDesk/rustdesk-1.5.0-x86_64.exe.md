## Как получить

Единственный Windows x64 ассет релиза `1.5.0` от 2026-09-30.

Для 32-битных станций есть отдельный ассет `rustdesk-1.5.0-x86-sciter.exe`
(13377392 байта) — он собран на движке Sciter и в состав не входит, но
под старое железо брать его.

## Проверка подлинности

После скачивания вычислить SHA256 и внести вместо `PENDING`:

```powershell
Get-FileHash -Algorithm SHA256 "E:\tools\network\remote\RustDesk\rustdesk-1.5.0-x86_64.exe"
```

```bash
sha256sum "/mnt/tools/network/remote/RustDesk/rustdesk-1.5.0-x86_64.exe"
```

Размер 25887600 байт сверен через API GitHub и служит первой проверкой.
Контрольную сумму сверить с ассетом того же релиза на странице GitHub.

## Куда положить на флешке

`Tools:\network\remote\RustDesk\` — файл как есть, установка не нужна при запуске с `--noinstall`.

Рядом с файлом должен лежать `LICENSE-SOURCE.md` со ссылкой на репозиторий и
тег. Требование лицензии — обеспечить получателю доступ к исходникам. Мы
бинарник не изменяем, поэтому этого достаточно.
