# RustDesk: доступ к исходному коду

Файл лежит рядом с `rustdesk-1.5.0-x86_64.exe` и закрывает требование лицензии
AGPL-3.0 об обеспечении получателя доступом к исходному коду.

## Где исходники

| Поле | Значение |
|------|----------|
| Репозиторий клиента | https://github.com/rustdesk/rustdesk |
| Тег версии | `1.5.0` |
| Архив исходников этой версии | https://codeload.github.com/rustdesk/rustdesk/tar.gz/refs/tags/1.5.0 |
| Репозиторий сервера | https://github.com/rustdesk/rustdesk-server |
| Тег сервера | `1.1.16` |
| Лицензия | GNU Affero General Public License v3, файл `LICENCE` в корне репозитория |

## Что мы изменяем

**Ничего.** На флешку кладётся официальный ассет релиза без правок. Поэтому
обязательства по публикации изменений не возникает.

## Что требуется от того, кто распространяет дальше

При передаче этого файла кому-либо вместе с ним передаётся и этот файл.
Требование AGPL-3.0 — обеспечить получателю возможность получить исходный код
той же версии.
