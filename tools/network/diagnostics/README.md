# diagnostics/ — диагностика сети средствами ОС

Утилит здесь **нет намеренно**. Базовую диагностику Windows делает своими
средствами, и они всегда под рукой, в том числе в WinPE.

## Что использовать

| Задача | Команда | На что смотреть |
|--------|---------|-----------------|
| Доступность узла | `ping -n 10 192.168.1.1` | Потери и разброс задержки |
| Путь до узла | `tracert 8.8.8.8` | На каком узле обрывается |
| Путь с замером каждого узла | `pathping 8.8.8.8` | Где именно потери |
| Разрешение имени | `nslookup ya.ru` | Какой DNS ответил и что вернул |
| Проверка порта | `Test-NetConnection 192.168.1.1 -Port 445` | `TcpTestSucceeded` |
| Конфигурация | `ipconfig /all` | Адрес, маска, шлюз, DNS, DHCP |
| Сброс стека | `netsh int ip reset` | После сбоя стека, нужна перезагрузка |
| Сброс Winsock | `netsh winsock reset` | Когда сокет-слой сломан |
| Сброс DNS-кэша | `ipconfig /flushdns` | После смены DNS |
| Таблица ARP | `arp -a` | MAC-адреса соседей, поиск дублей |
| Таблица маршрутов | `route print` | Куда идёт трафик |
| Открытые соединения | `netstat -ano` | Что слушает и что установлено |
| Сетевые адаптеры | `Get-NetAdapter -IncludeHidden` | Состояние и скрытые адаптеры |
| Профиль Wi-Fi | `netsh wlan show interfaces` | Канал, скорость, уровень сигнала |
| Поддержка hosted network | `netsh wlan show drivers` | Строка `Hosted network supported` |
| Сохранённые сети | `netsh wlan show profiles` | Что помнит адаптер |
| Загрузить файл | `curl.exe -O адрес` | `curl` входит в состав Windows 10 и новее |

## Порядок диагностики

Порядок важнее инструмента. Пропуск шага даёт неверный вывод.

1. **Своя машина.** `ipconfig /all` — адрес получен, шлюз и DNS указаны.
2. **Шлюз.** `ping` на адрес шлюза. Нет ответа — проблема в кабеле, Wi-Fi или
   самом роутере.
3. **Наружу по адресу.** `ping 8.8.8.8`. Шлюз отвечает, а этот адрес нет —
   проблема у провайдителя или в маршрутизации.
4. **Наружу по имени.** `ping ya.ru`. Адрес отвечает, имя нет — проблема DNS.
5. **Скорость.** Только теперь замер, см. [`../speed/`](../speed/).
6. **Что открыто.** [`../scan/`](../scan/).
7. **Что в эфире**, если станция на Wi-Fi: [`../wifi/`](../wifi/).
8. **Разбор по пакетам**, если предыдущие семь шагов не объяснили проблему:
   [`../capture/`](../capture/).

Пять минут по этому порядку экономят час перебора настроек.

## Правила

> Не менять настройки сети станции заказчика до того, как снят исходный
> `ipconfig /all` и `route print` в файл. Иначе восстановить «как было» будет
> нечем.

> `netsh int ip reset` и `netsh winsock reset` требуют перезагрузки. Не
> применять их посреди работы, если перезагрузку сейчас делать нельзя.
