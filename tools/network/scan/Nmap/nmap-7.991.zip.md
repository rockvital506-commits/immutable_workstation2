## Как получить

Инсталлятор для Windows с `nmap.org/download.html`, затем упаковать в zip
без изменений содержимого.

**Почему архивом.** Решение владельца от 2026-10-15: официальные Windows-
сборки Nmap содержат `Npcap`, а его лицензия запрещает распространение без
отдельного разрешения. NPSL содержит оговорку, что включение Nmap в сжатой
или архивной форме не подпадает под определение производной работы, поэтому
на флешке хранится архив, а распаковка и установка происходят на месте.
Риск принят осознанно — раздел 10 NPSL сформулирован безусловнее оговорки
про архивы. Подробности: `research/23-license-scope.md`, N18.

Версия 7.991 и имя файла `nmap-7.991-setup.exe` взяты из поисковой выдачи по
официальной странице загрузки и из тега `v7.991` в зеркале `nmap/nmap` на
GitHub. **Релиза с ассетами в GitHub-зеркале нет** — проверено через API:
запросы `releases/latest` и `releases/tags/v7.991` возвращают `Not Found`.
Скачивать только с `nmap.org`.

## Проверка подлинности

После скачивания вычислить SHA256 и внести вместо `PENDING`:

```powershell
Get-FileHash -Algorithm SHA256 "E:\tools\network\scan\Nmap\nmap-7.991.zip"
```

```bash
sha256sum "/mnt/tools/network/scan/Nmap/nmap-7.991.zip"
```

Контрольную сумму сверить с опубликованной на `nmap.org` при скачивании.
Версию после установки проверить командой `nmap --version`.

## Напоминание про Npcap

Для сканирования нужен драйвер `Npcap`. Свежий — `npcap-1.89.exe` с
`npcap.com`; в инсталлятор Nmap может быть вложена более старая версия.
