## Как получить

Инсталлятор для Windows с `nmap.org/download.html`.

Версия 7.991 и имя файла `nmap-7.991-setup.exe` взяты из поисковой выдачи по
официальной странице загрузки и из тега `v7.991` в зеркале `nmap/nmap` на
GitHub. **Релиза с ассетами в GitHub-зеркале нет** — проверено через API:
запросы `releases/latest` и `releases/tags/v7.991` возвращают `Not Found`.
Скачивать только с `nmap.org`.

## Проверка подлинности

После скачивания вычислить SHA256 и внести вместо `PENDING`:

```powershell
Get-FileHash -Algorithm SHA256 "E:\tools\network\scan\Nmap\nmap-7.991-setup.exe"
```

```bash
sha256sum "/mnt/tools/network/scan/Nmap/nmap-7.991-setup.exe"
```

Контрольную сумму сверить с опубликованной на `nmap.org` при скачивании.
Версию после установки проверить командой `nmap --version`.

## Куда положить на флешке

`Tools:\network\scan\Nmap\` — инсталлятор; каталог утилиты на флешке хранит именно его.

## Напоминание про Npcap

Для сканирования нужен драйвер `Npcap`. Свежий — `npcap-1.89.exe` с
`npcap.com`; в инсталлятор Nmap может быть вложена более старая версия.
