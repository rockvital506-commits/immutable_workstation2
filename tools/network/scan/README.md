# scan/ — поиск узлов и открытых портов

Два разных вопроса, и их не надо смешивать: **кто есть в сети** и **что на нём
открыто**.

## Чем закрываем

| Задача | Инструмент | Где |
|--------|-----------|-----|
| Список устройств с именами, IP и MAC | `Advanced IP Scanner 2.5.4594.1` | **Strelec**, не дублируем |
| Открытые порты, версии служб, определение ОС | [`Nmap/`](Nmap/) | здесь |
| Быстро проверить один порт | `Test-NetConnection адрес -Port номер` | средство ОС |
| Что слушает сама станция | `netstat -ano` | средство ОС |
| MAC-адреса соседей, поиск дублей | `arp -a` | средство ОС |

`Advanced IP Scanner` закрывает инвентаризацию, и ставить рядом ещё один
сканер узлов смысла нет. Nmap нужен именно за порты и версии служб — этого в
Strelec нет.

## Типовые сценарии

| Ситуация | Чем |
|----------|-----|
| «В сети тормозит, надо понять кто» | `Advanced IP Scanner` — список, дальше по подозрительным |
| «Не работает сетевая папка» | `Test-NetConnection -Port 445`, потом `nmap -p 445` |
| «Роутер торчит наружу?» | `nmap -F` на внешний адрес роутера |
| «Найти IP устройства без экрана» | `Advanced IP Scanner` до и после подключения устройства |
| «Что это за устройство в сети» | `nmap -sV` — по открытым портам часто виден тип |
| «Проверить, что межсетевой экран закрыл нужный порт» | `nmap -p список` до и после |

## Порядок

1. Сначала пассивно: `arp -a` и `Advanced IP Scanner`. Никаких пакетов, никого
   не тревожим.
2. Потом точечно: конкретный адрес и конкретный порт.
3. Широкое сканирование — только с разрешения и только после предупреждения.

## Правила

> **Сканировать только с разрешения владельца сети.** Фиксировать разрешение в
> заявке. Сканирование чужой сети может быть расценено как попытка
> несанкционированного доступа.

> Активное сканирование видно в журналах межсетевого экрана и может поднять
> тревогу у службы безопасности заказчика. Предупреждать до начала.

> Не сканировать сегменты, принадлежащие не заказчику. В многоквартирном доме
> или бизнес-центре соседняя сеть может оказаться в том же широковещательном
> домене.

> Полное сканирование `-p-` по сегменту с IoT-устройствами может их
> перезагрузить или вывести из строя. Начинать с `-F`.

## Не проверено на месте

| Пункт | Что нужно |
|-------|-----------|
| Работа Nmap в WinPE Strelec без Npcap | Проверить в выезде: TCP-connect может работать и без драйвера |
| Реакция типовых домашних роутеров на `-sV` | Наблюдение на месте |
