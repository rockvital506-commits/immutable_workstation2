# network/ — группа «Сеть»

Диагностика сети, замер скорости, сканирование, Wi-Fi, удалённый доступ.
Группа наполняется на Этапе 4.4.

## Подкатегории

| Подкатегория | Что закрывает | Статус |
|--------------|---------------|--------|
| `diagnostics/` | Пинг, трассировка, DNS, проверка маршрута | пусто |
| `speed/` | Замер пропускной способности, iperf | пусто |
| `scan/` | Поиск узлов и открытых портов в сегменте | пусто |
| `wifi/` | Анализ эфира, каналы, уровень сигнала | пусто |
| `remote/` | Удалённый доступ к станциям заказчика | пусто |
| `capture/` | Перехват и разбор трафика | пусто |

запускаться **из живой ОС** без перезагрузки в WinPE.
