## Как получить

Официальный релиз `esnet/iperf` **не содержит сборок под Windows** — только
`iperf-3.22.tar.gz` (849295 байт) и файл `.sha256` к нему. Проверено через API
GitHub: ассетов ровно два.

Готовые бинарники берём из `ar51an/iperf3-win-builds`, релиз `3.22` от
2026-09-30. Состав релиза:

| Ассет | Размер | Когда |

| `iperf-3.22-win64.zip` | 1209932 | Обычная 64-битная станция |

## Проверка подлинности

После скачивания вычислить SHA256 и внести вместо `PENDING`:

```powershell
Get-FileHash -Algorithm SHA256 "E:\tools\network\speed\iperf3\iperf-3.22-win64.zip"
```

```bash
sha256sum "/mnt/tools/network/speed/iperf3/iperf-3.22-win64.zip"
```

Размеры сверены через API GitHub. Контрольную сумму сверить с ассетом релиза.
