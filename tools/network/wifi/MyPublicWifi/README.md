# MyPublicWifi

## Назначение

Точка доступа Wi-Fi на станции или ноутбуке мастера. Нужна там, где встроенный
«Мобильный хот-спот» Windows **не запускается**, — а он не запускается без
подключения к интернету.

> **Статус: внедрена условно.** Версия, подпись и условия лицензии по
> первоисточнику **не проверены** — официальный сайт недоступен из рабочей
> среды. До проверки на месте утилита не считается доверенной.

## Когда применять

- Интернета на объекте нет, а локальная сеть между устройствами нужна.
- Надо проверить роутер заказчика в изолированной тестовой сети, не трогая его
  конфигурацию.
- Надо дать диагностическому планшету или телефону управляемый доступ к станции
  без кабеля.
- Встроенный хот-спот Windows выдаёт «Не удаётся настроить мобильный
  хот-спот».

## Запуск

Инсталлятор. После установки **требуется перезагрузка** — это отмечено в
описаниях утилиты и это её главный минус в выезде: перезагрузить станцию
заказчика посреди работы не всегда можно.

- Требуются права администратора: **да**
- Работает из-под WinPE: **нет**
- Работает с флешки без установки: **нет**, только установка
- Требует .NET / VC++ Redist: по описаниям — нет

## Ключи и типовые сценарии

Графический интерфейс, ключей командной строки в описаниях нет.

| Задача | Где |
|--------|-----|
| Поднять точку доступа | SSID, пароль от 8 символов, WPA2, выбор раздаваемого подключения |
| Видеть клиентов | Вкладка с IP, MAC и именем устройства |
| Ограничить скорость | Bandwidth Manager, отдельно загрузка и отдача |
| Ограничить число клиентов | Настройка максимального количества |
| Запретить клиентам доступ в локальную сеть | Отдельный переключатель |
| Пробросить порт | Port forwarding |
| Подключить устройство по QR | Поддержка QR-кода |

Заявлены режимы **WiFi Direct** и **Hosted Network** для Windows 10/11. Именно
WiFi Direct важен: классический hosted network на современных адаптерах,
включая Intel AX211, обычно не поддерживается.

## Результаты и как их читать

Список клиентов с IP, MAC и именем устройства. При включённом журнале —
текстовый файл с действиями. **Журнал URL не включать**, см. риски.

## Риски и предупреждения

> **URL-журналирование своих устройств допустимо, чужих — нет.** Прежний
> запрет был абсолютным и обоснован тем, что запись посещённых клиентом
> адресов — обработка персональных данных, а у выездного мастера нет ни
> согласия клиента, ни правового основания (решение от 2026-10-10).
>
> С 2026-10-16 профиль некоммерческий: сеть своя, и журнал своих собственных
> устройств — это свои же данные. Основание запрета изменилось, а не исчезло:
> он остаётся в силе для **любых чужих устройств** в этой сети — домашних,
> гостевых, любых, чьи владельцы согласия не давали. Запись их адресов — та же
> обработка персональных данных, что и прежде.
>
> Практически: включать журналирование только в изолированной тестовой сети,
> где кроме своих устройств никого нет.

> Блокировку социальных сетей не включать для чужих устройств по той же
> причине. Для своих — вопрос не правовой, а практический.

> **Подпись и лицензия не проверены по первоисточнику.** Версия 31.3
> подтверждена `fileeagle.com`, `download.it`, `filehorse.com`, `filecr.com`
> и `softradar.com`, размер файла 4.85 МБ совпадает с нашей оценкой. Сайт
> `mypublicwifi.com`
> недоступен из рабочей среды (`http=000`). Каталоги дают 30.1, 31.2 и 31.3;
> разработчик указан то как «TRUE Software», то как «MyPublicWiFi Team».
> Проверить на официальном сайте до записи на флешку.

> Требуется перезагрузка после установки. Планировать так, чтобы не сорвать
> основную работу.

> Два средства создания виртуальной точки доступа одновременно не работают:
> возникает конфликт выделения адресов. Перед запуском отключить встроенный
> хот-спот и другие аналогичные утилиты.

> Межсетевой экран стороннего антивируса может блокировать раздачу — при
> проблемах проверять его первым.

## Аналоги

| Утилита | Когда предпочесть |
|---------|-------------------|
| Встроенный «Мобильный хот-спот» | **Всегда, когда есть интернет.** Ничего не ставит, WPA2, до 8 клиентов, выбор диапазона |
| `netsh wlan set hostednetwork` | Только если `netsh wlan show drivers` показывает `Hosted network supported: Yes` |
| Свой роутер из сумки | Надёжнее любой программной точки доступа, если есть физическая возможность |
| Раздача с телефона | Когда нужен именно интернет, а не локальная сеть |
