## Как получить

ZIP-архив с `nirsoft.net/utils/wifi_information_view.html`, есть варианты
x86 и x64. Портативный: распаковать и запустить, сканирование начинается само.

Версия 3.00 от 2026-06-10 — из поисковой выдачи по официальной странице
утилиты и по каталогам MajorGeeks и TechSpot. Требует Windows Vista и новее:
построена на новом Wi-Fi API.

## Проверка подлинности

После скачивания вычислить SHA256 и внести вместо `PENDING`:

```powershell
Get-FileHash -Algorithm SHA256 "E:\tools\network\wifi\WifiInfoView\wifiinfoview-x64.zip"
```

```bash
sha256sum "/mnt/tools/network/wifi/WifiInfoView/wifiinfoview-x64.zip"
```

Контрольную сумму сверить при скачивании. Архив должен содержать полный
набор файлов без изменений — условие лицензии NirSoft.

## Напоминание про лицензию NirSoft

Утилита freeware, её **можно** использовать в профессиональной работе. Но
лицензия запрещает продавать её и включать в состав коммерческого продукта,
а распространять разрешает только полным набором файлов без изменений.
Раздавать её клиентам как часть платного продукта нельзя.

Отдельно проверить состав `NirLauncher 1.23.67` в Strelec — возможно, утилита
уже там.
