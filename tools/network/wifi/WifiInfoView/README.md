# WifiInfoView

## Назначение

Пассивное сканирование эфира: какие точки доступа видны, на каких каналах они
сидят, какой у них уровень сигнала, кто производитель и сколько клиентов
подключено. Ничего не передаёт и не подключается — только слушает.

## Когда применять

- Жалоба «Wi-Fi работает плохо». Первое действие — посмотреть каналы и соседей.
- Выбор канала для роутера заказчика: найти наименее занятый.
- Поиск своей точки доступа, когда SSID скрыт или их много.
- Определение модели роутера по MAC-адресу и данным вендора.
- Проверка, добивает ли сигнал до нужной комнаты.
- Проверка, что после настройки роутера соседние сети не мешают больше, чем
  раньше.

## Запуск

Распаковать и запустить. Сканирование начинается само, без настройки.

```
E:\tools\network\wifi\WifiInfoView\WifiInfoView.exe
```

- Требуются права администратора: **нет**
- Работает из-под WinPE: **зависит от наличия Wi-Fi API в сборке**
- Работает с флешки без установки: **да**, портативный ZIP
- Требует .NET / VC++ Redist: **нет**

## Ключи и типовые сценарии

Графический интерфейс, но есть параметры командной строки для выгрузки.

| Задача | Команда |
|--------|---------|
| Выгрузить в CSV | `WifiInfoView.exe /scomma report.csv` |
| Выгрузить в HTML | `WifiInfoView.exe /shtml report.html` |
| Выгрузить в текст | `WifiInfoView.exe /stext report.txt` |
| Свой файл конфигурации | `WifiInfoView.exe /cfg путь` |
| Выбор адаптера | Клавиша F9, окно дополнительных параметров |
| Сводка по каналам | Режим BSS Type Summary |

## Результаты и как их читать

Верхняя панель — список сетей. Нижняя — информационные элементы выбранной сети
в шестнадцатеричном виде.

| Поле | Как использовать |
|------|------------------|
| `SSID` / `MAC Address` | Идентификация точки |
| `RSSI` | Уровень сигнала. Ближе к нулю — лучше; ниже −75 дБм связь ненадёжна |
| `Signal Quality` | То же в процентах, удобнее для разговора с заказчиком |
| `Channel` | Главный инструмент: найти канал, где соседей меньше |
| `PHY Type` | 802.11n / ac / ax. Показывает, на что реально способен роутер |
| `Maximum Speed` | Заявленная скорость канала |
| `Company Name` | Вендор по MAC-адресу |
| `Router Model` / `Router Name` | Только если роутер их отдаёт |
| `Stations Count` | Сколько клиентов на точке. Только при наличии `BSS Load` |

Режим сводки группирует сети по каналу, вендору, типу PHY или максимальной
скорости — это самый быстрый способ увидеть занятость диапазонов.

## Риски и предупреждения

> **Проверить состав `NirLauncher 1.23.67` в Strelec до записи на флешку.**
> Утилиты NirSoft обычно входят в этот набор, и тогда отдельная копия на
> разделе Tools избыточна. Правило «не дублировать Strelec».

> Требуется Windows Vista и новее: утилита построена на новом Wi-Fi API. На
> Windows XP не работает вообще.

> `Stations Count` доступен только для точек, отдающих `BSS Load`. Пустое поле
> — не ошибка.

> Модель и имя роутера заполняются, только если точка их транслирует. Пустое
> поле означает, что роутер их не отдаёт.

> Лицензия freeware разрешает использовать утилиту в профессиональной работе,
> но запрещает продавать её и включать в состав коммерческого продукта.
> Распространять можно только полным набором файлов без изменений. Раздавать
> клиентам как часть платного продукта нельзя.

**Откуда ожидаемая сумма.** Манифест пакета `NirSoft.WifiInfoView` версии `3.00` в
репозитории `microsoft/winget-pkgs`, поле `InstallerSha256`; URL в манифесте
совпадает с нашим. Это сторонний каталог по правилу §4, а не сайт вендора,
поэтому источник указан явно. Версия пакета совпадает с нашей, поэтому сумма
относится именно к нашему файлу. Прочитано через `api.github.com`
2026-10-16: `raw.githubusercontent.com` из рабочей среды недоступен.

**Почему строка остаётся `planned`.** Сумма известна, а размер — нет:
`манифест WinGet` размера не содержит, сайт вендора вне белого списка рабочей среды, а
сторонние каталоги дают противоречащие числа: `wifiinfoview-x64.zip` в каталогах около 486 КБ. Заполнять `size_bytes`
числом без источника §4 запрещает, поэтому строка остаётся `planned` с этой
причиной. Размер появится после скачивания файла — вместе со сверкой суммы.

**Второй источник разошёлся, и это полезно знать.** Scoop-бакет
`kodybrown/scoop-nirsoft` хранит сумму
`e9d0ee4d941764eace0ea34d2299714d38393d030a6019b08e14df2533ff8c12` — но она
относится к версии **2.93**, тогда как в манифесте того же бакета стоит
`"version": "2.93"` при нашей 3.00. Бакет отстал от сайта NirSoft, поэтому его
сумма к нашему файлу неприменима. Расхождение снято выбором источника, у
которого версия совпадает.
**Версия не сверена с первоисточником напрямую**: `nirsoft.net` недоступен из
рабочей среды (`http=000`). Версия 3.00 от 2026-06-10 подтверждена поисковой
выдачей по официальной странице утилиты, где приведён текст лицензии, и двумя

Автор — Nir Sofer. Формулировка лицензии взята с официальной страницы через
поисковую выдачу.
