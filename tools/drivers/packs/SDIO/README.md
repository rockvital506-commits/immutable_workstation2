# SDIO — Snappy Driver Installer Origin

## Назначение

Подбирает и ставит драйверы по HWID устройства. Работает офлайн: паки лежат рядом с программой, интернет на станции заказчика не нужен.

Единственная утилита подкатегории [`../`](../) — и единственная в группе `drivers/`, кроме средств ОС.

## Почему SDIO, а не DriverPack Solution

| | SDIO (Origin) | DriverPack Solution |
|---|---|---|
| Лицензия | **GNU GPL v3.0** | Ad-Supported, закрытый код |
| Коммерческое использование | разрешено | не разобрано |
| Побочное ПО | нет: no ads, no bundled software | Opera, Firefox, Yandex, Avast, 360 Security — **по умолчанию** |
| Реакция антивирусов | — | помечается как PUP |
| Деинсталлятор | не нужен, портативная | своего нет |

Отвязать побочное ПО в DriverPack можно только в Expert Mode, а не в режиме по
умолчанию. Для мастера, который работает на чужой коммерческой машине, это
неприемлемо.

## Паки драйверов

Лежат отдельной сущностью — [`../SDIO-drivers/`](../SDIO-drivers/). Там же
разобран размер (источники дают от 15 до 55,8 ГБ, планировать от **50 ГБ**) и
вопрос свободного места на разделе Tools.

Сама программа занимает около 11 МБ; без паков она работает только онлайн,
скачивая индексы и нужные драйверы.

```
Tools:\drivers\packs\SDIO\
├── SDIO_x64.exe           распакованная программа, имя уточнить
└── drivers\               распакованные паки, каталог drivers/ рядом с программой
```

SDIO ищет паки в каталоге `drivers` рядом с исполняемым файлом.

## Порядок работы

1. Распаковать `SDIO_2.0.4.887.zip`, положить паки в `drivers\` рядом.
2. Запустить `SDIO_x64.exe` от имени администратора.
3. Дождаться индексации — при первом запуске на 50 ГБ это минуты.
4. **Снять галочки со всего лишнего.** SDIO предлагает не только драйверы:
   смотреть, что именно отмечено.
5. Ставить по одному устройству, а не «всё сразу».
6. После установки — `pnputil /enum-devices /problem`: список проблемных
   должен стать короче.

## Правила

> **Снимать галочки перед установкой.** SDIO может предложить обновить то, что
> работает. Обновление рабочего драйвера — необоснованное изменение чужой
> системы.

> **Не ставить из пака драйвер видео и чипсета ноутбука.** В паках
> универсальные версии, а у ноутбуков свои настройки питания и графики. Для
> них — сайт вендора.

> **Пак стареет.** Драйверы в нём заморожены на момент скачивания раздачи.
> Раз в несколько месяцев скачивать свежую раздачу, иначе пак начнёт ставить
> устаревшее.

> **50 ГБ на флешке — это 50 ГБ, которые не положить больше никуда.** Решение
> принято осознанно, но место на разделе Tools нужно проверить.

## Версия и источник

| Поле | Значение |
|------|----------|
| Версия | 2.0.4.887 — **не сверена с первоисточником** |
| Дата проверки версии | 2026-10-11 |
| Официальный сайт | https://www.glenn.delahoy.com/snappy-driver-installer-origin/ |
| SHA256 | `PENDING` |
| Лицензия | GNU GPL v3.0 — коммерческое использование разрешено |

Версия подтверждена тремя независимыми каталогами (MajorGeeks 2026-09-14,
Softpedia 2026-09-15, Chocolatey), но не первоисточником: официальный хостинг —
SourceForge, он недоступен, а на GitHub официального репозитория нет — поиск
API GitHub даёт только форки и темы.

**Лицензий две, а не одна.** Страница проекта на SourceForge в поле License
указывает: «Creative Commons Attribution License, GNU General Public License
version 3.0 (GPLv3)». GPL v3 относится к коду, CC BY — к данным проекта
(индексам и прочему содержимому). Запись «GNU GPL v3.0» в таблице выше
неполная.

**Что требует GPL v3 при распространении.** Вместе с бинарной копией должны
ехать текст лицензии и указание на исходный код. Мы распространяем копию —
флешка выезжает к заказчикам, поэтому при комплектовании рядом с
`SDIO_2.0.4.887.zip` надо положить `gpl-3.0.txt`. В самом архиве утилиты файл
лицензии обычно есть, но полагаться на это нельзя: в репозитории проекта он
лежит отдельным файлом `resources/gpl-3.0.txt`, то есть исходники его
содержат, а состав zip-архива из рабочей среды не проверить.

Платных редакций у SDIO нет — «no paid tiers, no trial periods, and no premium
features locked behind a paywall», проект живёт на пожертвования. Вопрос о
целесообразности бесплатной редакции решается однозначно.

## Аналоги

| Утилита | Когда предпочесть |
|---------|-------------------|
| `pnputil` | Драйвер уже есть в INF, ничего подбирать не нужно |
| `DISM /Add-Driver` | Нужно встроить драйвер в образ установщика |
| Драйверы из сборки станции | Станция известна — это надёжнее пака |
| DriverPack Solution | **Не использовать**: ставит побочное ПО по умолчанию |
