# SDIO-drivers — полный пак драйверов

## Назначение

Набор паков драйверов для Snappy Driver Installer Origin. Даёт ему работать
**без интернета на станции заказчика**: программа ищет устройства по HWID и
берёт драйвер из паков, лежащих рядом.

Отдельная сущность, а не часть [`../SDIO/`](../SDIO/), потому что живёт своей
жизнью: раздача обновляется независимо от версии программы, а занимает в
десятки раз больше места.

## Состав каталога

| Файл | Что это | В git |
|------|---------|-------|
| `Drivers.torrent` | Раздача с полным набором паков | заглушка `Drivers.torrent.md` |
| `README.md` | Этот файл | как есть |

После скачивания распакованное содержимое кладётся в каталог `drivers` рядом с
исполняемым файлом SDIO — иначе программа паки не увидит.

## Размер — источники расходятся

| Источник | Что утверждает |
|----------|----------------|
| `sdi-tool.org/download/` | Torrent · **50,0 ГБ**, версия 2.26.4 (R2604) |
| `snappydriverinstaller.com` | полная коллекция «up to 49 GB», торрент «~15+ GB» |
| `archive.org` (2024-04-17) | 55,8 ГБ, пак R2309 |
| `archive.org` (2018) | 16,3 ГБ, пак 18.08.2 |

Пак растёт со временем, поэтому все числа верны для своего момента.
**Планировать надо от 50 ГБ.** В исследовании Этапа 4.6 сначала фигурировали
25 ГБ — это была одна из оценок, а не факт; исправлено.

## Место на флешке

Раздел Tools — NTFS, 128,00 ГБ. Формат такой файл допускает, но **свободное
место нужно проверить до копирования**: сколько занято остальным, из рабочей
среды не видно. Решение положить полный пак принято заказчиком осознанно,
цена — около 15 % раздела Ventoy либо существенная часть Tools.

## Риски и предупреждения

> **Пак стареет.** Драйверы в нём заморожены на момент раздачи. Раз в
> несколько месяцев скачивать свежую, иначе пак начнёт ставить устаревшее.

> **Не ставить из пака драйвер видео и чипсета ноутбука.** В паках
> универсальные версии, а у ноутбуков свои настройки питания и графики.

> **Снимать галочки в SDIO перед установкой.** Программа предложит обновить и
> то, что работает.
