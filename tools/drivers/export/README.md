# export/ — средствами ОС, без утилит

**Утилит здесь нет и не нужно.** Всё делается `pnputil` и `DISM`, которые есть
в любой Windows и в WinPE Strelec.

> **База пути.** Непомеченные пути в этом документе считаются от каталога
> этого модуля. Пути от корня репозитория и пути на разделы флешки помечаются
> префиксами `CONVENTIONS.md` §10.1.

## Установка из INF

| Задача | Команда |
|--------|---------|
| Поставить все INF из каталога с подкаталогами | `pnputil /add-driver "E:\drivers\*.inf" /subdirs /install` |
| Поставить один INF | `pnputil /add-driver "E:\drivers\netwtw08.inf" /install` |
| Поставить даже если подходящий уже есть | добавить `/force` |
| Перечислить сторонние пакеты | `pnputil /enum-drivers` |
| Найти проблемные устройства | `pnputil /enum-devices /problem` |
| Найти устройство по HWID | `pnputil /enum-devices /deviceid "PCI\VEN_8086&DEV_51F0"` |
| Удалить драйвер | `pnputil /delete-driver oem12.inf /uninstall` |
| Удалить и удалить файлы | добавить `/force` |

Номера `oem<NN>.inf` берутся из `pnputil /enum-drivers`.

## Выгрузка драйверов

| Задача | Команда |
|--------|---------|
| Из работающей ОС | `DISM /Online /Export-Driver /Destination:"E:\drivers\export"` |
| Из образа или подключённого раздела | `DISM /Image:"E:\mount" /Export-Driver /Destination:"E:\drivers\export"` |
| В WinPE, когда система не грузится | то же самое с `/Image:` |

## Интеграция в образ установщика

| Задача | Команда |
|--------|---------|
| Подключить install.wim | `DISM /Mount-Image /ImageFile:"D:\sources\install.wim" /Index:1 /MountDir:"E:\mount"` |
| Добавить драйверы | `DISM /Image:"E:\mount" /Add-Driver /Driver:"E:\drivers" /Recurse` |
| Только для проблемных устройств | добавить `/ForceUnsigned` не нужно, а вот `/Recurse` обязателен для дерева каталогов |
| Отключить | `DISM /Unmount-Image /MountDir:"E:\mount" /Commit` |

Это путь «подсунуть драйвер накопителя в установщик», когда `VMD controller`
включён в BIOS и установщик не видит NVMe. Второй путь — нажать F6 в
установщике и указать флешку с INF. Третий — отключить VMD в BIOS.

## Связь с бэкапом

`export-drivers` в
[`../../backup/initial_backup/`](../../backup/initial_backup/) делает то же
самое — выгрузку драйверов, но как часть бэкапа станции перед переустановкой.
Разница в назначении:

| | `backup/initial_backup/export-drivers` | `drivers/export/` |
|---|---|---|
| Зачем | Сохранить набор драйверов станции перед сносом ОС | Поставить драйверы и выгрузить их для повторного использования |
| Когда | До переустановки | Когда угодно, в том числе в WinPE |
| Результат | Каталог в бэкапе | Каталог на флешке |

Дублирования нет: скрипт один, сценариев два.

## Порядок

1. `pnputil /enum-devices /problem` — что не работает.
2. Если станция известна — драйверы из её сборки в
   [`../../../ventoy-partition/builds/`](../../../ventoy-partition/builds/).
3. Если нет — [`../packs/`](../packs/).
4. Установка через `pnputil /add-driver ... /install`.
5. Повторный `pnputil /enum-devices /problem` — список должен стать короче.
6. Проверить, что устройство **работает**, а не просто перестало быть
   проблемным.

## Правила

> **Проверять результат устройством, а не отсутствием ошибки.** Устройство
> может исчезнуть из списка проблемных и при этом не работать: например, Wi-Fi
> определился, а сеть не поднимается.

> **Не удалять драйвер, не убедившись, что он не используется.**
> `pnputil /delete-driver` с `/force` на нужном драйвере оставляет станцию без
> устройства до следующего выезда.

> **`/Recurse` обязателен** при добавлении дерева каталогов в образ: без него
> `DISM` возьмёт только INF из корневого каталога.

## Скрипт интеграции

Добавление отобранного дерева драйверов в образ или в установленную систему —
пара скриптов:

- [`scripts/integrate-drivers.sh`](scripts/integrate-drivers.sh)
- [`scripts/integrate-drivers.ps1`](scripts/integrate-drivers.ps1)

Оба оборачивают `DISM /Add-Driver /Recurse` (в PowerShell — `Add-WindowsDriver`),
считают INF в источнике, пишут лог и различают коды возврата: `0` успех, `1`
ошибка аргументов, `2` нет прав или DISM, `3` источник или образ недоступны.
Есть `--dry-run` / `-WhatIf`.

> **Скрипт ставит только драйверы.** Обновлений Windows в нём нет намеренно —
> решение заказчика от 2026-10-14. Драйвер снимается через
> `pnputil /delete-driver`, обновление с SSU не удаляется вовсе, и порядок
> отката у них разный. Совмещать их в одном скрипте нельзя. Обоснование —
> [`../../../research/13-offline-updates.md`](../../../research/13-offline-updates.md).

Процедура офлайн-обновлений — отдельно:
[`../../os/windows/updates/offline-procedure.md`](../../os/windows/updates/offline-procedure.md).
