# CrystalDiskInfo

## Назначение

Показывает S.M.A.R.T., температуру и состояние накопителей в виде
человекочитаемой карточки с вердиктом «Хорошо / Тревога / Плохо». Нужна,
когда результат надо показать заказчику на экране, а не в логе.

## Когда применять

- Быстрая оценка здоровья диска при первом осмотре станции.
- Показать заказчику, почему диск надо менять — вердикт и атрибуты нагляднее
  вывода `smartctl`.
- Температура накопителя под нагрузкой.
- USB-накопители и внешние боксы.

## Запуск

```
CrystalDiskInfo9_9_2.zip  →  распаковать  →  DiskInfo64.exe
```

- Требуются права администратора: **да** для полного доступа к SMART
- Работает из-под WinPE: **да**, но в сборке Strelec уже есть своя копия
- Работает с флешки без установки: **да**, это портативная версия
- Требует .NET / VC++ Redist: **нет**

## Ключи и типовые сценарии

Утилита графическая, но поддерживает ключи:

| Задача | Действие |
|--------|----------|
| Открыть на конкретном диске | выбрать диск в верхней панели |
| Сохранить отчёт в файл | меню «Файл» → «Сохранить» → текст или JSON |
| Все атрибуты разом | «Сервис» → «Копировать» → весь вывод в буфер |
| Автообновление | «Функции» → интервал обновления |
| Единицы и язык | «Функции» → «Язык» → Русский |

Для автоматизации отчётов предпочтительнее `smartctl` — он пишет в файл одной
командой без кликов.

## Результаты и как их читать

| Вердикт | Что означает |
|---------|--------------|
| **Хорошо** | Атрибуты в норме |
| **Тревога** | Есть атрибут выше порога — диск доживает, данные спасать |
| **Плохо** | Диск отказывает, работы только через образ |

Смотреть в первую очередь: `05 Reallocated Sectors Count`,
`C5 Current Pending Sector Count`, `C6 Uncorrectable Sector Count`,
`C7 UltraDMA CRC Error Count`, `BB Reported Uncorrectable Errors` (SSD).
Для SSD дополнительно — `Total Host Writes` и остаток ресурса в процентах.

## Риски и предупреждения

> Утилита только читает. Но «Хорошо» — не разрешение на рискованные операции:
> при переразметке всё равно сначала снимается образ.

> Версии с суффиксом **Shizuku Edition** отличаются только оформлением.
> Для рабочей флешки брать обычную.
