## Как получить

Скачать ZIP-архив портативной версии (не `.exe`-установщик) с SourceForge или
из релизов GitHub, распаковать в каталог на флешке.

## Проверка подлинности

Релизы на GitHub сопровождаются подписями. Для файлов с SourceForge сверять
хэш с опубликованным на странице релиза.

## Куда положить на флешке

`Tools:\diagnostics\disk\CrystalDiskInfo\` — распакованным каталогом, чтобы
запускать `DiskInfo64.exe` без распаковки в выезде.
