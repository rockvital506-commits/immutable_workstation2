# smartmontools

## Назначение

`smartctl` и `smartd` — чтение S.M.A.R.T. с ATA/SATA, SCSI/SAS и NVMe
накопителей из командной строки. Закрывает задачу «получить состояние диска
текстом, пригодным для отчёта и для сравнения между визитами».

## Когда применять

- Нужен SMART в файл, а не на экран — отчёт заказчику, история наблюдений.
- Надо сравнить состояние диска до работ и после.
- Накопитель NVMe: у `smartctl` есть NVMe self-test и `Protocol Specific`
  данные, которых нет у части GUI-утилит.
- Станция работает, перезагружаться в WinPE нельзя.

## Запуск

```
smartmontools-7.5.win32-setup.exe /S
```

`/S` — тихая установка (NSIS). После установки `smartctl.exe` и `smartd.exe`
лежат в `C:\Program Files\smartmontools\bin`.

- Требуются права администратора: **да**
- Работает из-под WinPE: **да, при наличии бинарников** — в сборке Strelec
  smartmontools отсутствует, нужно носить с собой
- Работает с флешки без установки: **да**, если распаковать `bin` рядом
- Требует .NET / VC++ Redist: **нет**

## Ключи и типовые сценарии

| Задача | Команда |
|--------|---------|
| Весь SMART по диску | `smartctl -a \\.\PhysicalDrive0` |
| Расширенный вывод (NVMe, SATA-логи) | `smartctl -x \\.\PhysicalDrive0` |
| Только состояние одной строкой | `smartctl -H \\.\PhysicalDrive0` |
| Все атрибуты и пороги | `smartctl -A \\.\PhysicalDrive0` |
| Лог ошибок | `smartctl -l error \\.\PhysicalDrive0` |
| Запустить короткий самотест | `smartctl -t short \\.\PhysicalDrive0` |
| Запустить длительный самотест | `smartctl -t long \\.\PhysicalDrive0` |
| Результат самотеста | `smartctl -l selftest \\.\PhysicalDrive0` |
| Температура NVMe | `smartctl -a \\.\PhysicalDrive0 \| findstr Temperature` |
| Список дисков | `smartctl --scan` |
| Диск за USB-мостом | `smartctl -d sat -a \\.\PhysicalDrive1` |

В Linux (Live Mint) устройство указывается как `/dev/nvme0n1`, `/dev/sda`.

## Результаты и как их читать

Ключевое для решения «менять диск или нет»:

| Атрибут | Норма | Тревога |
|---------|-------|---------|
| `Reallocated_Sector_Ct` (5) | 0 | любой рост |
| `Current_Pending_Sector` (197) | 0 | любой рост |
| `Offline_Uncorrectable` (198) | 0 | любой рост |
| `UDMA_CRC_Error_Count` (199) | 0 | рост — проблема кабеля/моста, не диска |
| `Power_On_Hours` (9) | — | наработка, сравнивать с гарантией |
| NVMe `Percentage Used` | < 90% | > 100% — ресурс выработан |
| NVMe `Available Spare` | выше порога | ниже порога — замена |
| `Temperature` | до 70 °C | выше — проверить охлаждение |

Строка `SMART overall-health self-assessment test result: PASSED` — это
самооценка диска, а не гарантия. Смотреть надо атрибуты.

## Риски и предупреждения

> `smartctl -t long` на HDD большого объёма идёт часами и нагружает диск.
> Не запускать на станции, которую надо вернуть сегодня.

> Запись на диск утилита не выполняет, но `-s on` включает SMART, а
> `-t` инициирует самотест силами самого накопителя.

> На диске с BitLocker чтение SMART доступно, но не путайте «SMART в порядке»
> с «том расшифрован».
