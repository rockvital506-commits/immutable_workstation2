## Как получить

На `mersenne.org/download/` взять пакет для **Windows 64-bit** в формате ZIP.
Существуют также 32-битный ZIP, сборки для Linux и macOS — для флешки нужен
именно win64 ZIP.

Имя файла содержит номер версии, поэтому при обновлении меняется и имя. После
обновления править и `/manifest.csv`, и имя заглушки.

## Проверка подлинности

Официальный источник один — `mersenne.org`. Сторонние каталоги загрузки для
этой утилиты использовать не следует: встречаются пересобранные пакеты.

## Куда положить на флешке

`Tools:\diagnostics\cpu\Prime95\` — распакованным каталогом.

использовала станцию заказчика для распределённых вычислений.
