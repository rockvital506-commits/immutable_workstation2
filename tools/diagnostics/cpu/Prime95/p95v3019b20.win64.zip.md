## Как получить

На `mersenne.org/download/` взять пакет для **Windows: 64-bit**, строка
30.19b20. Файл раздаётся через зеркало `download.mersenne.ca`, ссылка на
которое ведёт в Google Drive. Существуют также 32-битный ZIP, сборки для
Linux, macOS и FreeBSD, а также вариант `win64.service.zip` — для флешки
нужен именно `p95v3019b20.win64.zip`.

Имя файла содержит номер версии и сборки, поэтому при обновлении меняется и
имя. После обновления править и `/manifest.csv`, и имя заглушки.

## Проверка подлинности

Сумма опубликована самим вендором на странице загрузки, а не взята из
стороннего каталога:

```
MD5    7a4ac1f3ff0045951fe6ad66e36c7929
SHA1   51a5849e8652b69909cce28f1d5f5697d96c1571
SHA256 d9475f2ff3f4a6a701abc49a86a66126cb48abd10bda6fa87039d98fa8756bca
```

MD5 независимо подтверждён листингом зеркала
`download.mersenne.ca/gimps/v30/30.19/`, где для этого файла указаны те же
`7a4ac1f3ff0045951fe6ad66e36c7929` и размер 8 805 545 байт. Совпадение MD5 и
размера в двух источниках означает, что страница загрузки и зеркало говорят
об одном и том же дистрибутиве.

После скачивания вычислить SHA256 и сверить:

```powershell
Get-FileHash -Algorithm SHA256 "E:\tools\diagnostics\cpu\Prime95\p95v3019b20.win64.zip"
```

```bash
sha256sum "/mnt/tools/diagnostics/cpu/Prime95/p95v3019b20.win64.zip"
```

Официальный источник один — `mersenne.org` и его зеркало. Сторонние каталоги
загрузки для этой утилиты использовать не следует: встречаются пересобранные
пакеты.

## Почему 30.19, а не более новая линия v31

Решение владельца от 2026-10-21. Обстоятельства выбора записаны в
`research/24-next-steps.md`, пункт A5: линия v31 существует и доходит до
31.07 build 2, но страница загрузки вендора называет последней именно
30.19 build 20, а для сборок v31 зеркало публикует только MD5. Выбор
стабильной ветки даёт проверяемую SHA256 ценой более старой версии.
