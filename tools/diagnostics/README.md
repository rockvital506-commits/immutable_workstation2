# diagnostics/ — группа «Диагностика»

Диагностика железа и накопителей. Группа построена по принципу разделения
сред, а не по принципу «сложить всё сюда».

## Принцип: что где лежит

| Среда | Где живёт | Когда |
|-------|-----------|-------|
| **Strelec WinPE** | ISO в `ventoy-partition/ISO/winpe/` | Нужна перезагрузка, доступ к диску вне ОС, доска ещё не грузится, надо снять SMART/температуры до вмешательства |
| **Портативные утилиты** | эта группа на разделе `Tools` | Станция работает в своей ОС, перезагрузка недопустима или нежелательна; нужен лог в файл для отчёта |
| **Live Linux Mint** | ISO + persistence | Нужны `nvme-cli`, `smartctl`, `sensors`, `stress-ng` без установки в целевую ОС |

> **Правило: не дублировать Strelec.** Всё, что уже есть в сборке, на раздел
> `Tools` второй копией не кладётся. Состав сборки — в
> [`strelec-tools.md`](strelec-tools.md).

## Подкатегории

| Подкатегория | Содержимое | Состав |
|--------------|-----------|--------|
| `disk/` | Накопители: SMART, поверхность, температура | `smartmontools`, `CrystalDiskInfo` |
| `memory/` | Оперативная память | `MemTest86Plus` |
| `cpu/` | Стресс-тесты CPU и подсистем | `Prime95`, `stress-ng` |

## Чего здесь сознательно нет

| Утилита | Причина |
|---------|---------|
| Victoria | Уже в Strelec 5.37, включая DOS-вариант 3.52 |
| HWiNFO64 | Уже в Strelec (8.34 в сборке 2026.02.05). Отдельно — **запрещена в коммерции** без Engineer/Corporate лицензии |
| OCCT | Уже в Strelec (10.0.5). Personal-редакция **запрещена в коммерции** |
| AIDA64, CPU-Z, HD Tune, HDDScan, Hard Disk Sentinel | Уже в Strelec |
| LinX, Linpack Xtreme, BurnInTest, PerformanceTest | Уже в Strelec |
| MemTest86 (PassMark) | Уже в Strelec как UEFI/DOS-вариант 11.5.1000; free-редакция урезана |

## Лицензии — сводка по коммерческому выезду

Профиль работ — выездной мастер, то есть коммерческое использование. Это
ограничивает выбор сильнее, чем кажется.

| Утилита | Коммерческое использование |
|---------|---------------------------|
| smartmontools | Разрешено, GPL-2.0 |
| CrystalDiskInfo | Разрешено, MIT |
| MemTest86+ | Разрешено, GPL v2 |
| Prime95 | Freeware |
| stress-ng | Разрешено, GPL v2 |
| Victoria | Freeware, hdd.by |
| **HWiNFO64 (не-Pro)** | **Запрещено** — только 14 дней оценки; нужен Engineer/Corporate |
| **HWiNFO32 / HWiNFO for DOS** | **Разрешено** — freeware |
| **OCCT Personal** | **Запрещено** — нужен Pro/Enterprise |
| MemTest86 (PassMark) Free | Урезанная редакция: нет PXE, нет загрузки с floppy, нет старых BIOS |

Если в работе нужны HWiNFO64 или OCCT — использовать **из Strelec**, где они
уже лежат, либо приобрести лицензию. Класть их на раздел `Tools` отдельными
копиями смысла нет.

## Порядок применения на станции

| Задача | Инструмент | Среда |
|--------|-----------|-------|
| Быстро посмотреть SMART | `smartctl -a` | живая ОС / Mint / Strelec |
| SMART в отчёт заказчику | `smartctl -x > reports\smart.txt` | живая ОС |
| Температура NVMe | `smartctl -a` или `nvme smart-log` | живая ОС / Mint |
| Тест поверхности HDD | Victoria 5.37 | Strelec |
| Оценка износа SSD | CrystalDiskInfo / `smartctl` | любая |
| Проверка ОЗУ | MemTest86+ 8.10 | перезагрузка, UEFI/DOS |
| Стресс CPU на живой ОС | Prime95 Blend | живая ОС |
| Стресс CPU/памяти/IO в Linux | `stress-ng` | Live Mint |
| Полный осмотр железа | AIDA64 / HWiNFO | Strelec |
