## Как получить

На `memtest.org` в разделе Download выбрать **Linux ISO (64 bits)** — это
обычный загрузочный ISO, который понимает Ventoy. Другие варианты:

| Вариант | Когда нужен |
|---------|-------------|
| Windows USB Installer | Запись на отдельную флешку мимо Ventoy — **не наш случай** |
| Linux ISO (64 bits) | **нужен этот**, кладётся в `ISO/diagnostics/` |
| Linux ISO (32 bits) | Старые станции без x64 |
| Linux ISO w/ GRUB (64 bits) | Если Ventoy не подхватит обычный ISO |
| Binary files | PXE и chainloading |

После скачивания переименовать файл в `mt86plus_8.10.iso`, если имя другое, и
записать фактическое имя в `/manifest.csv`.

## Проверка подлинности

Сайт публикует MD5, SHA256 и SHA512 для каждой сборки. Сверить перед записью.

## Куда положить на флешке

`Ventoy:\ISO\diagnostics\mt86plus_8.10.iso`

В `ventoy.json` добавить `menu_alias`, чтобы в меню Ventoy пункт назывался
понятно, например `MemTest86+ 8.10 — тест ОЗУ`.
