# MemTest86+

## Назначение

Автономный тест оперативной памяти, работающий вне операционной системы.
Проверяет ОЗУ алгоритмами, недоступными из-под Windows, потому что ОС не может
достоверно протестировать память, которую сама же использует.

## Когда применять

- Синие экраны, самопроизвольные перезагрузки, повреждение архивов.
- Станция после падения или перевозки.
- Перед миграцией ОС: ошибка памяти на этапе установки даёт непредсказуемый
  результат, и искать потом придётся не там.
- Проверка XMP/EXPO-профилей и разгона.

Для станции MSI Modern 15 B12M-211RU: память **распаяна**, 8 ГБ DDR4-3200,
добавить или заменить модули нельзя. Ошибка памяти здесь означает ремонт
платы, а не замену планки — поэтому тест обязателен до любых работ.

## Запуск

Ventoy → пункт `MemTest86+ 8.10` → старт. Тест начинается автоматически.

- Требуются права администратора: **нет**, ОС не используется
- Работает из-под WinPE: **нет**, это самостоятельная загрузка
- Работает с флешки без установки: **да**, через Ventoy
- Требует .NET / VC++ Redist: **нет**

Поддерживаются и UEFI, и legacy BIOS. Есть отдельные сборки x86 и x64; для
современных станций — x64.

## Ключи и типовые сценарии

Управление с клавиатуры во время теста:

| Клавиша | Действие |
|---------|----------|
| `Esc` | Выйти и перезагрузиться |
| `Space` | Пауза / продолжить |
| `c` | Настройка: число проходов, диапазон адресов, выбор ядер |
| `1`–`9` | Запустить конкретный тест |

| Задача | Действие |
|--------|----------|
| Полная проверка | 4 полных прохода, это несколько часов |
| Быстрая оценка | 1 проход |
| Проверка конкретного диапазона | `c` → задать начало и конец |
| Только подозрительная область | `c` → сузить диапазон |

## Результаты и как их читать

| Результат | Что делать |
|-----------|-----------|
| `Errors: 0` после 4 проходов | Память исправна |
| Любая ошибка | Память неисправна. Работы на станции прекращаются |
| Ошибки только в одном тесте | Всё равно брак — разные тесты ловят разные дефекты |
| Ошибки плавают по адресам | Дефект контроллера памяти или питания, не только чипов |

Ноль ошибок за один проход — **не** доказательство исправности. Дефекты часто
проявляются на прогреве, поэтому проходов нужно минимум четыре.

## Риски и предупреждения

> Тест идёт часами. Планировать выезд с учётом этого или оставлять станцию
> на ночь.

> Во время теста станция недоступна ни для чего другого.

> На гибридных CPU (P- и E-ядра) часть тестов может вести себя иначе; версия
> 8.10 содержит исправления для таких процессоров, включая Intel Panther Lake.

> Ошибка памяти делает недостоверными **все** остальные проверки на этой
> станции, включая тест поверхности диска. Поэтому память проверяется первой.
