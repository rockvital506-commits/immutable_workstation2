# memory/ — проверка оперативной памяти

## Состав

| Утилита | Версия | Среда | Лицензия |
|---------|--------|-------|----------|
| [`MemTest86Plus/`](MemTest86Plus/) | 8.10 | Загрузка через Ventoy, UEFI и BIOS | GPL v2 |

## Почему память проверяется первой

Ошибка памяти делает недостоверными все остальные проверки на станции: тест
поверхности диска даст ложные bad-блоки, установка ОС завершится
непредсказуемо, а поиск причины уведёт не туда. Поэтому тест ОЗУ — до
переразметки и до установки.

## Порядок

1. Загрузиться через Ventoy → MemTest86+ 8.10.
2. Минимум **4 полных прохода**. Один проход не доказывает исправность:
   дефекты проявляются на прогреве.
3. Результат сфотографировать или записать в `reports/` станции.
4. При любой ошибке — работы прекращаются, станция уходит в ремонт.

## Что уже есть в Strelec

| Утилита | Версия в сборке | Когда предпочесть |
|---------|-----------------|-------------------|
| MemTest86 | 11.5.1000 (UEFI) | Нужны ECC-инъекции; free-редакция урезана |
| Memtest86+ | 7.20 (UEFI/DOS) | Уже в Strelec, версия старше |
| GoIdMemory PRO | 7.85 | Нужен детальный отчёт по модулям |
| R.tester | 1.20.11.21 | Проверка из-под WinPE без перезагрузки |

Отдельная копия MemTest86+ на флешке оправдана версией: 8.10 против 7.20 в
сборке, с исправлениями для гибридных CPU и новых чипсетов.

## Особенность станции-референса

На MSI Modern 15 B12M-211RU память **распаяна**: 8 ГБ DDR4-3200, слотов нет.
Ошибка памяти означает ремонт платы, а не замену модуля. Апгрейд ОЗУ на этой
станции невозможен — это надо сообщать заказчику до начала работ.
