# drivers/ — экспорт и каталогизация драйверов

## Задача

Получить **чистые** драйверы рабочей машины до переустановки, без сторонних
драйвер-паков.

## Основной механизм

```powershell
# Из работающей ОС
DISM /Online /Export-Driver /Destination:<путь>

# Из WinPE — ключ /Online НЕ работает (Error 50)
DISM /Image:C:\ /Export-Driver /Destination:<путь>
```

DISM выгружает **только INF-пакеты**. EXE/MSI-установщики вендоров не
выгружаются — их нужно брать с сайта производителя отдельно.

Альтернативы: `pnputil /export-driver` (только online),
`Export-WindowsDriver` (PowerShell, online и offline).

## Что попадает в экспорт

Все сторонние пакеты из Driver Store, каждый — в подкаталог `oemNN.inf`.

## Чего в экспорте не будет

| Компонент | Причина |
|-----------|---------|
| Драйверы в составе Windows | Не являются сторонними |
| Утилиты вендоров (MSI Center, Intel DSA) | Это приложения, не драйверы |
| Прошивки устройств | Обновляются отдельно, через утилиты вендора |

## Правила

- Экспорт делается **до** любых операций с разделами.
- Результат сопровождается манифестом SHA256.
- Для конкретной станции копия кладётся в
  `ventoy-partition/builds/<станция>/drivers/`.
