# disk_image/ — образы дисков и разделов

## Инструмент

**Clonezilla Live** — `ocs-sr` поверх `partclone`. Копируются только занятые
блоки для поддерживаемых ФС, для неподдерживаемых — посекторно `dd`.
Поддерживаются MBR и GPT, загрузка в BIOS и UEFI.

## Скрипт

`scripts/disk-image.sh` — обёртка, которая:

1. проверяет, что устройство не смонтировано (Clonezilla не работает со
   смонтированным томом);
2. проверяет свободное место в назначении;
3. делает дамп GPT (`sgdisk --backup`) и MBR (`dd bs=512 count=1`);
4. снимает образ диска через `ocs-sr ... savedisk`;
5. строит манифест SHA256.

Дамп таблицы разделов — **обязательная** часть: без него восстановление на
другой геометрии превращается в ручную работу с `dd` и `sgdisk --load-backup`.

## Ключи ocs-sr, которые использует скрипт

| Ключ | Значение |
|------|----------|
| `-q2` | partclone |
| `-c` | восстановление с того же устройства |
| `-j2` | клонирование скрытых разделов |
| `-z9p` | многопоточное сжатие |
| `-i 4096` | размер блока |
| `-e1 auto` | создание ФС при восстановлении |
| `-e2` | — |
| `-r` | повторные попытки при ошибках чтения |
| `-p true` | выключиться после завершения |

## Особенности NVMe

В меню Clonezilla и в путях grub устройство — `nvme0n1`, а не `sda`.
Разделы — `nvme0n1p1`, `nvme0n1p2`, ...

## Ограничения Clonezilla

- Целевой раздел должен быть **не меньше** исходного.
- Инкрементальных и дифференциальных образов нет.
- Онлайн-клонирования нет — раздел обязан быть размонтирован.
- Из образа нельзя достать отдельный файл, образ не монтируется.
- BitLocker-том снимается через `dd` размером со весь том.

## Исключение из правила дуальности

`.ps1`-пары у `disk-image.sh` нет: `ocs-sr` существует только в Clonezilla Live.
