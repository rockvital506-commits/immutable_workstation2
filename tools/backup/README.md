# backup/ — группа «Резервное копирование»

Инструменты и модули снятия копий: образы дисков, экспорт драйверов, перенос
пользовательских данных.

## Подкатегории

| Подкатегория | Содержимое |
|--------------|-----------|
| `disk_image/` | Образы дисков и разделов, дампы MBR/GPT |
| `drivers/` | Экспорт и каталогизация драйверов |
| `profiles/` | Перенос профилей браузеров, редакторов, приложений |

## Состав

| Модуль | Назначение |
|--------|-----------|
| `initial_backup/` | Первоначальный бэкап станции перед любыми разрушающими действиями |

## Правило группы

Ни один скрипт этой группы **ничего не удаляет и не перезаписывает без явного
флага**. Бэкап — операция, после которой система обязана остаться в том же
состоянии, в котором была до неё.

Каждый бэкап сопровождается манифестом с SHA256 — иначе копия непроверяема.
