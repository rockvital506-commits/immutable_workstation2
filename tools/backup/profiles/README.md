# profiles/ — перенос профилей пользователей

Копии пользовательских данных: браузеры, редакторы, приложения.

## Состав

| Модуль | Скрипты | Что копирует |
|--------|---------|--------------|
| Профиль Chrome | `../initial_backup/scripts/backup-chrome.ps1` / `.sh` | `User Data` целиком: закладки, история, cookies, автозаполнение, настройки, расширения |
| Настройки VS Code | `../initial_backup/scripts/backup-vscode.ps1` | `%APPDATA%\Code\User` + `%USERPROFILE%\.vscode\extensions` + список расширений |

## Обязательные условия

1. **Приложение закрыто.** Базы SQLite при работающем приложении заблокированы,
   копия получается несогласованной. `backup-chrome.ps1` отказывается работать
   при запущенном Chrome (код возврата 4) — обход только через `-Force`.
2. **Копия проверена.** Каждая копия сопровождается `_manifest.sha256.csv`;
   проверка — `verify-backup.ps1` / `verify-backup.sh`.
3. **Пароли переносятся отдельно.** `Login Data` зашифрован DPAPI в контексте
   учётной записи и на другой машине не расшифруется. Только штатный экспорт.

## Структура копии

```
chrome_2026-10-07_12-00-00/
├── Default/                  профиль по умолчанию
├── Profile 1/                дополнительные профили
├── Local State               глобальное состояние Chrome
├── _manifest.sha256.csv      манифест целостности
└── _RESTORE_NOTES.md         порядок восстановления и ограничения
```

## Именование

`<приложение>_<ГГГГ-ММ-ДД_ЧЧ-ММ-СС>/` — временная метка исключает перезапись
предыдущей копии.
