# debloat/ — удаление предустановленного мусора

Снятие предустановленных приложений, отключение телеметрии и рекомендаций
системы. Первый этап настройки после установки драйверов, до подключения сети.

## Утилита

[`Win11Debloat/`](Win11Debloat/) — версия 2026.08.24, MIT, 102 параметра.

## Что закрывает и чем

| Задача | Механизм |
|--------|----------|
| Удаление предустановленных приложений | `Config\Apps.json`, 38616 байт, параметр `-RemoveApps` |
| Правки системы и интерфейса | 93 файла `.reg` в `Regfiles\`, описание в `Config\Features.json` |
| Откат отдельной правки | 65 файлов в `Regfiles\Undo\` |
| Телеметрия | `-DisableTelemetry`, включено по умолчанию |
| Точки восстановления | `-CreateRestorePoint`, включено по умолчанию |
| Бэкап реестра перед применением | Автоматически, отключается `-SkipRegistryBackup` |

## Особенность LTSC

Windows 11 IoT Enterprise LTSC 2024 поставляется **без большей части
потребительского мусора**: нет Widgets, Xbox, Teams, части рекламных
компонентов. Поэтому:

- список `Apps.json` отработает частично — это нормально, а не ошибка;
- правки, связанные с отсутствующими компонентами, ничего не изменят;
- основная работа здесь — телеметрия, рекомендации, поиск Bing, Copilot,
  автоустановка приложений производителя.

Фактический состав пакета в образе `f6b14814` **не проверен** — нужен
`Get-AppxProvisionedPackage -Online` на установленной системе.

## Порядок

1. Станция установлена, драйверы поставлены, **сеть отключена**.
2. Прогон с `-WhatIf` — прочитать, что изменится.
3. Реальный прогон. Точка восстановления и бэкап реестра создаются сами.
4. Проверка: приложения сняты, телеметрия отключена.
5. Только после этого — WinUtil и Sophia Script.

## Правила

> Сначала `-WhatIf`. Прогон вслепую на станции заказчика недопустим: часть
> правок затрагивает поведение, которое заказчик заметит сразу.

> `-SkipRegistryBackup` не использовать ни при каких обстоятельствах.

> Снятие приложения только для текущего пользователя без снятия
> provisioned-пакета приводит к тому, что приложение возвращается после
> обновлений. Проверять оба уровня.

> Приложения, установленные из Store в audit mode, ломают `sysprep` с ошибкой
> `0x80073cf2`. По официальной документации Microsoft: приложение,
> «установленное для пользователя, но не подготовленное для всех», не будет
> работать в образе. Audit mode на этой станции не используется, но правило
> стоит помнить при работе с эталонными образами.

> Не удалять компоненты, назначение которых неизвестно. Часть системных
> приложений нужна для работы Store, печати, медиакодеков.

## Не проверено на месте

| Пункт | Что нужно |
|-------|-----------|
| Состав provisioned-пакетов в `f6b14814` | `Get-AppxProvisionedPackage -Online` |
| Какие пункты `Apps.json` отработают на LTSC | Прогон на станции |
| Повторное появление приложений после обновлений | Наблюдение после первого цикла обновлений |
