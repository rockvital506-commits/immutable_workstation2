## Как получить

Особенность этой утилиты: **ассет релиза — не сама утилита**. В релизе
`2026.08.24` один ассет, `Get.ps1` размером 9071 байт, и это загрузчик. По коду
он обращается к API GitHub за `zipball_url` последнего релиза, скачивает архив
репозитория во временный каталог и распаковывает его.

То есть на флешку кладётся **весь распакованный каталог**, а не один файл:

| Путь в архиве | Размер |
|---------------|--------|
| `Win11Debloat.ps1` | 28155 |
| `Run.bat` | 1854 |
| `LICENSE` | 1093 |
| `Config\Apps.json` | 38616 |
| `Config\DefaultSettings.json` | 1543 |
| `Config\Features.json` | 72659 |
| `Scripts\Get.ps1` | 8817 |
| `Regfiles\` | 93 файла `.reg`, из них 65 в `Undo\` |

Скачать архив конкретной версии:

```
https://codeload.github.com/Raphire/Win11Debloat/zip/refs/tags/2026.08.24
```

В поле `file` строки `/manifest.csv` указана точка входа `Win11Debloat.ps1` —
именно она запускается, остальные файлы каталога идут вместе с ней.

## Проверка подлинности

После скачивания вычислить SHA256 точки входа и внести вместо `PENDING`:

```powershell
Get-FileHash -Algorithm SHA256 "E:\tools\os\windows\debloat\Win11Debloat\Win11Debloat.ps1"
```

```bash
sha256sum "/mnt/tools/os/windows/debloat/Win11Debloat/Win11Debloat.ps1"
```

Размер 28155 байт сверен по исходникам тега `2026.08.24` и служит первой
проверкой, что скачана та же версия.

## Куда положить на флешке

`Tools:\os\windows\debloat\Win11Debloat\` — распакованным каталогом, целиком,
со `Scripts\`, `Config\` и `Regfiles\`. Без `Regfiles\` откат правок работать
не будет.

## Напоминание про версию

Релизы нумеруются по датам: `2026.08.24`, `2026.07.11`, `2026.06.24`. При
обновлении меняются размеры файлов и контрольные суммы — править и
`/manifest.csv`, и эту заглушку.

## Напоминание про кодировку

Файлы `.reg` в каталоге `Regfiles\` сохранены в UTF-16LE. В простом редакторе
они выглядят как текст с нулями между символами — это нормально, пересохранять
их в UTF-8 нельзя.
