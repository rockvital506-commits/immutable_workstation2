# Win11Debloat

## Назначение

Основной слой очистки Windows 11: удаляет предустановленные приложения и
применяет правки реестра и локальных политик. Работает **только через реестр и
политики** — системные файлы не патчит, поэтому правки обратимы.

В утверждённой связке идёт **первым**, до WinUtil и Sophia Script.

## Когда применять

- Свежеустановленная станция, сеть ещё не подключена — снять предустановленный
  мусор до первого входа пользователя.
- После крупного обновления Windows вернулись приложения и параметры — прогнать
  повторно. Утилита рассчитана на повторный запуск.
- Нужен предпросмотр: что именно изменится, до применения.

## Запуск

Интерактивно, с повышением прав:

```
E:\tools\os\windows\debloat\Win11Debloat\Run.bat
```

`Run.bat` ищет Windows Terminal (обычная установка или Scoop), поднимает права
через `Start-Process -Verb RunAs` и пишет журнал в `Logs\Win11Debloat-Run.log`.

Из PowerShell:

```powershell
cd E:\tools\os\windows\debloat\Win11Debloat
.\Win11Debloat.ps1 -CLI
```

Без интернета: **да**, если каталог лежит на флешке целиком. `Scripts\Get.ps1`
нужен только для скачивания новой версии — он обращается к API GitHub и
распаковывает архив релиза.

- Требуются права администратора: **да**
- Работает из-под WinPE: **нет**
- Работает с флешки без установки: **да**
- Требует .NET / VC++ Redist: **нет**, нужен Windows PowerShell 5.1

## Результаты и как их читать

Журнал запуска — `Logs\Win11Debloat-Run.log` в каталоге утилиты.

Бэкап реестра создаётся автоматически перед применением. Откат отдельной
правки — соответствующим файлом из `Regfiles\Undo\`, например
`Prevent_Auto_Reboot.reg` откатывается `Allow_Auto_Reboot.reg`.

Метки применения и отката каждой правки лежат в `Config\Features.json` в полях
`ApplyText`, `UndoLabel`, `RegistryKey`, `RegistryUndoKey`. Если нужно понять,
что именно делает правка, — смотреть туда, а не угадывать по имени.

Значения по умолчанию, которые применяются без явного указания:
`CreateRestorePoint`, `DisableTelemetry`, `DisableSuggestions`,
`DisableEdgeAds`, `DisableLockscreenTips`, `DisableBing`,
`DisableStoreSearchSuggestions`, `DisableCopilot`, `DisableRecall`,
`DisableClickToDo` — по `Config\DefaultSettings.json`.

## Риски и предупреждения

> `-SkipRegistryBackup` не использовать. Бэкап реестра — единственное, что
> позволяет откатить правку, если станция перестала вести себя ожидаемо.

> Параметр `NoRestartExplorer` устарел и заменён на `SkipExplorerRestart`.
> Поддержка старого имени будет удалена.

> Поддержка собственного списка `CustomAppsList` удалена в релизе `2026.06.24`.
> Список приложений задаётся только через `-Apps` и `Config\Apps.json`.

> Блокировки драйверов из Windows Update в утилите **нет** — проверено поиском
> по `Scripts\` и `Regfiles\`. Её закрывает WinUtil, см. [`../updates/`](../../updates/).

> `-PreventUpdateAutoReboot` выставляет `NoAutoRebootWithLoggedOnUsers`, а режим
> `Updates → security` у WinUtil этот ключ удаляет. Порядок применения — в
> индексе группы.

> На LTSC часть правок не отработает: там нет потребительских компонентов.
> Это не ошибка утилиты.

> Перед прогоном на станции заказчика — запуск с `-WhatIf` и прогон на своей
> тестовой машине.
