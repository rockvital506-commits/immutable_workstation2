## Как получить

Единственный ассет релиза `26.10.07` — это и есть `winutil.ps1`. Это
скомпилированный файл: `Compile.ps1` из репозитория собирает его из исходников
в `functions/`, `config/` и `xaml/`.

Скачать ассет релиза напрямую:

```
https://github.com/ChrisTitusTech/winutil/releases/download/26.10.07/winutil.ps1
```

Штатный способ запуска у автора — `irm christitus.com/win | iex`. Он тянет
файл из сети и каждый раз может получить другую версию, поэтому для флешки не
годится: нужна закреплённая копия с известной контрольной суммой.

## Проверка подлинности

После скачивания вычислить SHA256 и внести его в `/manifest.csv` и в эту
заглушку вместо `PENDING`:

```powershell
Get-FileHash -Algorithm SHA256 "E:\tools\os\windows\tweaks\WinUtil\winutil.ps1"
```

```bash
sha256sum "/mnt/tools/os/windows/tweaks/WinUtil/winutil.ps1"
```

Контрольную сумму сверить с ассетом того же релиза на странице GitHub. Размер
927798 байт уже сверен через API GitHub и служит первой грубой проверкой.

## Куда положить на флешке

`Tools:\os\windows\tweaks\WinUtil\` — файл как есть, распаковка не требуется.

## Напоминание про версию

Релизы нумеруются по датам и выходят часто: `26.10.07`, `26.09.29`, `26.08.19`,
`26.08.04`. При обновлении меняются имя тега, размер файла и контрольная сумма —
править и `/manifest.csv`, и эту заглушку.

## Напоминание про конфликт

Запуск режима `Updates → security` снимает `NoAutoRebootWithLoggedOnUsers`,
который ставит Win11Debloat. Порядок применения и проверка — в
[`../updates/`](../../updates/).
