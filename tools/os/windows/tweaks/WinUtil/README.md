# WinUtil

## Назначение

Утилита настройки Windows от Chris Titus Tech: твики системы, режимы Центра
обновления, установка программ через winget. В нашей схеме играет роль
**watchdog**: при запуске определяет, какие из применённых ранее твиков система
сбросила. Это готовая реализация механизма M9 из
`research/07-blocking-mechanisms.md` — писать свою избыточно.

## Когда применять

- Настроенная станция вернулась из поля или пережила обновление — надо понять,
  что из правок уцелело.
- Нужен единый отчёт о состоянии всех твиков по категориям.
- Надо перевести Центр обновления в режим «только обновления безопасности».
- Надо перенести набор настроек на другую станцию — экспорт и импорт
  конфигурации.

## Запуск

С флешки, без интернета:

```powershell
Set-ExecutionPolicy Unrestricted -Scope Process -Force
& "E:\tools\os\windows\tweaks\WinUtil\winutil.ps1"
```

Штатный способ автора требует сети: `irm christitus.com/win | iex`. На флешке
лежит локальная копия именно для того, чтобы не зависеть от сети у заказчика.

- Требуются права администратора: **да**
- Работает из-под WinPE: **нет**, только в живой ОС
- Работает с флешки без установки: **да**, но требует снятого ExecutionPolicy
  для процесса
- Требует .NET / VC++ Redist: **нет**, нужен Windows PowerShell 5.1, он входит
  в состав Windows 11

## Ключи и типовые сценарии

Утилита с графическим интерфейсом, ключей командной строки у собранного файла
нет — действия выбираются в окне.

| Задача | Где |
|--------|-----|
| Отчёт о состоянии всех твиков | Функция `Get-WinUtilTweaksStateReport` в исходниках; в интерфейсе — отметка установленных твиков |
| Только обновления безопасности | Вкладка `Updates`, режим `security` |
| Вернуть режим по умолчанию | Вкладка `Updates`, режим `default` |
| Отключить обновления | Вкладка `Updates`, режим `disable` — **не применять**, противоречит R3 |
| Установить программы | Вкладка `Install`, через winget |
| Применить набор настроек | Импорт конфигурации |

Состав твиков по `config/tweaks.json` релиза `26.10.07`: **67 записей**, из них
50 с описанием в реестре и 2 через службы. Категории: `Essential Tweaks` — 18,
`Customize Preferences` — 25, `z__Advanced Tweaks - CAUTION` — 22,
`Performance Plans - NOT FOR LAPTOPS` — 2.

## Результаты и как их читать

Отчёт о состоянии группирует твики по четырём категориям и показывает для
каждого, применён он сейчас или нет. Твики типа `Combobox` и те, у которых нет
ни реестра, ни службы в описании, попадают в список «не оценивается» — они
в отчёт не входят, и это не ошибка.

Журнал пишется через `Write-WinUtilLog` с компонентом действия, например
`Updates`.

Режим `security` вкладки `Updates` по коду делает следующее: блокирует драйверы
из WU, откладывает функциональные обновления на 365 дней и качественные на
4 дня, ставит `AUOptions = 3` (загрузка с уведомлением) и **возвращает
работоспособность Центра обновления** — службы `BITS` и `wuauserv` в `Manual`,
`UsoSvc` в `Automatic`, задачи обновления включаются. Подробная таблица ключей —
в [`../updates/`](../../updates/).

## Риски и предупреждения

> Режим `security` **удаляет** `NoAutoRebootWithLoggedOnUsers`, который ставит
> Win11Debloat параметром `-PreventUpdateAutoReboot`. Если запускать WinUtil
> после Win11Debloat, запрет автоматической перезагрузки будет снят. Порядок и
> проверка — в [`../updates/`](../../updates/).

> Категория `z__Advanced Tweaks - CAUTION` помечена автором как опасная не
> случайно. На станции заказчика применять только те пункты, которые проверены
> на своей тестовой машине.

> Категория `Performance Plans` прямо помечена `NOT FOR LAPTOPS`. MSI Modern 15
> — ноутбук, эти два твика не применять.

> Утилита требует интернет для вкладки `Install`. Для твиков и обновлений сеть
> не нужна, если запускать локальную копию.

> Windows 10 больше не поддерживается — поддержка прекращена вместе с EOL
> 2025-10-14. Для целевой Win11 IoT LTSC 2024 ограничений нет.

> Версия меняется часто: релизы нумеруются по датам, `26.10.07`, `26.09.29`,
> `26.08.19`. Закреплять конкретную версию в `/manifest.csv`.
