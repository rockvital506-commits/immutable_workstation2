# installation/ — установка Windows 11 IoT Enterprise LTSC 2024

Разметка диска, файл ответов, драйверы. Всё, что происходит **до** первой
настройки системы.

## Что здесь и чего нет

| Что | Где |
|-----|-----|
| Полный алгоритм из 14 шагов | `ventoy-partition/builds/MSI_B12M-211RU_Win11_LTSC_IoT_24H2/algorithm.md` |
| Файл ответов станции | каталог `answer/` той же сборки |
| Драйверы станции | каталог `drivers/` той же сборки |
| Механизм автоустановки Ventoy | `ventoy-partition/ventoy/autoinstall/` |
| Утилиты | не нужны: установка идёт средствами самого образа |

## Загрузка образа через Ventoy

Проверено на Этапе 3: плагин `auto_install` в `ventoy.json` работает **только
через `parent`**, а не через `image`, и **не отрабатывает `timeout`**.

```json
{
    "auto_install": [
        {
            "parent": "/ISO/windows",
            "template": "/ventoy/autoinstall/autounattend.xml"
        }
    ]
}
```

Правило `parent` применяется ко всем образам в каталоге. Если для части образов
файл ответов не нужен — разнести их по разным каталогам, а не пытаться задать
исключения.

## Разметка диска

Станция MSI Modern 15 B12M-211RU: NVMe 256 ГБ, UEFI, GPT.

| Раздел | Размер | ФС | Назначение |
|--------|--------|-----|-----------|
| EFI (ESP) | **260 МБ** | FAT32 | Загрузчик. Минимум по требованиям Win11 — 100 МБ, но 260 МБ оставляет запас под второй загрузчик и обновления прошивки |
| MSR | 16 МБ | — | Зарезервирован Microsoft |
| Recovery | 1000 МБ | NTFS | Среда восстановления |
| Windows | остальное | NTFS | Система и данные |

Раздел с данными не создаётся: на 256 ГБ при 8 ГБ ОЗУ отдельный раздел под
данные только мешает — он упрётся в границу первым, а расширить его на NVMe с
одним разделом Windows проще.

## Драйверы до первого включения сети

Сеть на этапе установки **физически отключена**. Порядок:

1. Установка по `autounattend.xml` без сети.
2. Драйверы из каталога `drivers/` сборки станции — офлайн, `pnputil /add-driver`
   или установщики вендора в тихом режиме.
3. Только после этого сеть подключается под контролем.

Если сеть подключить раньше, Windows Update поставит свои версии драйверов, и
часть работы придётся переделывать. Закрытие этого канала — в
[`../updates/`](../updates/).

## Особенность Intel 11-го поколения и новее

i3-1215U на этой станции — 12-е поколение. Установщик Windows **не видит NVMe**,
если в UEFI включён режим VMD/IRST, потому что драйвер контроллера не входит в
состав образа.

Два варианта:

| Вариант | Действие | Когда |
|---------|----------|-------|
| Отключить VMD | `Enable VMD controller = Disabled` в UEFI | Проще, работает сразу |
| Оставить VMD | Подложить драйвер IRST/VMD в установщик | Если заказчику нужен RAID или режим менять нельзя |

Признак проблемы: на этапе выбора диска список пуст. Это не аппаратная
неисправность, и перезагрузка не помогает.

## Audit mode — не используется

Решение заказчика от 2026-10-07: одна станция, без audit mode. Обход OOBE
обеспечивает `autounattend.xml`, то есть главная выгода audit mode получена без
него. Дополнительно, по официальной документации Microsoft:

- Audit mode **не предназначен для тестирования и валидации** — проверять
  работу ОС можно только после завершения OOBE.
- Настройки из прохода `oobeSystem` файла ответов в audit mode не применяются.
- Вход выполняется под встроенным администратором, который отключается сразу
  после входа; включённая заставка с паролем может заблокировать вход.
- Установка и обновление приложений из Microsoft Store в audit mode ломает
  последующий `sysprep`.

Подробнее — `research/08-settings-attack-vectors.md`, раздел C1.

## Профиль по умолчанию

Если понадобится задать настройки для всех будущих учётных записей,
`CopyProfile` не использовать — Microsoft называет его legacy. Рабочий способ —
правка куста напрямую:

```cmd
reg load HKU\Default C:\Users\Default\NTUSER.DAT
reg add "HKU\Default\Software\..." /v Параметр /t REG_DWORD /d 1 /f
reg unload HKU\Default
```

## Проверка после установки

Минимум перед переходом к настройке:

| Что | Как | Норма |
|-----|-----|-------|
| Редакция | `winver`, `slmgr /dlv` | Windows 11 IoT Enterprise LTSC 2024 |
| Разметка | `diskpart` → `list partition` | ESP 260 МБ, MSR, Recovery, Windows |
| Загрузчик | `bcdedit /enum firmware` | Запись Windows, путь `\EFI\Microsoft\Boot\bootmgfw.efi` |
| Драйверы | `pnputil /enum-drivers`, Диспетчер устройств | Нет неизвестных устройств |
| Сеть | `ipconfig /all` | Отключена до шага настройки |
| Состояние SSD | `smartmontools` из группы diagnostics | `Percentage Used` в норме |
