# os/windows/ — группа «Операционная система: Windows»

Установка, активация, обновления, настройка, удаление предустановленного мусора
и закрепление сделанных настроек. Группа работает **только под Windows 11 IoT
Enterprise LTSC 2024** на станции MSI Modern 15 B12M-211RU.

## Область применения

| Параметр | Значение |
|----------|----------|
| Целевая ОС | Windows 11 IoT Enterprise LTSC 2024 (база 24H2) |
| Референсная станция | MSI Modern 15 B12M-211RU, см. `ventoy-partition/builds/MSI_B12M-211RU_Win11_LTSC_IoT_24H2/` |
| Прочие Windows-образы на флешке | Заглушки остаются, установка и настройка сейчас не рассматриваются |
| Домен | Отсутствует — только локальные групповые политики |
| Использование | Коммерческое — лицензии проверяются по этому критерию |

## Подкатегории

| Подкатегория | Что закрывает | Утилита здесь |
|--------------|---------------|---------------|
| [`installation/`](installation/) | Установка, `autounattend.xml`, разметка, драйверы | — |
| [`activation/`](activation/) | Активация и проверка лицензии LTSC | — |
| [`updates/`](updates/) | Сужение канала Windows Update, блокировка драйверов | — |
| [`tweaks/`](tweaks/) | Настройка системы и контроль отката правок | `WinUtil` |
| [`debloat/`](debloat/) | Удаление предустановленного мусора и телеметрии | `Win11Debloat` |
| [`gpo_lock/`](gpo_lock/) | Закрепление настроек локальными политиками | `Sophia Script` |

Скриптов `.ps1` и `.sh` на этом этапе нет — они переносятся на Этап 5 по
решению заказчика. Группа пока несёт индексы, документацию по механизмам и
три сторонние утилиты.

## Утверждённая связка инструментов

Решение заказчика от 2026-10-07, основание — `research/08-settings-attack-vectors.md`,
рекомендация R4. Инструменты применяются **последовательно, а не вместе**:
пересечение правок при одновременном запуске даёт непредсказуемый результат и
два набора откатов, которые невозможно сопоставить.

Решение **R1** принято вместе с ними: настройка идёт в обычной ОС, **не в audit
mode**. Обход OOBE обеспечивает `autounattend.xml`, а Microsoft прямо не
рекомендует audit mode для проверки и валидации. Основание —
[`installation/`](installation/) и `research/08-settings-attack-vectors.md`, C1.

| Порядок | Инструмент | Роль | Почему именно так |
|---------|-----------|------|-------------------|
| 1 | `Win11Debloat` 2026.08.24 | Основной слой: реестр и политики | Есть бэкап реестра, 65 файлов отката, собственный набор тестов. Сначала прогон с `-WhatIf` |
| 2 | `WinUtil` 26.10.07 | Watchdog: контроль отката правок | При запуске проверяет, не сбросила ли система применённые твики. Механизм M9 из `research/07-blocking-mechanisms.md` писать не нужно |
| 3 | `Sophia Script` 7.3.0 | Точечно, на непокрытое | Пакет именно для LTSC 2024; 150+ функций с парным откатом, только документированные методы |
| 4 | Свои скрипты | ACL-закрепление политик, блокировки | То, чего нет ни в одном инструменте; переносятся на Этап 5 |

**GTweak в состав не входит.** Его лицензия и наличие отката у каждой правки
не проверены, а на коммерческой станции непроверенный откат дороже выгоды.

## Порядок применения на станции

Порядок важнее состава. Нарушение первых двух пунктов обесценивает всё
остальное независимо от выбранных утилит.

1. Станция установлена по `autounattend.xml` **при отключённой сети**.
2. Драйверы поставлены офлайн, сеть не подключалась.
3. `Win11Debloat` — сначала `-WhatIf`, затем реальный прогон.
4. `WinUtil` — проверка состояния правок, экспорт конфигурации в JSON для
   переноса на другие станции.
5. `Sophia Script` — только функции, которых нет в первых двух.
6. Свои блокировки по `research/06-services-blocklist.md` и
   `research/07-blocking-mechanisms.md`.
7. Сужение канала Windows Update — см. [`updates/`](updates/).
8. ACL-закрепление политик — см. [`gpo_lock/`](gpo_lock/).
9. Перезагрузка и **двойная** пост-проверка: часть механизмов самовосстановления
   возвращает значения только после перезагрузки или по расписанию.
10. Эталонный бэкап образа.

## Правила группы

> Ни одна утилита не запускается без точки восстановления или выгруженного
> `.reg` по конкретной группе правок. Точка восстановления не переживает
> переустановку и не помогает, если станция перестала загружаться.

> `AllowTelemetry = 0` и пост-тест Центра обновления — обязательная пара.
> Применение телеметрических правок без проверки, что обновления всё ещё
> работают, считается незавершённым шагом.

> Версия каждой утилиты закрепляется в `/manifest.csv`. «Последняя» — не
> версия: у Win11Debloat релизы выходят по датам, у WinUtil — несколько раз
> в неделю.

> Перед применением на станции заказчика — прогон на своей тестовой машине
> той же редакции. LTSC не имеет потребительских компонентов, и часть правок
> на ней просто не отработает.

## Чего здесь нет и почему

| Что | Почему не здесь |
|-----|-----------------|
| GTweak | Лицензия и наличие отката не проверены |
| Win10-based скрипты debloat | Поддержка Windows 10 в WinUtil прекращена 2025-10-14; целевая ОС — Win11 LTSC 2024 |
| Средства активации и «активаторы» | Коммерческое использование; см. [`activation/`](activation/) |
| Патчи системных файлов | Все три инструмента работают только через реестр и политики |
| Настройка Linux | Не входит в группу `os/windows/`; Mint живёт как live-среда в разделе VENTOY |
