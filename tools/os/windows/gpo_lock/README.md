# gpo_lock/ — закрепление настроек локальными политиками

Последний слой настройки. Всё, что применено до этого, живёт в реестре и может
быть отменено обновлением, службой или задачей. Локальная групповая политика
переживает перезагрузку и видна в `gpresult` — но сама по себе защищает
недостаточно.

## Утилита

[`Sophia_Script/`](Sophia_Script/) — версия 7.3.0, MIT, 110 функций с парным
откатом.

Домена нет, поэтому используются **только локальные** политики. Механизм —
**M3** из `research/07-blocking-mechanisms.md`.

## Почему одной политики мало

`research/08-settings-attack-vectors.md`, векторы A2 и A3. Достаточно прав
локального администратора:

```powershell
Stop-Service wuauserv -Force
Remove-Item "C:\Windows\System32\GroupPolicyUsers" -Recurse -Force
Remove-Item "C:\Windows\System32\GroupPolicy" -Recurse -Force
Remove-Item "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate" -Recurse -Force
Start-Service wuauserv
```

Это штатный способ сброса локальных политик, он публично документирован.
Результат при этом непредсказуем: удаление политики не откатывает
«татуированные» значения, часть параметров остаётся в реестре, часть
возвращается к умолчанию.

Значения политик физически лежат в `HKLM\SOFTWARE\Policies\...` и удаляются
через `reg delete` без всякого `gpedit`.

## Закрепление: ACL Deny на носитель политики

Механизм **M6** из `research/07-blocking-mechanisms.md`. Защищать надо не
значение, а место, где оно хранится:

| Объект | Что делать |
|--------|-----------|
| `C:\Windows\System32\GroupPolicy` | Снять наследование прав, запретить изменение |
| `C:\Windows\System32\GroupPolicyUsers` | То же |
| Ключевые ветки `HKLM\SOFTWARE\Policies\Microsoft\Windows\...` | Запретить доступ через редактор безопасности ключа |

Приём описан Марком Руссиновичем и работает даже против локального
администратора: после снятия наследования и запрета доступа политика перестаёт
изменяться.

### Цена закрепления

> После запрета доступа изменить политику можно, только вернув права.
> **Способ снятия обязательно документируется** в каталоге станционной сборки.
> Без него станция становится необслуживаемой — при следующем выезде её
> придётся переустанавливать.

Скрипт закрепления и снятия — на Этапе 5, здесь только регламент.

## Что закрепляем

| Группа | Где описано |
|--------|-------------|
| Телеметрия | `research/06-services-blocklist.md` P0, P1b |
| Службы и задачи | там же, P1a, P2; механизм M7 |
| Драйверы из Windows Update | [`../updates/`](../updates/) |
| Точечные запреты команд | `research/06-services-blocklist.md` T; механизм M1 (IFEO) |
| Сетевые каналы телеметрии | механизмы M4 (hosts) и M5 (межсетевой экран) |

## Порядок

1. Все настройки применены и проверены — Win11Debloat, WinUtil, Sophia Script.
2. `gpresult /h report.html` — убедиться, что политики применились.
3. Выгрузить ветки `HKLM\SOFTWARE\Policies` в `.reg` как бэкап.
4. ACL Deny на `GroupPolicy`, `GroupPolicyUsers` и ключевые ветки.
5. Задокументировать способ снятия прав в каталоге станционной сборки.
6. Перезагрузка и повторная проверка — часть механизмов самовосстановления
   возвращает значения только после перезагрузки.

## Проверка закрепления

| Проверка | Команда | Норма |
|----------|---------|-------|
| Политики применились | `gpresult /h report.html` | Нужные политики в разделе «Компьютер» |
| Значение на месте | `reg query "HKLM\SOFTWARE\Policies\..."` | Ожидаемое значение |
| Каталог политик защищён | `icacls C:\Windows\System32\GroupPolicy` | Есть явный запрет |
| После перезагрузки | Повторить первые две | Значения не изменились |

## Чем закрепление не защищает

| Вектор | Почему | Что делать |
|--------|--------|-----------|
| A1 — обновления возвращают значения | ACL не мешает системе применить свои значения при обслуживании | Watchdog: WinUtil, повторная проверка после обновлений |
| A11 — загрузка с внешнего носителя | Любой ACL обходится офлайн-доступом к диску | BitLocker и пароль на UEFI |
| Функциональное обновление | Фактически переустановка | Закрепление целевой версии, см. [`../updates/`](../updates/) |

## Правила

> Закрепление без задокументированного способа снятия прав не делать.

> Перед закреплением — бэкап веток `Policies` в `.reg`. ACL защищает от
> изменения, но не от того, что значение понадобится поменять по делу.

> Не закреплять то, что не проверено после перезагрузки. Закреплённая ошибка
> воспроизводится стабильно.
