# Sophia Script for Windows 11 LTSC 2024

## Назначение

Набор из 110 функций настройки Windows, у **каждой** из которых есть парная
функция возврата к значениям по умолчанию. Использует только официально
документированные Microsoft механизмы — реестр, групповые политики,
PowerShell API.

В утверждённой связке идёт **третьим**, после Win11Debloat и WinUtil, и
применяется точечно — только на те функции, которых нет в первых двух.

## Когда применять

- Нужна конкретная настройка, которой нет ни в Win11Debloat, ни в WinUtil.
- Нужен гарантированный откат одной правки, а не всей группы.
- Надо закрепить что-то через локальную групповую политику, а не через
  «сырой» ключ реестра.

## Состав каталога

| Файл | Что это | В git |
|------|---------|-------|
| `Sophia.ps1` | Пресет: список функций, каждая закомментирована или нет | заглушка `Sophia.ps1.md` |
| `Import-TabCompletion.ps1` | Автодополнение имён функций в консоли | как есть |
| `Module\Sophia.psm1` | Модуль с реализацией, 275642 байта | как есть |
| `Module\Localizations\` | Языковые файлы, включая `ru-RU` | как есть |

## Запуск

```powershell
cd E:\tools\os\windows\gpo_lock\Sophia_Script
Set-ExecutionPolicy Unrestricted -Scope Process -Force
Import-Module .\Module\Sophia.psd1 -Force
```

Дальше — либо вызвать нужные функции по именам, либо отредактировать
`Sophia.ps1` и запустить его целиком:

```powershell
.\Sophia.ps1
```

По инструкции в самом пресете: знак `#` перед функцией — не выполнять, снятый
`#` — выполнить.

- Требуются права администратора: **да**
- Работает из-под WinPE: **нет**
- Работает с флешки без установки: **да**
- Требует .NET / VC++ Redist: **нет**, нужен Windows PowerShell 5.1

## Ключи и типовые сценарии

Параметров командной строки у пресета нет — состав выбирается правкой
`Sophia.ps1`. Для удобства есть автодополнение:

```powershell
.\Import-TabCompletion.ps1
```

После этого имена функций подсказываются по Tab.

| Задача | Как |
|--------|-----|
| Одна функция | `ИмяФункции` в консоли после импорта модуля |
| Откат одной функции | Парная функция с суффиксом возврата, имя видно в `Sophia.psm1` |
| Набор функций | Раскомментировать нужные строки в `Sophia.ps1` |
| Список доступных функций | `Get-Command -Module Sophia` |
| Графическая оболочка | `Sophia.Script.Wrapper.v2.8.40.zip` — отдельный ассет того же релиза |

## Результаты и как их читать

Каждая функция печатает в консоль, что именно она делает. Утверждение автора в
заголовке пресета: «Every tweak in the preset file has its corresponding
function to restore the default settings» — у каждой правки есть функция
возврата. Это главная причина держать утилиту в связке: откат предсказуем и
точечен.

Локализация берётся из `Module\Localizations\`, русский язык есть.

## Риски и предупреждения

> Нужен пакет **именно для LTSC 2024**. Обычный пакет для Windows 11 содержит
> функции для потребительских компонентов, которых в LTSC нет, — они либо не
> отработают, либо выдадут ошибку.

> На LTSC 2024 отсутствуют Widgets, Xbox, Teams и часть других
> потребительских компонентов. Значительная доля твиков из обычного пакета
> здесь просто неприменима.

> Не применять весь пресет целиком на станции заказчика. Раскомментировать
> только то, что нужно, и только после проверки на тестовой машине.

> Функции, работающие через групповые политики, попадают в
> `C:\Windows\System32\GroupPolicy` и снимаются удалением этого каталога.
> Закрепление — в индексе подкатегории.

> При одновременном запуске с Win11Debloat или WinUtil часть правок
> перекрывается, и сопоставить откаты становится невозможно. Порядок применения
> — в индексе группы.

## Поддержка LTSC 2024

Подтверждена официальным README проекта: в таблице поддерживаемых редакций есть
строка `Windows 11 Enterprise LTSC 2024` с отдельной ссылкой на релиз. В
исходниках тега `7.3.0` этому соответствуют:

- `src/Sophia_Script_for_Windows_11_LTSC_2024/` — отдельный каталог варианта;
- `Scripts/Building/Windows_11_LTSC_2024.ps1` — сборка под PowerShell 5.1;
- `Scripts/Building/Windows_11_LTSC_2024_PS7.ps1` — сборка под PowerShell 7.

Вариант под PowerShell 7 — отдельный ассет размером 10542142 байта. Для флешки
берётся вариант под 5.1: Windows PowerShell 5.1 входит в состав Windows 11, а
PowerShell 7 придётся ставить отдельно.

Конфликт, зафиксированный на Этапе 2 в `research/02-findings.md`, закрыт.

## Аналоги

| Утилита | Когда предпочесть |
|---------|-------------------|
| `Win11Debloat` | Для основного слоя: там есть бэкап реестра и 65 файлов отката. Идёт первым |
| `WinUtil` | Для контроля отката правок и режимов Центра обновления. Идёт вторым |
| `gpedit.msc` вручную | Когда правка одна и её надо показать заказчику |
| `Sophia Script Wrapper` | Когда нужен графический выбор функций вместо правки пресета |
