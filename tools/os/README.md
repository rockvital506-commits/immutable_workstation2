# os/ — группа «Операционные системы»

Установка, активация, обновление, настройка, удаление предустановленного мусора
и закрепление сделанных настроек.

## Подгруппы

| Подгруппа | Статус | Область |
|-----------|--------|---------|
| [`windows/`](windows/) | ✅ Этап 4.3 | Только Windows 11 IoT Enterprise LTSC 2024 |

## Почему нет `linux/`

Linux в этом проекте представлен одной ролью: **live-среда с персистентностью**
на разделе VENTOY — Linux Mint 22.3 Cinnamon с файлом персистентности 16 ГБ.
Он не устанавливается на станции заказчика, поэтому настраивать и закреплять
там нечего.

Состав и настройка live-среды описаны в разделе VENTOY:

| Что | Где |
|-----|-----|
| Образ | `ventoy-partition/ISO/linux/` |
| Файл персистентности | `ventoy-partition/ventoy/persistence/` |
| Конфигурация | `ventoy-partition/ventoy/ventoy.json`, блок `persistence` |

Если появится задача установки Linux на станцию заказчика — подгруппа `linux/`
добавляется здесь, а не в другом месте дерева.

## Правило группы

> Группа `os/` описывает настройку **целевой** операционной системы. Образы,
> которые лежат на флешке «на всякий случай», в группу не входят: у них есть
> заглушка в `ventoy-partition/ISO/`, и этого достаточно.

Решение заказчика от 2026-10-07: установка, чистка, оптимизация, защита
настроек и нейтрализация встроенных механизмов реанимации выполняются только
под Windows 11 IoT Enterprise LTSC 2024. По прочим Windows-образам с флешки —
Win10 IoT LTSC 21H2, Win11 Pro, Win10 Pro — установка и настройка сейчас не
рассматриваются.
