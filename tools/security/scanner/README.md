# scanner/ — проверка и лечение

**Утилит здесь нет намеренно.** Причина лицензионная, а не техническая:
профиль работ коммерческий, а бесплатные портативные сканеры разрешают только
личное некоммерческое использование.

## Основной слой: Microsoft Defender средствами ОС

Он уже стоит на станции, которую мы обслуживаем, и его лицензия оплачена
вместе с Windows. Отдельного разрешения вендора не требует, ничего везти не
нужно, следов в системе не оставляет.

`MpCmdRun.exe` лежит в двух местах, и это важно:

- `%ProgramFiles%\Windows Defender` — есть всегда, но там может быть **устаревшая**
  копия;
- `%ProgramData%\Microsoft\Windows Defender\Platform\<версия платформы>` —
  здесь всегда **свежая**, именно её рекомендует документация Microsoft.

Папки нет в `PATH`, поэтому сначала переход в каталог со свежей версией, и
только потом команды. Переход одной строкой, с откатом на `%ProgramFiles%`,
если каталога платформы нет:

```cmd
(set "_done=" & if exist "%ProgramData%\Microsoft\Windows Defender\Platform\" (for /f "delims=" %d in ('dir "%ProgramData%\Microsoft\Windows Defender\Platform" /ad /b /o:-n 2^>nul') do if not defined _done (cd /d "%ProgramData%\Microsoft\Windows Defender\Platform\%d" & set _done=1)) else (cd /d "%ProgramFiles%\Windows Defender")) >nul 2>&1
```

| Задача | Команда |
|--------|---------|
| Быстрая проверка | `MpCmdRun.exe -Scan -ScanType 1` |
| Полная проверка | `MpCmdRun.exe -Scan -ScanType 2` |
| Проверка конкретной папки | `MpCmdRun.exe -Scan -ScanType 3 -File "C:\путь"` |
| Обновить базы перед проверкой | `MpCmdRun.exe -SignatureUpdate` |
| Сбросить базы и скачать заново | `MpCmdRun.exe -RemoveDefinitions -All`, затем `-SignatureUpdate` |
| То же самое средствами PowerShell | `Start-MpScan -ScanType QuickScan` / `FullScan` / `CustomScan -ScanPath "C:\путь"` |
| Состояние и версия баз | `Get-MpComputerStatus` |
| Что найдено | `Get-MpThreatDetection`, `Get-MpThreat` |
| Журнал | `Get-WinEvent -LogName "Microsoft-Windows-Windows Defender/Operational"` |
| Проверка до загрузки ОС | `Start-MpWDOScan` — встроен в Windows 10 1607+ и Windows 11; команда **сразу перезагружает** станцию в изолированную среду. Альтернатива без PowerShell — класс WMI `MSFT_MpWDOScan`, метод `Start` |
| Проверка через интерфейс | Безопасность Windows → Защита от вирусов и угроз |

Команды `MpCmdRun.exe` в таблице рассчитаны на то, что переход в каталог уже
сделан. Без перехода они не найдутся — это самая частая ошибка.

Порядок: обновить базы → быстрая проверка → если чисто, а симптомы остались →
полная → если и она чиста, смотреть [`../audit/`](../audit/).

### Что Defender не закрывает

- Активное заражение, которое **отключило** Defender. Тогда нужен
  Microsoft Defender Offline или загрузка в Live-среду.
- Рекламное и потенциально нежелательное ПО: по умолчанию Defender его не
  удаляет. Включается отдельно — `Set-MpPreference -PUAProtection Enable`.
- Руткиты, прячущиеся от работающей ОС.

## Второй слой: скачиваемое перед выездом

Эти программы на флешке **не хранятся** — они либо истекают, либо не обновляют
базы, либо требуют коммерческую лицензию. Скачивать перед каждым выездом.

| Программа | Почему не на флешке | Лицензия при коммерческом использовании |
|-----------|---------------------|------------------------------------------|
| Microsoft Safety Scanner | **истекает через 10 дней** после скачивания; x64 218 МБ | не проверена |
| Dr.Web CureIt! | баз не обновляет, скачивается заново | **нужна лицензия**: 351–702,77 ₽ за ПК в год, по числу станций |
| Kaspersky Virus Removal Tool | баз не обновляет | не проверена |
| SmartFix Tool | распространяется через `simplix.pro` | не проверена |
| Emsisoft Emergency Kit | обновляет базы сам, но лицензия ограничивает | **нужна лицензия**: EEK Pro или Remediation Kit |

**Ни одна из этих лицензий не подтверждена первоисточником**: сайты вендоров
из рабочей среды недоступны. Сведения — из каталогов софта, которые
противоречат друг другу.

### Правило запуска

> Сторонний сканер запускается **только после того, как заказчик принял
> лицензионные условия вендора**, и это зафиксировано в заявке. Решение о
> принятии лицензии принимает владелец машины, а не мастер.

## Порядок при подозрении на заражение

1. Изолировать станцию от сети, если есть признаки активной утечки.
2. Скопировать важные данные заказчика на носитель до лечения, а не после:
   лечение может повредить файлы.
3. `MpCmdRun.exe -SignatureUpdate`, потом `-ScanType 1`.
4. Чисто, а симптомы есть → `-ScanType 2`.
5. Не помогло → `Start-MpWDOScan`, проверка до загрузки ОС.
6. Не помогло → загрузка в Live Mint с флешки, разбор офлайн.
7. Параллельно — [`../audit/`](../audit/): что стартует, что держит соединения.

## Риски и предупреждения

> **Лечение может сделать станцию незагружаемой.** Удаление файла, который
> сканер счёл заражённым, но который нужен системе, — типичный исход. Копия
> данных до лечения обязательна.

> **Не удалять найденное молча.** Показывать заказчику список находок и что
> сделано с каждой. Отчёт сохранять.

> **Два сканера одновременно не запускать.** Конфликт драйверов и взаимная
> блокировка; результат будет недостоверным у обоих.

> **Ложные срабатывания бывают.** Ключи, активаторы и «лечилки» сканеры
> помечают охотно, и часть этих находок заказчику нужна. Удалять только то,
> что заказчик согласился удалить.

| Пункт | Что нужно |
|-------|-----------|
| Наличие каталога `%ProgramData%\Microsoft\Windows Defender\Platform` на IoT Enterprise LTSC 2024 | Если его нет, переход откатится на `%ProgramFiles%\Windows Defender`, а там копия может быть устаревшей |
| Ключи `MpCmdRun.exe` на IoT Enterprise LTSC 2024 | Прогон на станции: состав компонентов в LTSC отличается |
| Наличие `Start-MpWDOScan` в LTSC-редакции | Проверить на месте |
| Состав `SSTR/MInst/Portable/Antivirus` в Strelec | Нужен сам носитель |
| Лицензии всех пяти сторонних сканеров | EULA с сайта вендора |
