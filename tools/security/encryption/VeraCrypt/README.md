# VeraCrypt

## Назначение

Шифрование данных: контейнер-файл, раздел, флешка целиком или системный диск.
Наследник TrueCrypt с исправлениями в криптографии. Отвечает на задачу
«данные владельца не должны читаться, если носитель унесут».

Единственная утилита этой группы, чья версия и лицензия **подтверждены
первоисточником**.

## Когда применять

- Нужен зашифрованный переносной контейнер для рабочих файлов.
- Владелец просит защитить данные на флешке или внешнем диске.
- BitLocker недоступен: редакция Home, не-Windows, или нужен кроссплатформенный
  контейнер, который прочитается и в Linux.
- Нужен скрытый том.

**Когда не применять:** на станции с Windows Pro или Enterprise, где владельцу
достаточно штатного шифрования, — там BitLocker. Он не требует установки
драйвера и управляется штатными средствами.

## Запуск

```cmd
msiexec /i VeraCrypt_Setup_x64_1.26.29.msi
```

Тихая установка:

```cmd
msiexec /i VeraCrypt_Setup_x64_1.26.29.msi /qn ACCEPTLICENSE=YES
```

- Требуются права администратора: **да**, ставит драйвер
- Работает из-под WinPE: **нет**
- Работает с флешки без установки: **да**, портативный режим `/portable`
- Требует .NET / VC++ Redist: **нет**

## Ключи и типовые сценарии

| Задача | Команда |
|--------|---------|
| Создать контейнер | Интерфейс → `Create Volume` |
| Смонтировать | `VeraCrypt.exe /volume "D:\safe.hc" /letter X /password "..." /quit` |
| Размонтировать | `VeraCrypt.exe /dismount X /quit` |
| Размонтировать всё | `VeraCrypt.exe /dismount /quit` |
| Проверить заголовок | `VeraCrypt.exe /volume "D:\safe.hc" /hash sha512` |
| Портативный запуск | `VeraCrypt.exe /portable` |
| Отменить долгое монтирование | `/cancelmount` (появился в 1.26.29) |

Параметры шифрования по умолчанию в 1.26.x: AES, KDF **Argon2id**. RIPEMD-160 и
GOST89 удалены начиная с 1.26, старые контейнеры TrueCrypt не поддерживаются.

## Результаты и как их читать

| Что | Где смотреть |
|-----|--------------|
| Том смонтирован | Список томов, буква диска |
| Алгоритм и KDF | Свойства тома |
| Скрытый том существует | Не определяется никак — в этом смысл |
| Ошибка монтирования | Чаще неверный пароль или повреждённый заголовок |

**Зашифрованный контейнер неотличим от мусора.** Если пароль потерян, данные
не восстанавливаются ничем: ни мастер-паролем, ни поддержкой, ни бэкапом
заголовка, если его не сделали заранее.

## Риски и предупреждения

> **Потерянный пароль — потерянные данные.** Перед шифрованием данных
> владельца записать пароль и, если используется keyfile, сохранить его копию.
> Проверить, что том открывается, **до** того, как в него положено что-то
> важное.

> **Не включать шифрование «на всякий случай».** Зашифрованный диск без ключа
> — это безвозвратно потерянные данные. Прежнее основание включало претензию
> владельца к мастеру; при домашнем профиле исполнитель и владелец — одно
> лицо, поэтому остаётся чистая потеря данных, но правило от этого не слабее.
> Только по решению и с записанным ключом.

> **Резервная копия заголовка обязательна** для системного шифрования.
> Без неё повреждение загрузчика означает конец.

> **Шифрование системного диска требует перезагрузок и может не пережить
> обновление BIOS.** Secure Boot иногда приходится временно отключать. На
> чужой станции делать это только с согласия владельца.

> **Шифрование не защищает от работающей ОС.** Если на станции кейлоггер или
> вредоносное ПО, пароль будет перехвачен. С 1.26.24 есть защита от снимков
> экрана, но это мера, а не гарантия.

> **BitLocker и VeraCrypt на одном томе не совмещаются.**

## Версия и источник

| Поле | Значение |
|------|----------|
| Версия | 1.26.29 |
| Дата релиза | 2026-06-12 |
| Дата проверки версии | 2026-10-11 |
| Официальный сайт | https://veracrypt.io/ |
| Прямая ссылка на файл | https://github.com/veracrypt/VeraCrypt/releases/download/VeraCrypt_1.26.29/VeraCrypt_Setup_x64_1.26.29.msi |
| SHA256 | `5ba6426983123cfb92bc1f09bd888fdbc0f53f300d0d9c5da52ce3aee8d474f0` — ожидаемая, источник ниже |
| Размер | **52 789 248 байт** |
| Лицензия | TrueCrypt License 3.0 + Apache 2.0. По API GitHub — `NOASSERTION`, файл `License.txt` 40 425 байт |

**Версия сверена с первоисточником** — через API GitHub: тег
`VeraCrypt_1.26.29`, опубликован 2026-06-12, размер ассета 52 789 248 байт,
рядом подпись `.sig` 566 байт.

**Откуда ожидаемая сумма.** Манифест пакета `IDRIX.VeraCrypt` версии
`1.26.29` в репозитории `microsoft/winget-pkgs`, поле `InstallerSha256`; имя
файла в манифесте совпадает с нашим — `VeraCrypt_Setup_x64_1.26.29.msi`, хотя
URL ведёт на `launchpad.net`, а не на ассет GitHub. Размер ассета GitHub,
52 789 248 байт, получен ранее через API того же проекта, поэтому сумма и
размер относятся к одному файлу. По правилу §4 манифест пакетного менеджера —
сторонний каталог, источник назван явно. Прочитано через `api.github.com`
2026-10-16: `release-assets.githubusercontent.com` вне белого списка, поэтому
вычислить сумму самим было нельзя.

**Коммерческое использование разрешено.** Платного уровня, подписки и
ограничения по числу установок у VeraCrypt нет — это принципиальное отличие от
антивирусных сканеров той же группы.

Формулировка TrueCrypt License 3.0 по существу (`launchpad.net/veracrypt`,
текст лицензии):

> «You may make copies of This Product (unmodified) and distribute copies of
> This Product (unmodified) **that are not included in another product forming
> Your Product** (except as permitted under Chapter III). ... You may use This
> Product freely ... on any number of computers/systems for non-commercial
> and/or commercial purposes.»

То есть распространение неизменённых копий разрешено, если копия не входит в
состав чужого продукта. Флешка — носитель с набором самостоятельных
утилит, а не продукт, включающий VeraCrypt, поэтому наша схема под запрет не
попадает. Это та оговорка, которой не хватает в случае Nmap и Sysinternals.

Платных редакций у VeraCrypt нет, поэтому вопрос «целесообразна ли бесплатная
редакция» решается однозначно: другой просто не существует. Чего нет вместе с
бесплатностью — центрального хранилища ключей, удалённого восстановления,
политик и поддержки; заголовки томов резервируются вручную.

В 1.26.29 закрыт `CVE-2026-54073`: быстрое форматирование скрытого тома писало
нулевые секторы с интервалом 128 МиБ, что раскрывало наличие скрытого тома
(регрессия с 1.26.6). Использовать версию не ниже 1.26.29 именно поэтому.

## Аналоги

| Утилита | Когда предпочесть |
|---------|-------------------|
| BitLocker | Windows Pro/Enterprise, штатное шифрование, TPM, управление через домен |

| Зашифрованный архив 7-Zip | Нужно передать несколько файлов, а не работать с томом |
