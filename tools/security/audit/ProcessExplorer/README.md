# Process Explorer

## Назначение

Диспетчер задач, каким он должен быть: дерево процессов с путями к файлам,
загруженные DLL, открытые дескрипторы, потоки, цифровые подписи, обращения к
сети. Отвечает на вопросы «что это за процесс», «кто держит файл» и «почему
станция тормозит».

## Когда применять

- Загрузка процессора или памяти, а диспетчер задач не показывает виновника.
- Файл не удаляется: кто-то его держит.
- Подозрительный процесс: где лежит, кем подписан, что загрузил.
- Нужно найти родительский процесс: кто кого породил.
- Поиск строки в памяти или дескриптора: `Find → Find Handle or DLL`.

## Запуск

```cmd
procexp64.exe
```

- Требуются права администратора: **да**, иначе не видны процессы других
  пользователей и часть сведений
- Работает из-под WinPE: **не проверено**
- Работает с флешки без установки: **да**
- Требует .NET / VC++ Redist: **нет**

## Ключи и типовые сценарии

| Задача | Что делать |
|--------|------------|
| Убрать своё из виду | `Options → Hide Microsoft Entries` — оставить стороннее |
| Проверить подписи | `Options → Verify Image Signatures`, потом колонка `Verified Signer` |
| Кто держит файл | `Find → Find Handle or DLL` → имя файла |
| Что загрузил процесс | Двойной щелчок → вкладка `DLLs` |
| Потоки и загрузка | Двойной щелчок → вкладка `Threads` |
| Сетевые обращения | Двойной щелчок → вкладка `TCP/IP` |
| Заменить диспетчер задач | `Options → Replace Task Manager` |
| Снимок состояния | `File → Save As` |

Полезная связка: `Autorunsc.exe` показал запись автозапуска → `Process
Explorer` показал, работает ли она сейчас и из какого файла.

## Результаты и как их читать

| Признак | Что значит |
|---------|-------------|
| `No signature` в колонке подписей | Проверять первым |
| Путь в `%TEMP%`, `%APPDATA%` | Подозрительно |
| `Verified Signer` не совпадает с ожидаемым издателем | Подмена или пересборка |
| Процесс без описания и без компании | Смотреть DLL и сетевые вкладки |
| Высокая нагрузка на диск у системного процесса | Чаще антивирус или индексация, чем заражение |

## Риски и предупреждения

> **`Replace Task Manager` меняет систему заказчика.** Включать только с его
> согласия и выключать после работы: иначе у человека диспетчер задач будет
> вести себя непривычно.

> **Завершение процесса — действие, а не просмотр.** Незакрытая программа
> теряет несохранённые данные. Завершать только то, что заказчик согласился.

> **Закрытие дескриптора может повредить данные.** Функция есть, но применять
> её к чужим файлам без нужды нельзя.

> Утилита показывает чужие процессы и пути. Не использовать просмотр как повод
> разбирать личные файлы заказчика.

**Откуда ожидаемая сумма.** Манифест пакета `Microsoft.Sysinternals.ProcessExplorer` версии `17.14` в
репозитории `microsoft/winget-pkgs`, поле `InstallerSha256`; URL в манифесте
совпадает с нашим. Это сторонний каталог по правилу §4, а не сайт вендора,
поэтому источник указан явно. Версия пакета совпадает с нашей, поэтому сумма
относится именно к нашему файлу. Прочитано через `api.github.com`
2026-10-16: `raw.githubusercontent.com` из рабочей среды недоступен.

**Почему строка остаётся `planned`.** Сумма известна, а размер — нет:
`манифест WinGet` размера не содержит, сайт вендора вне белого списка рабочей среды, а
сторонние каталоги дают противоречащие числа: `ProcessExplorer.zip` описывают как 3.3 МБ без разброса, но это каталог, а не первоисточник. Заполнять `size_bytes`
числом без источника §4 запрещает, поэтому строка остаётся `planned` с этой
причиной. Размер появится после скачивания файла — вместе со сверкой суммы.
**Версия сверена 2026-10-15 по первоисточнику** — официальный индекс утилит
Sysinternals на `learn.microsoft.com/sysinternals/downloads/` указывает
`Process Explorer v17.14 (September 10, 2026)`. Расхождение источников снято:
17.1 относился к выпуску 05.03.2026, актуален 17.14. В `manifest.csv` версия
до этой сверки не была заполнена вовсе (`unversioned`).

**Что именно разрешает лицензия.** Microsoft Sysinternals Software License —
freeware: использование бесплатное, в том числе в бизнесе, число запусков и
машин не ограничено. Запрещены две вещи: распространение — Microsoft не выдаёт
лицензии на распространение, поэтому третьим лицам нельзя включать утилиты в
свои продукты и выкладывать у себя; и снятие брендирования — утилиты нельзя
переупаковывать под своим именем, убирать знаки и сведения о Microsoft.

> «Microsoft does not offer any type of distribution license, which means that
> third-party entities are not permitted to distribute the utilities in their
> software or through their websites» — `techtarget.com/searchwindowsserver/
> definition/Windows-Sysinternals`.
>
> «According to the Sysinternals licensing terms, redistribution is not
> permitted without explicit permission» — ответ Microsoft Q&A от 2025-11-12,
> там же адрес для запроса: `licensing@microsoft.com`.

Текст самого лицензионного соглашения по первоисточнику не прочитан:
`learn.microsoft.com` недоступен из рабочей среды (`http=000`), поэтому обе
формулировки — из вторичных источников. Это не отменяет вывода, но и не
заменяет чтения EULA перед тем, как принимать решение.

**Последствие для нас то же, что у Nmap:** мы планировали хранить
`ProcessExplorer.zip` на флешке мастера, а флешка выезжает к заказчикам, то есть речь о
распространении копии. В отличие от NPSL, в лицензионном соглашении
Sysinternals оговорки про архивную форму нет. Риск принят заказчиком
2026-10-15 и записан в `research/23-license-scope.md`, N21.

Прежняя формулировка «по сторонним данным» снята: вместо неё — конкретные
формулировки с указанием источника и явная пометка о том, что EULA не прочитан.
