# audit/ — что в системе настроено и что работает

Задача — **увидеть**, а не почистить. Чистка делается на Этапе 4.3 в
[`../../os/windows/`](../../os/windows/); здесь диагностика.

В Strelec 2026.02.05 Sysinternals **нет вообще** — проверено по
[`../../diagnostics/strelec-tools.md`](../../diagnostics/strelec-tools.md).
Дублирования нет.

## Утилиты

| Утилита | Задача | Файл |
|---------|--------|------|
| [`Autoruns/`](Autoruns/) | Всё, что стартует вместе с системой, плюс `Autorunsc.exe` для отчёта в файл | `Autoruns.zip` |
| [`ProcessExplorer/`](ProcessExplorer/) | Процессы, потоки, DLL, дескрипторы | `ProcessExplorer.zip` |
| [`TCPView/`](TCPView/) | Кто держит сетевые соединения | `TCPView.zip` |

Все три — Microsoft Sysinternals, портативные, устанавливаются распаковкой.

## Лицензия Sysinternals

Freeware, разрешено использование в том числе в бизнесе, включая развёртывание
по парку машин. Ограничение другое: **нельзя распространять их третьими лицами и
нельзя убирать брендирование Microsoft**.

С 2026-10-16 профиль некоммерческий, поэтому ограничение для нашего случая
**не применяется**: флешка личная, копия никому не передаётся, значит
распространения нет (`research/25-profile-change.md`, категория B). Утилиты
лежат здесь без оговорок. Прежняя запись держала риск распространения
(находка N21) и решение C2 «оставить с записанным риском» — основание обоих
отпало, пометка к N21 добавлена.

Оговорка: обязательство вернётся, если флешка когда-либо будет передана
другому человеку или её содержимое выложено публично.

Текст EULA по первоисточнику не проверен: `microsoft.com` недоступен из рабочей
среды.

## Чем закрываем, если Sysinternals под рукой нет

| Задача | Средство ОС |
|--------|-------------|
| Автозапуск | `Get-CimInstance Win32_StartupCommand`, `msconfig`, планировщик заданий |
| Службы | `Get-Service`, `services.msc` |
| Процессы и их пути | `Get-Process \| Select Path`, диспетчер задач |
| Открытые порты | `netstat -ano`, см. [`../../network/diagnostics/`](../../network/diagnostics/) |
| Драйверы | `Get-WmiObject Win32_SystemDriver` |
| Установленное ПО | `Get-ItemProperty HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*` |
| События безопасности | `Get-WinEvent -LogName Security` |

Средств ОС достаточно для беглого осмотра. Sysinternals нужен, когда надо
увидеть **всё** сразу и выгрузить в файл.

## Порядок аудита

1. `Autorunsc.exe -accepteula -a * -c > autoruns.csv` — снять полный список
   автозапуска в файл, пока ничего не меняли.
2. Прочитать CSV, а не интерфейс: так видно всё сразу и есть что приложить к
   отчёту.
3. `Process Explorer` — что работает сейчас, что грузит процессор и память, у
   какого процесса нет цифровой подписи.
4. `TCPView` — куда станция стучится прямо сейчас.
5. Сопоставить: запись в автозапуске → процесс → соединение. Цепочка и есть
   ответ на вопрос «что это за программа».

## Правила

> **Сначала снять состояние, потом менять.** Список автозапуска в файл — до
> любых отключений. Иначе восстановить «как было» нечем.

> **Отключение записи автозапуска — изменение системы заказчика.** Делать
> только то, что заказчик согласился отключить, и записывать что именно.

> Не отключать записи, назначение которых не понятно. Часть из них нужна
> драйверам оборудования и службам заказчика.

> `Autorunsc.exe` без `-accepteula` в первом запуске покажет окно EULA и
> сломает скрипт. Ключ обязателен.
