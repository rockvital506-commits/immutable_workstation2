# Autoruns

## Назначение

Показывает **всё**, что запускается вместе с системой: ключи `Run` и `RunOnce`,
службы, драйверы, планировщик заданий, расширения проводника, BHO, провайдеры
Winsock, кодеки, уведомления Winlogon. Дальше обычного `msconfig` и диспетчера
задач на порядок.

Вторая половина ценности — `Autorunsc.exe`: тот же анализ из командной строки с
выгрузкой в CSV. Это то, что нужно в отчёте владельцу.

## Когда применять

- Станция тормозит, а что именно грузится — не видно.
- Подозрение на заражение: что стартует без подписи и из подозрительных путей.
- «После установки программы стало плохо» — что она за собой оставила.
- Нужен снимок состояния системы **до** правок, чтобы было с чем сравнить.
- Отчёт владельцу по результатам аудита.

## Запуск

```cmd
Autoruns64.exe
```

Снять полный список автозапуска в файл:

```cmd
Autorunsc64.exe -accepteula -a * -c > "%USERPROFILE%\Desktop\autoruns.csv"
```

- Требуются права администратора: **да**, иначе часть разделов не видна
- Работает из-под WinPE: **не проверено**
- Работает с флешки без установки: **да**
- Требует .NET / VC++ Redist: **нет**

## Ключи и типовые сценарии

| Задача | Команда |
|--------|---------|
| Всё в CSV | `Autorunsc64.exe -accepteula -a * -c > all.csv` |
| Всё в XML | `Autorunsc64.exe -accepteula -a * -x all.xml` |
| Только без подписи | `Autorunsc64.exe -accepteula -a * -c \| findstr /i "no signature"` |
| Только автозапуск пользователя | `Autorunsc64.exe -accepteula -a * -u -c > user.csv` |
| Конкретный пользователь | `Autorunsc64.exe -accepteula -u DOMAIN\user -a * -c` |
| Сравнить две станции | снять CSV на обеих, сравнить |

В интерфейсе: `Options → Hide Microsoft Entries` — оставить только стороннее,
это первое, что делают при поиске лишнего. `Options → Verify Code Signatures` —
подсветить записи без подписи.

## Результаты и как их читать

| Признак | Что значит |
|---------|-----------|
| Нет цифровой подписи | Не приговор, но проверять первым |
| Путь в `%TEMP%`, `%APPDATA%`, `C:\Users\Public` | Подозрительно: штатные программы там не живут |
| Имя файла не совпадает с описанием | Признак подмены |
| Запись есть, а файла на диске нет | Остаток удалённой программы либо маскировка |
| Издатель неизвестен | Смотреть, что это, до отключения |

Для отчёта владельцу достаточно CSV с включённой проверкой подписей и списка
того, что отключено.

## Риски и предупреждения

> **Отключение записи — изменение системы владельца.** Делать только то, что он
> согласился отключить, и записывать что именно. Восстановить «как было» без
> предварительного CSV будет нечем.

> **Не отключать непонятное.** Часть записей нужна драйверам оборудования,
> службам шифрования и программам владельца. Отключённый драйвер выглядит как
> «сломалось само».

> **Удаление записи не удаляет файл.** Это только отключение автозапуска.
> Программа остаётся на диске.

> **`-accepteula` обязателен** в первом запуске `Autorunsc.exe`: без него
> появится окно лицензионного соглашения и скрипт встанет.

**Откуда ожидаемая сумма.** Манифест пакета `Microsoft.Sysinternals.Autoruns` версии `14.3` в
репозитории `microsoft/winget-pkgs`, поле `InstallerSha256`; URL в манифесте
совпадает с нашим. Это сторонний каталог по правилу §4, а не сайт вендора,
поэтому источник указан явно. Версия пакета совпадает с нашей, поэтому сумма
относится именно к нашему файлу. Прочитано через `api.github.com`
2026-10-16: `raw.githubusercontent.com` из рабочей среды недоступен.

**Почему строка остаётся `planned`.** Сумма известна, а размер — нет:
`манифест WinGet` размера не содержит, сайт вендора вне белого списка рабочей среды, а
сторонние каталоги дают противоречащие числа: `Autoruns.zip` описывают как 2.80, 2.86, 3 и 3.04 МБ. Заполнять `size_bytes`
числом без источника §4 запрещает, поэтому строка остаётся `planned` с этой
причиной. Размер появится после скачивания файла — вместе со сверкой суммы.
**Версия сверена 2026-10-15 по первоисточнику** — официальный индекс утилит
Sysinternals на `learn.microsoft.com/sysinternals/downloads/` указывает
`Autoruns v14.3 (June 17, 2026)`. Прежняя пометка «не сверена» снята:
`download.sysinternals.com` по-прежнему недоступен из рабочей среды
(`http=000`), но индекс — это страница Microsoft, а не сторонний каталог.
Адрес загрузки отдаёт актуальную версию, поэтому при скачивании позже этой
даты версию надо перепроверить по тому же индексу.

С v14.2 Autoruns показывает упакованные приложения Windows (MSIX/AppX) в
автозапуске, а v14.3 выровнял командный `autorunsc` с возможностями
интерфейса. Для аудита автозапуска станции с приложениями из магазина это
содержательное изменение: прежние версии таких записей не показывали.

**Что именно разрешает лицензия.** Microsoft Sysinternals Software License —
freeware: использование бесплатное, в том числе в бизнесе, число запусков и
машин не ограничено. Запрещены две вещи: распространение — Microsoft не выдаёт
лицензии на распространение, поэтому третьим лицам нельзя включать утилиты в
свои продукты и выкладывать у себя; и снятие брендирования — утилиты нельзя
переупаковывать под своим именем, убирать знаки и сведения о Microsoft.

> «Microsoft does not offer any type of distribution license, which means that
> third-party entities are not permitted to distribute the utilities in their
> software or through their websites» — `techtarget.com/searchwindowsserver/
> definition/Windows-Sysinternals`.
>
> «According to the Sysinternals licensing terms, redistribution is not
> permitted without explicit permission» — ответ Microsoft Q&A от 2025-11-12,
> там же адрес для запроса: `licensing@microsoft.com`.

Текст самого лицензионного соглашения по первоисточнику не прочитан:
`learn.microsoft.com` недоступен из рабочей среды (`http=000`), поэтому обе
формулировки — из вторичных источников. Это не отменяет вывода, но и не
заменяет чтения EULA перед тем, как принимать решение.

**Последствия для нас больше нет.** Прежний вывод строился на том, что флешка
выезжает к заказчикам, то есть `Autoruns.zip` распространяется, а лицензия
Sysinternals распространение третьими лицами запрещает. С 2026-10-16 профиль
некоммерческий: флешка личная, копия никому не передаётся, распространения
нет (`research/25-profile-change.md`, категория B). Запрет Microsoft не
отменён, но к личному использованию не применяется.

Риск, принятый 2026-10-15 и записанный в `research/23-license-scope.md`,
N21, больше не актуален — к находке добавлена пометка об этом. Оговорка:
обязательство вернётся, если флешка когда-либо будет передана другому
человеку или её содержимое выложено публично.

Прежняя формулировка «по сторонним данным» снята: вместо неё — конкретные
формулировки с указанием источника и явная пометка о том, что EULA не прочитан.

## Аналоги

| Утилита | Когда предпочесть |
|---------|-------------------|
