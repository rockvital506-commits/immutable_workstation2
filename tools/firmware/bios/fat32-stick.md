# Отдельная FAT32-флешка для файлов прошивки

Решение владельца от 2026-10-14. Наша основная флешка для файла прошивки не
годится: утилита прошивки MSI требует **FAT32**, а у нас `Ventoy` — exFAT,
`Tools` — NTFS, `VTOYEFI` — FAT16 на 32 МБ и помечен «не изменять».

Поэтому в комплекте — **вторая, маленькая флешка**, только для
прошивок.

## Зачем не менять основную

| Вариант | Почему отклонён |
|---------|-----------------|
| Переформатировать раздел `Ventoy` в FAT32 | Ventoy это поддерживает, но FAT32 даёт лимит 4 ГБ на файл, а наши ISO больше; переформатирование уничтожает образы |
| Переустановить Ventoy с зарезервированным местом | Уничтожает и `ISO`, и `Tools` — всё наполнение пришлось бы раскладывать заново |
| Класть файл в `Tools:` (NTFS) | Документация MSI говорит только про FAT32. Часть сообщества сообщает, что NTFS тоже читается, часть — что нет. Проверять на рабочей станции владельца нельзя |

Вторая флешка — единственный вариант, который ничего не ломает.

## Требования

| Параметр | Значение |
|----------|----------|
| Ёмкость | 1–8 ГБ, больше не нужно |
| Файловая система | **FAT32**, не exFAT и не NTFS |
| Содержимое | Только распакованный файл прошивки, **в корне** |
| Разметка | Одна таблица, один раздел |

Файл прошивки обычно десятки мегабайт, так что 1–8 ГБ хватает с запасом, а
Windows форматирует в FAT32 носители до 32 ГБ без сторонних инструментов.

## Подготовка

1. Вставить флешку, убедиться, что на ней ничего нужного — форматирование
   стирает всё.
2. `Проводник` → правый клик по носителю → `Форматировать`.
3. `Файловая система` — **FAT32**, `Размер кластера` — по умолчанию,
   `Быстрое форматирование` — включить.
4. Проверить результат:

   ```cmd
   fsutil fsinfo volumeinfo E: | findstr /i "File System Name"
   ```

   Ожидается `FAT32`.

## Правило использования

> **Ничего лишнего на этой флешке.** Утилита прошивки MSI ищет файл в корне и
> путается, если рядом посторонние каталоги. Одна прошивка — один файл в
> корне, после работы удалить.

> **Файл распаковать.** В корне должен лежать сам файл прошивки, а не ZIP-архив.

> **Не переименовывать.** Имя вроде `MSI.ROM` нужно только для Flash BIOS
> Button на платах, которые его поддерживают. Для прошивки из UEFI имя файла
> должно совпадать со строкой версии BIOS в самом BIOS — переименованный файл
> не найдётся.

> **Это не загрузочный носитель.** Делать его загрузочным не нужно и вредно:
> лишние файлы в корне мешают утилите прошивки.

## Если утилита прошивки не видит флешку

Проверить по порядку, именно в этой последовательности — так чаще всего и
находится причина:

1. Файловая система — FAT32, а не exFAT/NTFS.
2. Файл распакован, а не оставлен в архиве.
3. Файл в **корне**, а не в подкаталоге.
4. Имя файла **не изменено**.
5. Файл скачан для **точной** модели и ревизии платы.
6. Попробовать другой USB-порт — желательно USB 2.0 на задней панели, не через
   хаб.
7. Попробовать другую флешку. Утилита прошивки MSI привередлива к конкретным
   носителям, и это документированно не объясняется.

## Что делать, если второй флешки под рукой нет

Файл прошивки можно положить в корень диска `C:` станции — утилита прошивки
MSI читает локальные разделы. Это обходной путь: он требует работающей Windows
и оставляет файл на диске владельца, который потом надо удалить.

> **Не использовать для этого наш носитель.** Ни exFAT-раздел `Ventoy`, ни
> NTFS-раздел `Tools` документированно не поддерживаются.

## Не проверено на месте

| Пункт | Что нужно |
|-------|-----------|
| Поведение утилиты прошивки с GPT-носителем из нескольких разделов | Только отдельные сообщения сообщества |
| Читает ли конкретная плата NTFS | Расхождение документации и практики |
| Минимальный размер флешки, который видит BIOS целевой станции | Проверить на MSI B12M-211RU |
