# bios/ — прошивка BIOS/UEFI материнской платы

Единственная подкатегория группы `firmware/`. Утилит здесь нет намеренно:
прошивка выполняется **средством самой платы**, из её UEFI.

> **База пути.** Непомеченные пути в этом документе считаются от каталога
> этого модуля. Пути от корня репозитория и пути на разделы флешки помечаются
> префиксами `CONVENTIONS.md` §10.1.

## Чем шьём

| Средство | Когда | Риск |
|----------|-------|------|
| **Утилита прошивки в UEFI** (у MSI — `Advanced → UEFI BIOS Update` на ноутбуках, `M-FLASH` на платах) | Штатный способ | Минимальный: работает вне ОС |
| `Windows Update → Дополнительные обновления → Micro-Star International Firmware` | Если на станции есть интернет и обновления не сужены | Средний: срыв в Windows хуже, чем в UEFI |
| `Intel FPT` (`fptw64.exe`) | **Только восстановление и бэкап**, не штатное обновление | Высокий: пишет напрямую в SPI |
| DOS-утилиты (`afudos` и подобные) | Не используем | Устаревший путь |

`MSI Center` / `Live Update` не используем: это установка вендорского ПО на
станцию заказчика, что противоречит правилу проекта о мусоре.

## Шаг 0. Инвентаризация

**До любых изменений.** Скрипт `scripts/bios-inventory.ps1` (и парный `scripts/bios-inventory.sh`):

```powershell
powershell -ExecutionPolicy Bypass -File bios-inventory.ps1 -OutDir E:\tools\firmware\reports
```

```bash
sudo bash bios-inventory.sh --out /mnt/tools/firmware/reports
```

Снимает модель платы, версию и дату BIOS, Secure Boot, TPM, BitLocker,
Intel ME (только из Windows), прошивки накопителей и печатает чек-лист
настроек UEFI, которые надо записать от руки.

Коды возврата: `0` — успех, `1` — ошибка записи, `2` — нет нужных средств,
`3` — каталог недоступен.

## Шаг 1. Приостановить BitLocker

Если шифрование включено — приостановить **один раз на весь выезд**:

```powershell
Suspend-BitLocker -MountPoint "C:" -RebootCount 0
```

Обновление прошивки меняет измерения загрузки в TPM. При привязке к PCR 7/11
обновление прошивки вендора терпимо, при уходе на PCR 0,2,4,11 станция уходит
в восстановление BitLocker и требует ключ при каждой загрузке.

## Шаг 2. Сбросить нестандартные настройки

Официальное требование MSI: **перед** обновлением вернуть все изменённые
дополнительные настройки (андервольтинг, разгон) к значениям по умолчанию.
Порядок MSI: `Save & Exit → Load Optimized Defaults → Yes`, затем
`Save Changes and Restart`, и после перезагрузки снова войти в BIOS.

## Шаг 3. Подготовить носитель

> **Наша флешка не годится.** Утилита прошивки MSI требует **FAT32**, а у нас
> `Ventoy` — exFAT, `Tools` — NTFS, `VTOYEFI` — FAT16 на 32 МБ «не изменять».
>
> Нужна **отдельная маленькая FAT32-флешка**. Подготовка и проверка —
> [`fat32-stick.md`](fat32-stick.md).

## Шаг 4. Скачать файл прошивки

`msi.com` → поиск по точной модели → `Support` / `Drivers & Downloads` →
вкладка `BIOS` → скачать → **распаковать ZIP** → **все** распакованные файлы
в **корень** флешки, не в подкаталог.

> **Не переименовывать файл.** Имя вроде `MSI.ROM` нужно только для Flash BIOS
> Button. Для прошивки из UEFI имя файла должно совпадать со строкой версии
> BIOS в самом BIOS — переименование гарантирует, что файл не найдётся.

## Шаг 5. Прошить

Официальная последовательность MSI для ноутбуков:

1. Логотип MSI — непрерывно жать `Delete` до входа в BIOS.
2. `Advanced` → `UEFI BIOS Update` → `UEFI BIOS Update`.
3. Выбрать флешку с файлом.
4. Выбрать файл прошивки, подтвердить `Yes`.
5. Станция уйдёт в перезагрузку и сама войдёт в программу прошивки —
   нажать `Enter` на `Proceed with flash update`.

Во время прошивки: питание от сети подключено, ничего не нажимать, флешку не
вынимать.

## Шаг 6. После прошивки

1. Войти в BIOS, **сверить версию** с той, что ставили.
2. **Вернуть настройки UEFI по чек-листу из снимка** — прошивка возвращает их
   к значениям по умолчанию. Критично для нашей задачи:
   - `Intel VMD controller` — при `Enabled` установщику Windows нужен драйвер
     IRST/VMD в образе, иначе накопитель не виден;
   - `Secure Boot` — состояние и режим ключей;
   - порядок загрузки и загрузочная запись Windows;
   - `SATA Mode`, `Fast Boot`, `CSM/Legacy`.
3. Загрузить Windows.
4. **Возобновить BitLocker**, если приостанавливали:
   ```powershell
   Resume-BitLocker -MountPoint "C:"
   ```
5. Сверить снимок: снова запустить `bios-inventory` и сравнить с прежним.

## Бэкап SPI — средство восстановления, не штатный путь

`Intel FPT` читает и пишет SPI-флеш через интерфейс ME. Ценен тем, что даёт
полный бэкап до изменений:

```cmd
fptw64.exe -i
fptw64.exe -d backup_20261014.bin
```

Но:

- **версия FPT обязана соответствовать версии ME**, иначе `Error 26`;
- на многих платах запись заблокирована Flash Descriptor / BIOS Lock —
  `Error 25: The host CPU does not have read access to the target flash area`;
- в WinPE нужно вручную загрузить драйвер: `drvload HECI.inf`;
- ошибка при записи — это «кирпич», а не откат.

> **Для штатного обновления BIOS FPT не использовать.** Только бэкап и
> восстановление, когда утилита вендора уже не помогает.

> **Лицензия не проверена.** FPT распространяется в составе Intel ME System
> Tools как инструмент для разработчиков и производителей плат; условий для
> сервисного выезда в первоисточнике найти не удалось, сайт Intel из рабочей
> среды недоступен. Проверить до того, как класть на коммерческий носитель.

## Правила

> **Сначала снимок, потом прошивка.** Без `bios-inventory` до изменений
> после прошивки не с чем сверить и нечего возвращать.

> **Не прошивать без конкретного повода.** Обновление BIOS откатывает часть
> работы предыдущих этапов проекта — настройки UEFI возвращаются к значениям
> по умолчанию.

> **Не прерывать.** Питание от сети обязательно, клавиатуру и мышь не трогать,
> флешку не вынимать. Если процесс выглядит зависшим — подождать ещё 3–5 минут
> до принудительного выключения.

> **Прошивка не лечит софт.** Если неисправность не связана с прошивкой по
> описанию версии, обновление её не исправит, а настройки собьёт.

## Не проверено на месте

| Пункт | Что нужно |
|-------|-----------|
| Версии BIOS и ME на целевой станции | Прогон `bios-inventory` на MSI B12M-211RU |
| Точное имя файла прошивки для B12M-211RU | `msi.com` недоступен из рабочей среды |
| Есть ли в BIOS этой модели пункт `Advanced → UEFI BIOS Update` | Проверить на станции |
| Наличие `fptw64.exe` и `MEInfoWin` в Strelec 2026.02.05 | Проверить в выезде |
| Читает ли BIOS конкретной платы NTFS-раздел | Расхождение документации и практики; проверять на рабочей станции нельзя |
| Поведение после прошивки на Win11 IoT Enterprise LTSC 2024 | Пробный прогон |
