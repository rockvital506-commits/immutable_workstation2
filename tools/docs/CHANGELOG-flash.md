# Журнал изменений флешки

Ведётся по вехам, не по каждому коммиту. Правило: запись появляется, когда
изменилось **содержимое флешки** или **правило, по которому оно
наполняется**. Правки формулировок и исправления опечаток не записываются.

> **База пути.** Непомеченные пути в этом документе считаются от корня
> репозитория. Префиксы `CONVENTIONS.md` §10.1 применяются там, где путь
> указывает на раздел флешки.

Дата берётся из истории git. Полная история — `git log`.

## Как вносить запись

```
## <дата> — <что изменилось одной строкой>

Что добавилось или изменилось на флешке, в двух-пяти пунктах.
Решение владельца, если оно было причиной.
Что из этого следует для выезда.
```

Запись вносится **по возвращении с выезда** или сразу после изменения
содержимого — см. [field-checklist.md](field-checklist.md).

## 2026-10-16 — Правило перехода строк манифеста и первые ожидаемые суммы

- В `CONVENTIONS.md` §4 объявлено правило **«Когда строка становится
  `present`»** — четыре условия: заглушка, официальный URL, ожидаемая сумма с
  пометкой об источнике и размер с пометкой. До этого §4 задавал только
  обязательность полей, а условия перехода не было вовсе, поэтому строки не
  могли покинуть `planned` даже при полностью известных данных.
- Размер добавлен четвёртым условием не для формы: `scripts/csv-check.py`
  отвергает `present` с `size_bytes=0`. Первое применение правила это и
  вскрыло — суммы нашлись у пяти утилит, а размеров нет, и строки пришлось
  вернуть в `planned` с записанной причиной.
- **Появились первые ожидаемые суммы утилит**, все из манифестов пакетных
  менеджеров, прочитанных через `api.github.com`: три утилиты Sysinternals,
  `smartmontools`, `WifiInfoView`, `VeraCrypt`, `SDIO`. Версии пакетов
  совпали с нашими, поэтому суммы относятся к нашим файлам. В `present`
  перешли те, у кого размер уже был известен: `smartmontools`, `VeraCrypt`, `Win11Debloat`,
  `LGPO`.
- **У `Win11Debloat` исправлен источник**: в манифесте стояла ссылка на ассет
  релиза `Get.ps1`, а это загрузчик, который скачивает архив из интернета — на
  флешке он бесполезен. Заменён на tarball тега; это единственная утилита, чья
  сумма вычислена нами по фактически скачанному файлу, а основная проверка —
  blob sha из API GitHub.
- Для выезда: **ожидаемая сумма есть у 9 утилит из 22** — `smartmontools`,
  `Win11Debloat`, `LGPO`, `WifiInfoView`, `Autoruns`, `ProcessExplorer`,
  `TCPView`, `VeraCrypt`, `SDIO`. Сверять файл с ней надо сразу после
  скачивания. У пяти из них (`WifiInfoView`, `Autoruns`, `ProcessExplorer`,
  `TCPView`, `SDIO`) сумма есть, а размера нет — каталоги дают противоречащие
  числа, поэтому размер появится только после скачивания; до тех пор строка
  остаётся `planned`.
