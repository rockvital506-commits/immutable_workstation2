# Документация флешки — регламенты и справочники

Каталог живёт на флешке в разделе **Tools** (`tools/docs/`), то есть доступен
с любого ПК без интернета и без репозитория. Решение владельца от 2026-10-15.

> **База пути.** Непомеченные пути в этом документе считаются от корня
> репозитория. Префиксы `CONVENTIONS.md` §10.1 применяются там, где путь
> указывает на раздел флешки.

Эти документы отвечают на вопрос **«что делать»**. Описания отдельных утилит —
в `README.md` их каталогов; здесь только сводные действия.

## Состав

| Файл | Когда открывать |
|------|-----------------|
| [recovery.md](recovery.md) | Станция не работает: не грузится, тормозит, данные под угрозой |
| [reinstall.md](reinstall.md) | Ставим систему заново — на целевую станцию или произвольную |
| [field-checklist.md](field-checklist.md) | Работы со станцией: что взять, что проверить, что записать. Короткий, для печати |
| [compatibility.md](compatibility.md) | Какой образ подойдёт этому железу. Сроки поддержки |
| [flash-update.md](flash-update.md) | Обновить Ventoy или содержимое флешки |
| [flash-backup.md](flash-backup.md) | Резервное копирование разделов, раз в месяц |
| [flash-verify.md](flash-verify.md) | Сверить содержимое флешки с `manifest.csv`; что делать, если сумма не сошлась |
| [CHANGELOG-flash.md](CHANGELOG-flash.md) | Что менялось на флешке и когда |
| [summary.md](summary.md) | Итог сборки: что есть, что проверено, что осталось сделать |

## Порядок чтения при работе

1. `field-checklist.md` — до начала работ и по завершении.
2. `compatibility.md` — прежде чем выбирать образ.
3. `recovery.md` — если станцию надо спасти.
4. `reinstall.md` — если спасать нечего или нужна чистая система.

## Обслуживание самой флешки

`flash-update.md`, `flash-backup.md` и `flash-verify.md` — про носитель, а не
про станции. Полная сверка раз в месяц: `repo-validate` → `csv-check` →
`check-flash --verify`; что делать при расхождении — в
[flash-verify.md](flash-verify.md).

Код возврата 0 у `check-flash` при нуле сверенных сумм — **не признак
благополучия**, а отсутствие файлов для сверки. Чем именно покрыты 29 строк
с суммой и почему 17 строк `PENDING` не покрыты ничем — там же.
