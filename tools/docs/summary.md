## 6. Что не проверено

Полный перечень — в разделе «Не проверено» каждого документа; здесь главное.

| Не проверено | Почему |
|---|---|
| Все 16 файлов `.ps1` | В среде сборки нет PowerShell |
| `check-flash` на реальной флешке | Флешка не подключалась, проверка ни разу не выполнялась |
| Сверка SHA256 с реальным файлом | Все `planned`-файлы не скачаны: сверять нечего |
| Загрузка образов (UEFI и Legacy BIOS) | Требует реального железа |
| Файлы ответа на установщике Windows | Не применялись ни разу |
| Поведение 24H2 при GVLK в `specialize` | Не проверялось |
| `slmgr` и `wmic` | Не выполнялись |
| Ключ в прошивке станции | Не читался |
| Дамп GPT и бэкап разделов | Не снимались |
| Clonezilla на exFAT 340 ГБ и время образа 128 ГБ | Не измерялось |
| Ёмкость внешнего диска для бэкапа | Не измерялась |

**Контрольная точка, которой нет:** размер всех семи ISO в манифесте равен 0.
Правило `csv-check.py` требует ненулевой размер только для `present`, поэтому
проверка проходит. Следствие: неполную загрузку образа нечем обнаружить, кроме
сверки SHA256, а SHA256 образов тоже не заполнен. Заполняйте оба поля в момент
скачивания — это единственная защита от «файл скачался наполовину».

## 7. Что осталось сделать перед эксплуатацией

Порядок обязателен: пункт 3 нельзя выполнить до пункта 2.

1. **Скачать 30 файлов** со статусом `planned` по URL из `manifest.csv`
   и проставить в манифесте `size_bytes` и `sha256` каждого.
2. **Снять дамп GPT и копию конфигурации** по `tools/docs/flash-backup.md`.
3. **Прогнать `check-flash` на подключённой флешке** — после пункта 1 он
   обязан сверить все 30 сумм.
4. **Проверить загрузку** каждого образа в UEFI и Legacy BIOS.
5. **Пройти алгоритм сборки** на целевой станции и заполнить `checklist.md`.

Только после пункта 5 флешку можно считать готовой к эксплуатации.
