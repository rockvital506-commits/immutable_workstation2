## Чем делать разметку под установку Windows

Для целевой задачи — чистая разметка NVMe перед установкой — используется
`diskpart`, потому что он предсказуем и скриптуется:

```
diskpart
list disk
select disk 0
clean
convert gpt
create partition efi size=260
format quick fs=fat32 label="System"
create partition msr size=16
create partition primary
format quick fs=ntfs label="Windows"
exit
```

Подробно — в `ventoy-partition/builds/MSI_B12M-211RU_Win11_LTSC_IoT_24H2/algorithm.md`,
шаг 5.

## Конвертация MBR → GPT

| Способ | Когда |
|--------|-------|
| `mbr2gpt.exe` из Windows | ОС работает, данные надо сохранить. Есть в составе Windows 10/11 |
| `DiskGenius` | ОС не грузится, данные надо сохранить |
| `clean` + `convert gpt` | Данные не нужны или уже в бэкапе — самый надёжный путь |

`mbr2gpt` проверяет пригодность перед конвертацией:

```
mbr2gpt /validate /disk:0 /allowFullOS
```

## Правила

> **Образ диска перед любой правкой разделов.** Изменение размера, слияние,
> конвертация — операции, после которых данные можно потерять безвозвратно.

> Уменьшать раздел с NTFS средствами сторонних утилит безопаснее, чем
> увеличивать: при увеличении ошибка приводит к потере файловой таблицы.

> **Выравнивание разделов — 4096 байт** (а лучше 1 МБ). Несовпадение даёт
> кратный рост записи и заметное падение скорости на SSD.

> На 4Kn-дисках EFI-раздел не может быть меньше 260 МБ.

> Раздел восстановления Windows на 256 ГБ накопителе создавать не обязательно:
> LTSC работает без него, а место в дефиците.
