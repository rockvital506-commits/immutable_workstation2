# boot/ — восстановление загрузки

## Что уже есть в Strelec

| Утилита | Версия в сборке | Когда применять |
|---------|-----------------|-----------------|
| `EasyBCD` | 2.4.0.237 | Основной инструмент для правки BCD |
| `Bootice` | — | Запись загрузчика, правка MBR/PBR, BCD |
| `EasyUEFI` | 6.0 | Порядок загрузки в UEFI, создание и удаление записей |
| Средство восстановления Windows | — | Штатное восстановление запуска |
| `WinNTSetup` | — | Установка Windows с контролем загрузчика |
| `BootIt Bare Metal` | 1.92 (DOS, BIBM++) | Загрузчик и разделы без ОС |
| `CMOS De-Animator` | 3 | Сброс CMOS, когда настройки UEFI не дают загрузиться |

## Портативных дополнений нет

Восстановление загрузчика делается из среды вне ОС — из WinPE или из среды
восстановления. Из живой ОС это либо не нужно, либо уже делается штатными
средствами.

## Диагностика: что именно сломалось

| Симптом | Вероятная причина |
|---------|-------------------|
| «Operating System not found» | Нет загрузочной записи в UEFI или повреждён MBR |
| «BOOTMGR is missing» | Повреждён загрузочный сектор раздела или сам раздел |
| «\Boot\BCD» с кодом ошибки 0xc000000f и ниже | Повреждён или отсутствует BCD |
| Синий экран `INACCESSIBLE_BOOT_DEVICE` | Не тот драйвер контроллера — не загрузчик, а драйверы |
| Циклическая перезагрузка | Повреждён куст SYSTEM или драйвер — см. `../registry/` |
| UEFI не видит диск в списке загрузки | Слетела запись EFI или диск перешёл в другой режим (AHCI/RAID) |

Прежде чем чинить загрузчик, убедиться, что проблема в нём: диск виден в UEFI,
разметка цела, EFI-раздел на месте и содержит `\EFI\Microsoft\Boot\bootmgfw.efi`.

## Приёмы восстановления

### Загрузиться в командную строку

Из Ventoy — ISO Windows → «Восстановление системы» → «Командная строка».
Либо из Strelec.

### Восстановить загрузочные файлы (UEFI + GPT)

```cmd
:: Примонтировать EFI-раздел
diskpart
select disk 0
list volume
select volume 1        :: раздел с меткой System, FAT32
assign letter=S
exit

bcdboot C:\Windows /s S: /f UEFI
```

### Пересоздать BCD

```cmd
bootrec /fixmbr
bootrec /fixboot
bootrec /scanos
bootrec /rebuildbcd
```

`bootrec /fixboot` на Windows 10/11 может вернуть «Отказано в доступе» —
это нормально, тогда помогает `bcdboot`.

### Проверить и починить записи UEFI

```cmd
bcdedit /enum firmware
```

Либо `EasyUEFI`: посмотреть список, поднять нужную запись на первое место,
пересоздать отсутствующую, указав `\EFI\Microsoft\Boot\bootmgfw.efi`.

### Legacy BIOS + MBR

```cmd
bootrec /fixmbr
bootrec /fixboot
```

Либо `Bootice` — записать PBR и MBR явно.

## Особенности станций с Intel VMD

На Intel 11-го поколения и новее установщик и среда восстановления могут не
видеть NVMe-накопитель. Тогда `diskpart` показывает пустой список дисков и
чинить нечего — проблема в драйвере.

Решения: `Enable VMD controller = Disabled` в BIOS, либо подать драйвер
Intel IRST/VMD в среду восстановления.

## Правила

> Перед правкой загрузчика — **образ диска** или хотя бы копия EFI-раздела:
> `diskpart` → `select volume` → либо побайтовая копия через `dd` в Live Mint.

> `bcdboot` предпочтительнее `bootrec /rebuildbcd`: он просто пересоздаёт
> загрузочные файлы, а не пытается угадать, что было.

> После восстановления проверить **обе** ветки: что система грузится и что
> грузится именно та ОС, которая нужна (актуально при двух системах).

> Не смешивать режимы: если диск размечен в GPT, загрузчик должен быть UEFI.
> Попытка записать MBR-загрузчик на GPT-диск ломает загрузку.
