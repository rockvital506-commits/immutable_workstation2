# data_recovery/ — восстановление данных

## Правило номер один

> **Не писать на диск.** Каждая запись снижает шанс возврата. Если данные
> пропали с системного раздела — станцию выключить и работать из WinPE.

## Что уже есть в Strelec

| Утилита | Назначение | Когда предпочесть |
|---------|-----------|-------------------|
| `R-Studio` | Полноценный комплекс восстановления | Основной инструмент, сложные случаи |
| `R.saver` | Восстановление, бесплатный | Простые случаи, удалённые файлы |
| `Runtime GetDataBack` (NTFS / FAT) | Восстановление по ФС | Когда R-Studio не даёт результата |
| `Runtime Captain Nemo` | Быстрое восстановление | Оценка, простые случаи |
| `Runtime RAID Reconstructor` | Сборка RAID без массива | Распался RAID |
| `TestDisk` | Разделы и загрузочные секторы | Пропал раздел, повреждён бут-сектор |
| `DMDE` | Редактор диска и восстановление | Быстрый скан, правка структур |
| `Active File Recovery` | Восстановление | Альтернатива |
| `EaseUS Data Recovery Wizard` | Восстановление с мастером | Когда нужен простой интерфейс |
| `PC3000 Disk Analyzer` | Глубокая диагностика | Подозрение на проблемы с накопителем |

## Порядок работ

| # | Действие | Почему именно так |
|---|----------|-------------------|
| 1 | Прекратить запись на диск | Иначе данные перезапишутся |
| 2 | Проверить SMART | Если диск умирает — сначала образ, потом восстановление |
| 3 | Снять образ диска | Работать по образу безопаснее, можно повторить попытку |
| 4 | Быстрый скан | `DMDE` — оценить, что вообще видно |
| 5 | Полное сканирование | `R-Studio` по образу |
| 6 | Восстановить на **другой** носитель | Запись на исходный диск уничтожает остаток данных |
| 7 | Проверить файлы | Открыть несколько, а не только посмотреть список имён |

## Типовые случаи

| Случай | Что делать |
|--------|-----------|
| Удалён файл, корзина очищена, сразу заметили | Быстрый скан `DMDE` или `R.saver` — высокий шанс |
| Раздел отформатирован | `R-Studio` полным сканом, структура каталогов обычно восстанавливается |
| Диск стал RAW | `TestDisk` — поиск и восстановление загрузочного сектора |
| Пропал раздел | `DMDE` или `TestDisk` — поиск по копиям бут-секторов |
| После сбоя питания не монтируется | Сначала образ, потом `chkdsk` по образу, потом восстановление |
| Флешка не определяется | `MHDD` / `HDAT2` в DOS — возможно, контроллер, а не данные |

## Про HDD Regenerator

`HDD Regenerator` (в Strelec версии 2024 и 2011) переназначает сбойные секторы.
Применять с осторожностью:

- Он **не восстанавливает данные** в повреждённом секторе — данные там теряются.
- Рост переназначенных секторов означает деградацию поверхности: диск доживает.
- Правильный порядок: сначала снять образ, потом думать о ремонте.

## Ограничения

> Восстановление после TRIM на SSD обычно невозможно: контроллер физически
> очищает блоки. Поэтому на SSD шанс возврата удалённого заметно ниже, чем на HDD.

> Шифрованный том (BitLocker) без ключа не восстанавливается: утилиты увидят
> случайные данные.

> Запись на тот же диск в процессе восстановления — самая частая причина
> окончательной потери данных.
