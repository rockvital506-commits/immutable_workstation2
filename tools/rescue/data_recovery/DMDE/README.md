# DMDE

## Назначение

DM Disk Editor and Data Recovery: поиск удалённых и потерянных разделов,
восстановление файлов, побайтовый редактор диска. Работает портативно из
Windows, Linux, macOS и DOS, поэтому запускается **из живой ОС без
перезагрузки** — это и есть причина держать копию на разделе `Tools`.

## Когда применять

- Станция ещё работает, и надо быстро оценить, что пропало, до перезагрузки
  в WinPE.
- Нужен быстрый скан: DMDE находит потерянные разделы за секунды по копиям
  загрузочных секторов.
- Надо посмотреть или поправить дисковые структуры напрямую: MBR, GPT,
  загрузочные секторы, MFT, FAT, каталоги.
- Нужен RAID-конструктор или снятие образа/клона диска.

## Запуск

```
dmde-4-4-4-842-win64-gui.zip  →  распаковать  →  dmde.exe
```

Утилита портативная: запускается сразу после распаковки, ничего не устанавливает.

- Требуются права администратора: **да**
- Работает из-под WinPE: **да**, и в сборке Strelec уже есть своя копия
- Работает с флешки без установки: **да**
- Требует .NET / VC++ Redist: **нет**

## Ключи и типовые сценарии

Утилита графическая. Основные маршруты:

| Задача | Действие |
|--------|----------|
| Быстрый поиск потерянных разделов | выбрать физический диск → «Полное сканирование» не нужно, достаточно открытия диска |
| Найти раздел по копии бут-сектора | «Найденные разделы» → выбрать → «Восстановить» |
| Восстановить удалённые файлы | открыть раздел → пометить файлы → «Восстановить» |
| RAW-поиск по сигнатурам | «Поиск по сигнатурам файлов» |
| Правка дисковых структур | «Диск» → редактор, есть шаблоны структур |
| Снять образ диска | «Диск» → «Создать образ» |
| Карта кластеров | найти файл, занимающий указанный сектор |

## Результаты и как их читать

| Что видно | Смысл |
|-----------|-------|
| Раздел найден в «Найденных» | Есть копия загрузочного сектора или суперблока — раздел восстанавливаем |
| Файлы видны с исходными именами и путями | Цела файловая таблица — восстановление полное, структура каталогов сохраняется |
| Только сигнатуры, без имён | ФС разрушена, возврат по типам файлов, имена потеряны |
| Файл помечен как перезаписанный | Шансов нет, данные уже замещены |

## Ограничения свободной версии

Это главное, что надо знать до начала работы:

> **Бесплатно восстанавливается до 4000 файлов из одного выбранного каталога**,
> с неограниченным числом повторений. То есть по одному каталогу за проход.

> **Восстановление группами и целыми каталогами недоступно** — это платная
> функция. Для массового восстановления нужна лицензия либо `R-Studio`
> из Strelec.

> Для сохранения результатов, отчётов и настроек нужен раздел, поддерживаемый
> ОС; в DOS/Win9x/ME требуется FAT.

Практический вывод: DMDE на разделе `Tools` — инструмент **оценки и точечного**
возврата. Массовое восстановление делается из Strelec.

## Риски и предупреждения

> **Любая запись на исходный диск снижает шанс возврата.** Восстанавливать
> только на другой носитель.

> Редактор диска позволяет испортить диск одной правкой байта. Без понимания
> структуры в редактор не заходить.

> Перед правкой разделов — образ диска.

> Диск с BitLocker без ключа выглядит как случайные данные: восстановить
> что-либо не получится.

> После TRIM на SSD удалённые данные обычно не возвращаются.
