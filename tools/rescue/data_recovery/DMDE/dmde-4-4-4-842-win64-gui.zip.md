## Как получить

Скачать архив для **Windows 64-bit GUI** с официального сайта. Существуют
варианты для DOS, Linux и macOS, а также консольная сборка — для флешки нужен
GUI-вариант под Windows x64.

Имя архива содержит номер версии, поэтому при обновлении меняется и имя.
После обновления править `/manifest.csv` и имя этой заглушки.

## Проверка подлинности

использовать не следует.

## Куда положить на флешке

`Tools:\rescue\data_recovery\DMDE\` — распакованным каталогом, чтобы запускать
`dmde.exe` без распаковки в выезде.

## Напоминание про ограничения

Бесплатно восстанавливается до 4000 файлов из одного каталога за проход;
восстановление группами и каталогами — платная функция. Для массового
возврата данных использовать `R-Studio` из Strelec.
