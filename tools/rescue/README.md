# rescue/ — группа «Аварийные работы»

Снятие паролей, восстановление данных, правка разделов, офлайн-правка реестра,
восстановление загрузки.

## Главное: это группа решений, а не утилит

Аварийные работы почти всегда требуют среды вне целевой ОС — загрузиться в
WinPE, получить доступ к диску без её драйверов и блокировок. Всё необходимое
для этого **уже есть в Strelec**, и в большом количестве: шесть средств сброса
пароля, десять средств восстановления данных, двенадцать редакторов разделов.

Поэтому группа устроена так:

| Что здесь | Где |
|-----------|-----|
| Матрица «симптом → инструмент Strelec» | этот файл и индексы подкатегорий |
| Портативные утилиты для живой ОС | каталоги утилит в подкатегориях |

Портативные утилиты нужны для одного сценария: **станция ещё работает в своей
ОС, и надо оценить масштаб до перезагрузки в WinPE**. Не для того, чтобы
дублировать Strelec.

| Подкатегория | Что закрывает | Портативно здесь |
|--------------|---------------|------------------|
| [`password/`](password/) | Сброс и обход паролей локальных учётных записей | `NTPWEdit` |

| [`partition/`](partition/) | Разделы, разметка, конвертация MBR/GPT | — |

## Матрица: симптом → что делать

| Симптом | Первая среда | Инструмент |
|---------|--------------|-----------|
| Забыт пароль локальной учётки | Strelec | `Reset Windows Password 7.0.5.702` или `Simplix Password Reset 5.1` |
| Пароль нужен, а станция ещё грузится | живая ОС | `NTPWEdit` (правка SAM офлайн не выйдет, только из PE) |
| Забыт пароль домена | — | Локально не сбрасывается, нужен контроллер домена |
| Удалены файлы, корзина пуста | живая ОС, затем Strelec | `DMDE` для оценки → `R-Studio` / `R.saver` для работы |
| Пропал раздел, диск стал RAW | Strelec | `DMDE` (в Strelec есть) → `DiskGenius` → `TestDisk` |
| Повреждена таблица разделов | Strelec | `TestDisk`, `DiskGenius`, `BootIt Bare Metal` |
| Слетел загрузчик Windows | Strelec | `EasyBCD 2.4.0.237`, `Bootice`, средство восстановления Windows |
| Не грузится после конвертации MBR→GPT | Strelec | `EasyUEFI 6.0`, `Bootice`, правка BCD |
| Надо править реестр незагружаемой ОС | Strelec | `Registry Editor PE`, `reg load` вручную |
| ОС не грузится, надо вытащить данные | Strelec | `Total Commander` + `R.saver` |
| Диск не определяется вообще | Strelec DOS | `MHDD 4.6`, `HDAT2 7.6` |

## Порядок действий при потере данных

Порядок важнее инструмента: нарушение первых двух пунктов делает данные
невосстановимыми независимо от софта.

1. **Не писать на диск.** Ничего не устанавливать, не сохранять, не
   дефрагментировать. Если пропали данные на системном разделе — выключить
   станцию и работать из WinPE.
2. **Снять образ диска**, если есть подозрение на проблемы с накопителем.
   Работать по образу, а не по живому диску.
3. Оценить масштаб быстрым сканом (`DMDE`).
4. Восстанавливать **на другой носитель**, никогда не на тот же диск.
5. Проверить восстановленное: открыть файлы, а не только посмотреть список.

## Правила группы

> Ни один инструмент этой группы не запускается «на пробу». Каждая операция
> здесь либо читает диск, либо меняет его необратимо.

> Перед правкой разделов и таблиц — образ диска. Исключений нет.

> Диск с BitLocker сначала расшифровать или приостановить шифрование: часть
> утилит не понимает зашифрованный том и покажет его как RAW.

> Данные заказчика — не смотреть. Восстанавливать только то, что назвал
> заказчик, и сразу переносить на его носитель.
