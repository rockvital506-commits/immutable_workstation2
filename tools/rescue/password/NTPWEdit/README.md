# NTPWEdit

## Назначение

> **База пути.** Непомеченные пути в этом документе считаются от корня
> репозитория. Префиксы `CONVENTIONS.md` §10.1 применяются там, где путь
> указывает на раздел флешки.

Меняет или снимает пароль локальной учётной записи Windows правкой куста SAM.
Работает с кустом как с файлом, то есть **не требует загрузки целевой системы**.
Одна маленькая утилита вместо тяжёлого комбайна, когда задача ровно одна.

## Когда применять

- Уже загружены в WinPE и надо быстро сменить один пароль.
- Не хочется запускать `Reset Windows Password` ради одной учётной записи.
- Нужен простой и предсказуемый инструмент без дополнительных функций.

## Запуск

```
ntpwed07.zip  →  распаковать  →  ntpwed64.exe
```

Для 32-битных систем — `ntpwed32.exe`.

- Требуются права администратора: **да**
- Работает из-под WinPE: **да**, это основной сценарий
- Работает с флешки без установки: **да**
- Требует .NET / VC++ Redist: **нет**

## Ключи и типовые сценарии

Утилита графическая, ключей командной строки нет.

| Задача | Действие |
|--------|----------|
| Открыть куст | указать путь `X:\Windows\System32\config\SAM`, где `X:` — буква диска целевой ОС |
| Сменить пароль | выбрать учётку → «Сменить пароль» → задать новый |
| Снять пароль | выбрать учётку → оставить поле пустым |
| Разблокировать учётку | выбрать учётку → «Разблокировать» |
| Применить | **«Сохранить изменения»** — без этого правки не записываются |

## Результаты и как их читать

| Что видно | Смысл |
|-----------|-------|
| Список учётных записей заполнен | Куст SAM открыт верно |
| Список пуст | Не тот путь к SAM или куст повреждён |
| «Сохранить изменения» не нажата | Правки останутся только в памяти, на диске ничего не изменится |
| Ошибка записи | Куст заблокирован — система смонтирована или используется |

## Ограничения

> **Только локальные учётные записи.** Доменные не меняются — пароль хранится
> на контроллере домена.

> **Учётные записи Microsoft** локально не сбрасываются, пароль меняется
> через `account.microsoft.com`.

> **Не расшифровывает пароль, а заменяет его.** Узнать старый пароль утилита
> не может.

> **Утилита не обновляется много лет.** Последняя известная версия 0.7.
> На новых сборках Windows работает, но проверять на конкретной системе надо.

## Риски и предупреждения

> **Сброс пароля уничтожает доступ к EFS-зашифрованным файлам** этого
> пользователя безвозвратно. Спросить заказчика до сброса.

> **Сохранённые в DPAPI данные теряются**: пароли браузеров, сертификаты,
> часть настроек приложений. Поэтому бэкап профилей делается **до** работ —
> см. `tools/backup/initial_backup/`.

> **BitLocker.** При включённом шифровании без ключа восстановления данные
> недоступны независимо от пароля.

> **Обязательно нажать «Сохранить изменения»** и корректно закрыть утилиту.
> Незакрытый куст SAM может привести к незагружаемой системе.

> Не оставлять пароль пустым. После входа задать новый вместе с заказчиком.
