# password/ — сброс и обход паролей

## Что уже есть в Strelec

Средств больше, чем нужно. Выбор определяется типом учётной записи и тем,
сохранился ли доступ к данным.

| Утилита | Версия в сборке | Когда применять |
|---------|-----------------|-----------------|
| `Reset Windows Password` | 7.0.5.702 | Основной инструмент: сброс пароля, разблокировка, снятие ограничений |
| `Simplix Password Reset` | 5.1 | Альтернатива, если первая не сработала |
| `Windows Login Unlocker` | 2.3.0.6404 | Разблокировка учётной записи |
| `OO User Manager` | 1.0.1.5491 | Управление учётками: включить администратора, сменить пароль |
| `PCunlocker` | 5.6 | Ещё одна альтернатива |
| `Active Password Changer Professional` | 5.0 | DOS-вариант, когда WinPE не грузится |
| `Kon-Boot for Windows` | 2.5.0 | Обход без смены пароля — вход без знания текущего |

## Портативно на разделе Tools

| Утилита | Зачем |
|---------|-------|
| [`NTPWEdit/`](NTPWEdit/) | Правка SAM из WinPE или из живой ОС, когда не хочется запускать тяжёлый комбайн |

## Выбор способа

| Ситуация | Способ |
|----------|--------|
| Локальная учётка, пароль забыт, данные не шифрованы | `Reset Windows Password` — сброс пароля |
| Надо войти, не меняя пароль заказчика | `Kon-Boot` |
| Учётка заблокирована после неудачных попыток | `Windows Login Unlocker` |
| Нужен администратор, а его нет | `OO User Manager` — включить встроенного |
| WinPE не грузится, есть только DOS | `Active Password Changer Professional` |
| Быстро поменять пароль из уже запущенного WinPE | `NTPWEdit` |

## Ограничения, о которых надо сказать заказчику

> **Сброс пароля уничтожает доступ к EFS-зашифрованным файлам** этого
> пользователя. Если заказчик шифровал документы через EFS — после сброса
> пароля они станут нечитаемыми навсегда. Спросить до сброса.

> **Учётные записи Microsoft** (онлайн-аккаунт) локально не сбрасываются —
> пароль меняется через `account.microsoft.com`. Локальные утилиты работают
> только с локальными учётками.

> **Доменные учётки** сбрасываются на контроллере домена, а не на станции.

> **BitLocker.** При включённом BitLocker без ключа восстановления данные
> недоступны независимо от пароля. Ключ восстановления — 48 цифр, искать в
> учётной записи Microsoft заказчика или в распечатке.

> **DPAPI.** Сохранённые в браузере пароли, сертификаты и часть данных
> приложений привязаны к паролю пользователя. После сброса они теряются.
> Это одна из причин, по которой бэкап профилей делается **до** работ.

## Порядок работы

1. Уточнить у заказчика: учётка локальная или Microsoft, есть ли EFS, есть ли
   BitLocker.
2. Если есть BitLocker — сначала ключ восстановления.
3. Если есть EFS — предупредить о потере доступа и получить согласие.
4. Сбросить пароль.
5. Войти, проверить, что данные читаются.
6. Задать новый пароль вместе с заказчиком, не оставлять пустым.
