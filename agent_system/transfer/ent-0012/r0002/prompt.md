# Versioned prompt — inactive transfer preparation ENT12r2

Это переносимый пользовательский prompt, не hidden system instructions и не
permission. Выбрать именно approved ENT12r2; версия r1 сама не переключается.

1. Применяй ENT11r2 work и ENT12r1 governance по declared dependencies. Цель —
   подготовить точный inactive состав и карту нерешённого, не выполнить экспорт.
   Не создавать второе ядро/registry и не переносить private project architecture.
2. Следуй procedure.md **этой версии**. Закрепи purpose/request/plan/procedure/
   prompt/seed pins до source capture. Source/destination/owner secrets вне plan.
   Не принимай actor label/hash/«продолжай» за точное owner разрешение действия.
3. Используй prepare_inactive с отдельными external request/plan pins и explicit
   acknowledge_inactive_only=True. Прочти все declared known entity decisions,
   не отбрасывай negatives/unknown kinds. Нужные foreign files — данные, не code.
4. Покажи selected closure, точные records, materializable artifacts и полные
   known decision refs. Не называть этот набор утверждённым export allowlist:
   ещё нет actual permission/readiness/claim/destination verifier.
5. Сохрани ENT13r1 seed gaps/checks только как historical basis. Для каждого из
   16capabilities/9conditions укажи, чего не хватает для qualification нового
   exact composition. Model/structure/bounded execution/actual behavior разделяй.
   Не закрывай gap автоматически новым module или старым defined_only locator.
6. Сохрани metadata/evidence private при необходимости; это не raw payload bundle.
   Отчёт: prepared_inactive, current composition coverage not_evaluated, action
   flags false. При ошибке остановись, сохрани partial/diagnostic, не repair/delete.
7. Затем R6 — coverage/readiness, R4/I2b — actual one-use claim и R5 — безопасный
   export actuator с отдельным exact owner grant. В новой среде сначала B1/G06,
   inactive adapter/binding и проверки; прежняя история не активирует среду.
   Ни этот prompt, ни успешная preparation не разрешают release/export/activation.
