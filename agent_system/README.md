# agent_system — состояние внедрения

Создан минимальный фрагмент каталога, не полноценный выпуск.

- [Индекс каталога](catalog/registry.json).
- [ENT-0001 r0001 — контракт обязательного ядра](catalog/contracts/agent_system/ent-0001/r0001.md).
- [Свидетельство решения владельца](catalog/approvals/8c68d9f9-c096-46a5-a601-4195a4e0d6ce.json).

Все пути artifacts/reference в индексе и свидетельстве относительны корню
`agent_system/`. Индекс не дублирует нормативный текст.

Внедрён один утверждённый контракт. Реализации обязательных способностей,
таблица покрытия, полная схема и валидатор событий, экспортёр, разрешённый
выпуск и локальная активация пока отсутствуют. Пустой список relations этого
контракта не означает, что обязательное ядро реализовано.

Тесты репозитория проверяют текущую связность и точные байты, не поведение
агента и не подлинность человеческого решения. JSON-свидетельство — запись
агента о подтверждении владельца, не цифровая подпись.
