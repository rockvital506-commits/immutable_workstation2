# ENT19r1 — inactive binding procedure

Full planner/history profile; source — owner B/P1ред2, conditional implementation
и продолжение capability G05/G07 prerequisites. Exact ENT12r2 procedure/prompt и
ENT12r1 governance G06/G07/ENT1 core применяются как зависимости, не копируются.
Status/scopes/bytes/approval — единственный registry. Ни одной реальной target
environment/активации этот профиль не выбирает.

1. Сначала получить относящуюся задачу обследования. Реальная среда R7 требует
   отдельного выбора владельца. Не читать hidden system instructions/секреты.
   Сведения о host capabilities, scope, context и constraints — private snapshots.
2. Подготовить новый exact R5 composition с явным root ENT19r1 и всеми declared
   dependencies. Старый descriptor24/90 не включает этот component автоматически.
   External pins не owner authentication, declared approved label не proof согласия.
3. Зафиксировать closed request/environment/adapter declarations/evidence bytes
   и external expected-existing-context. Эти inputs описывают наблюдения, а не
   исполняемые scripts/callbacks. Adapter claims declaration_only; сохранение
   смысла правил и runtime imports этим resolver не доказаны.
4. host.* available требует pinned evidence bytes, но их truth/origin не проверены.
   unavailable/unknown не available. Adapters дают только binding.* после всех
   prerequisites. Duplicate providers/conflicts/cycles не silently игнорируются.
   Optional unknown остаётся limitation. Нельзя ослабить mandatory core этим
   перечнем локальных требований: core coverage/readiness здесь not_evaluated.
5. assess_binding выдаёт лишь declared_conditions_satisfied либо blocked_declared_
   requirements; binding_state inactive, all action flags false. Успех fixed-point
   не равен применённой адаптации/compatible release/agent behavior.
6. save_binding через ENT18 сохраняет immutable private node/inputs/assessment,
   binding_id=exclusive evidence UUID. Successor — новый UUID+exact predecessor
   run/index. Environment_id/scope сохраняются, changed survey требует большего
   logical revision. Старые records не меняются. Forks inactive drafts допустимы
   для сравнения: нет current/active pointer/last-wins, activation от истории нет.
7. inspect_history с external receipt проверяет все ancestors, bounded32nodes и
  128MiB aggregate. Corrupt/missing/unknown predecessor блокирует successor до
   writes; no adoption/repair/delete/retry. Write failure оставляет partial, не
   возвращает success receipt. Private evidence вне Git/allowlist экспорта.
8. activation_proposal лишь перечисляет необходимые gates для exact node/context.
   Release/export grant не activation decision. Actual activation authority,
   adapter execution/result verifier и manager не реализованы; они требуют
   отдельной qualification/explicit owner decision. Никаких реальных переключений.

Изменившиеся rules/environment/checks/constraints требуют нового анализа и node,
не редактирования прошлого. Rollback тоже отдельное полномочное действие, не
fallback при ошибке. Lineage completeness/freshness вне external pins не доказаны;
coherent rollback+old pin может пройти. Проверка evidence structural, не proof
execution/observations/semantics. Same-uid/root/writable installation вне обещания.
