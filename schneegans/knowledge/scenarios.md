# Сценарии и развитие решений

Сценарии выявляются по ходу блоков, а не задаются заранее как ограничение.

| Тип | Оформление |
|---|---|
| Обсуждённая, не выбранная альтернатива | Причина отказа в карточке блока |
| Интерактивный выбор | Условие, инструкция и остановка |
| Условие в одном механизме | Явная проверка, если согласована и безопасна |
| Самостоятельный сценарий установки | Своя спецификация/кандидат/проверки |

У ветви: ID, причина, условие выбора, изменяемые блоки, общие решения,
зависимости и проверка. Нет ветвей «на всякий случай». Не создавать полный XML
на каждую комбинацию. Диск/форматирование, редакция и защита — без скрытых
предположений. Старое решение не отменяется новым наблюдением без обсуждения.

Цель/критерии шага формируются и пересматриваются вместе с решениями. Сценарий
не является самоцелью: формулировать ожидаемое поведение станции. После изменения
блока проверить зависимые ветви, цель/критерии и необходимость новой ревизии.
Для MSI поддерживаемые ветви пока **не выбраны**. Наличие старого bypass-файла
не означает принятия такого сценария в текущем процессе.
