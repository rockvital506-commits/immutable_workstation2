# Ограничения, безопасность и нюансы

Источники: [S01, S02, S05–S09](../sources.md). Нижеследующие рекомендации — не
выбранные настройки билда; обсуждать в соответствующих блоках.

- Base64 — маскировка, не шифрование. Не вводить в форму реальные пароли, MAK,
  Wi-Fi-ключи или секреты скриптов; не сохранять их в URL/закладках и Git.
- Импорт заявлен для XML этого сервиса. Сохранение всех особенностей нашего
  произвольного файла при импорте не гарантировано. Ссылка на форму не заменяет
  сохранённую версию и происхождение XML.
- По S02 текущий генератор очищает определённые Panther/XML/Wi-Fi-файлы, если
  не выбран Keep sensitive files. Очистка зависит от исполнения финального
  сценария. Не считать очищенными исходный USB, Git, логи и произвольные секреты.
- Для файлов генератора автор S02 предписывает UTF-8 declaration, отсутствие BOM
  и raw non-ASCII (символы через числовые references). Это правило его workflow;
  не превращать его без исследования в универсальное утверждение обо всём XML.
- Disable Windows Update создаёт повторную паузу через задачу. Prevent reboot
  двигает активные часы. Always show tray icons на Windows 11 оставляет задачу.
- Make Edge uninstallable имеет предупреждение автора о проблемах WU.
  Удаление Store и других компонентов может усложнить возвращение.
- В списке удаления есть полезные администратору клиенты/инструменты. Разбирать
  каждый выбор и зависимости; название группы «bloatware» не оценка нужности.
- Отключение Defender/UAC/SmartScreen, junction, 8.3, шифрования или подкачки —
  изменения безопасности/совместимости, а не безусловная оптимизация.
- Имя локальной учётной записи и пустой пароль, первый вход и его контекст
  проверять вместе. Нельзя молча менять прежнее решение владельца.
- Скрытые PowerShell-окна несовместимы с ожидающими ввода подсказками.
  В штатной Windows PE PowerShell может отсутствовать; не приравнивать её к Strelec.
- $OEM$ не использовать для предварительного создания будущего профиля:
  автор предупреждает о создании Windows другого имени каталога профиля.
- Критерии выбора диска безопаснее безусловного Disk 0, но тоже требуют
  испытания. Ёмкость «ближайший диск» не уникальный идентификатор оборудования.
- Shell-Setup ProductKey и Setup/UserData ProductKey имеют разные роли по S09.
  Не считать specialize достаточным доказательством выбора редакции до него.
- Лицензия MIT относится к библиотеке, не лицензирует Windows. Локальная
  библиотека не доказательство доступности полного сайта офлайн.

Генератор — средство построения кандидата, не сертификация билда. Не скачивать
и не запускать встроенные/чужие сценарии без анализа. Не создавать новые ISO
ради этого гайда. Расположение ресурсов на обычном USB не переносить автоматически
на Ventoy. Предложения по границам автоматизации обсуждаются в блоках, не
закрепляются заранее как обязательный минимальный пресет.

## ЕЭЗ / DMA: уточнение регионального выбора — 2026-10-24

Источники: [Microsoft 2023/2024](https://blogs.windows.com/windows-insider/2023/11/16/previewing-changes-in-windows-to-comply-with-the-digital-markets-act-in-the-european-economic-area/),
[Microsoft 2025](https://blogs.windows.com/windows-insider/2025/06/02/updates-to-windows-for-the-digital-markets-act/).
Это Digital Markets Act, не одноимённый механизм Direct Memory Access.

Для ЕЭЗ Microsoft описывает удаление Edge/Bing web search, выбор сторонних
провайдеров поиска/лент, расширенный выбор браузера по умолчанию, меньше
навязывания Edge; в 2025 добавлено развёртывание удаления Microsoft Store.
Это не обещание всех перечисленных функций на любом SKU/образе LTSC: учитывать
состав компонентов, сборку, обновления и политики. Для конкретного MSI не проверено.

ЕЭЗ — ЕС плюс Исландия, Лихтенштейн, Норвегия. Литва, Германия, Ирландия входят;
географическая Европа сама по себе не критерий. Отдельное преимущество одной
страны ЕЭЗ над другой для перечисленных DMA-функций не подтверждено.

**Коррекция предыдущего упрощения:** пользовательский HomeLocation и регион
устройства, определяемый при setup для DMA, нельзя считать одним параметром.
По изученному Locales.cs генератор добавляет Set-WinHomeLocation через UserOnce,
если регион отличается от первого языка. Это не доказательство правильной
установки Device setup / DMA region. Перед обещанием преимуществ проверить
полученный XML и фактическую инициализацию региона устройства на целевом Setup.
Не считать запоздалую команду HomeLocation заменой выбора региона устройства.

Microsoft в документации 2023/2024 указывает, что изменение региона для DMA
требует сброса ПК. Поэтому обычный регион: изменение возможно; регион DMA:
**трудно**, нельзя обещать обычное переключение после установки. Не применять
патчи реестра/IntegratedServicesRegionPolicySet.json ради обхода без отдельного
разбора и согласования. Рекомендация — страна фактического использования в ЕЭЗ,
если соответствует сценарию, без автоматического выбора по геолокации чата.
