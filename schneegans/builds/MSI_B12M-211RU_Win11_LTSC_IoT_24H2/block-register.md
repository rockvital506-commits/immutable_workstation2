Источник: форма S01, исследование 2026-10-24, коммит `27237f82`.
Порядок записан по исследованной форме. Названия нормализованы (без конечного
двоеточия, типографики и неразрывных пробелов). Это контроль **блоков**, не
утверждение полного аудита их полей. Условные поля проверять при каждом разборе;

## Сервисные элементы (тоже не пропускать)

- C01: импорт XML этого генератора — не обещание импорта произвольного XML.
- C02: Presets/Reset/minimal output/local account — потенциально меняют сразу
  много полей; после применения сверять все затронутые решения, не терять их.
- C03: Submit form — Bookmark selection / View XML / Download XML / XML in ISO.
  Сохранение/просмотр не равно установка; ISO сейчас не создаём.

C01–03 пока не рассмотрены как решения MSI. Импорт/пресеты не применять молча.
B01 полностью согласован, реализация/проверка впереди. В B02 выбран генерируемый сайтом CMD. Отключение 8.3 выключено. Отключение Defender выключено. Пауза до разметки включена. Пауза перед перезагрузкой включена. Compact выключен. Пропуск проверки выключен. Образ — интерактивный ввод индекса. Автоматическая подготовка генератором согласована. Критерий no existing partitions выключен. Критерий SATA/SCSI/SAS/NVMe включён. Fixed hard disk выключен. Диапазон включён: 200–300 GiB. Критерий индекса выключен. Далее — альтернативы выбора цели (VBS / интерактивно);
остальные значения B02 не приняты.
