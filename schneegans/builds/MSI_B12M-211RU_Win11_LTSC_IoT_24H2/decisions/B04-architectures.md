# B04 — Processor architectures

**Решение:** владелец подтвердил только **Intel / AMD 64-bit**.
Intel / AMD 32-bit и Windows on Arm64 выключены. **Реализация:** XML ещё нет.
**Проверка:** требует проверки практикой.

Источник: [форма S01](../../../sources.md), раздел Processor architectures.
Флажки допускают несколько архитектур в одном ответе; это не конвертация ISO.
32-bit — x86, 64-bit — amd64 (в том числе Intel), Arm64 — ARM64.

**Цель подшага:** ограничить ответ архитектурой целевой станции/ОС.
**Обоснование:** Intel Core i3-1215U и целевая Windows 11 IoT Enterprise LTSC
2024 x64; ветви x86/ARM64 для этого билда неприменимы.
**Критерии:** компоненты ответа имеют processorArchitecture="amd64";
нет несогласованных x86/arm64-ветвей; фактический образ и PE совместимы с x64.
B02 выбирает индекс образа, но не преобразует архитектуру. B01 и пустое поле
активации B03 не меняются. По согласованным значениям противоречий нет.

Собственный скрипт не нужен. При сравнении проверить архитектуру всех
компонентов обоих кандидатов. Состав ISO ещё не проверен, установка не
выполнялась. Изменить архитектуру установленной ОС переключателем нельзя,
нужна переустановка подходящего образа. Решения B04 завершены; следующий
блок — B05 Setup settings, первое поле — обход требований Windows 11.
