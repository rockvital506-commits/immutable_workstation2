# Решения по блокам

В [B01](B01-region.md) согласован интерактивный режим всех параметров;
реализация и практика ещё не выполнены.
Остальные карточки появляются последовательно по [реестру](../block-register.md).
Полные будущие XML не создавать до завершения решений/ветвей.

В карточке: все поля/варианты → последствия/механизм → применимость/ветвление →
рекомендация → решение и причины → реализации → сквозная проверка → статус.
Существенные справочники сокращать объяснением выбора, не скрывать разные режимы.
Если код согласован — отдельный подшаг реализации с целью/критериями до практики.

Алгоритмы отражают каждый блок отдельным подшагом с обоснованием; в карточке
держать проекцию такого подшага до согласования места шага. Не менять алгоритмы
на основании несогласованных рекомендаций. Владелец решения — пользователь.
