# B01 — Region and language settings

**Источник:** [S01](../../../sources.md), форма `27237f82`, 2026-10-24.
**Решение:** обсуждается, выбора нет. **Реализация:** не реализовано.
**Проверка:** требует проверки практикой. Поля формы при практическом заполнении
сверить повторно; импорт/пресет не применялись. Это первая карточка, не готовый
ответ для сайта и не полный будущий файл установки.

## Назначение и поля

| Поле/режим | Варианты и смысл | Последствия, применимость и ветвление |
|---|---|---|
| Install Windows using these language settings | Явные настройки | Воспроизводимость, но требуют соответствия образу и согласования предпочтений |
| Select language settings interactively during Windows Setup | Выбор на установке | Подходит для сознательно оставленного выбора; меньше автоматизации; не считать пустоту явным интерактивным решением без проверки XML |
| Windows display language | Язык UI из справочника формы | Должен соответствовать образу; русские регион/клавиатура не добавляют языковой пакет |
| Language preferences and keyboard layouts | Один или несколько языков в порядке предпочтения | Первый задаёт начальный региональный формат; не путать с языком UI и SystemLocale |
| First language + Keyboard layout / IME | Язык и совместимая раскладка; справочники не равны друг другу | US отличается от US-International, Russian от фонетической; выбранная пара и порядок важны для ввода при установке/входе |
| Second language + Keyboard layout / IME | Не задано либо дополнительная пара | Для второго алфавита; не добавлять третью раскладку автоматически |
| Third language + Keyboard layout / IME | Не задано либо третья пара | Отдельный сценарий потребности, не обязательная настройка |
| Home location and device setup region | Географический регион | Не часовой пояс; может влиять на региональное поведение Windows/приложений; не определять по местоположению чата |

Полные справочники языков/регионов не перепечатываются: объяснены различия
полей, язык/раскладка/формат/регион рассматриваются отдельно. Фактические значения
enum/locale/keyboard-ID сверять в полученном XML. SystemLocale не угадывать по
надписи UI: если форма не даёт нужного различия, сначала разобрать результат,
затем согласовать дополнительный XML/сценарий, не внедрять его заранее.

## Применимость к MSI и существенные варианты

В контексте указан прежний en-US ISO. Без подтверждённого русского языкового
пакета выбор ru-RU UI нельзя считать реализованным. Старый XML сочетает en-US
на PE и ru-RU позже; это открытый вопрос, не пример для безусловного копирования.

Варианты обсуждения (не выбранные сценарии):
1. Доступный в образе английский UI, русские/английские средства ввода и
   согласованный формат — меньше языковых зависимостей.
2. Русский UI — нужен соответствующий образ/пакет и проверка LTSC; возможная
   дополнительная реализация только после решения владельца.
3. Интерактивный выбор — если вариативность важнее автоматизации этого блока.

Предварительная рекомендация: если фактический образ остаётся en-US без других
пакетов, не запрашивать отсутствующий UI. Это условный вывод, не выбор владельца.
Языки ввода, первый язык, регион и формат пока не определены.

## Вопросы для решения

- Предпочтительный UI: английский / русский / интерактивно / иной?
- Какие языки ввода и какие раскладки, в каком порядке?
- Какой региональный формат и Home location нужны именно станции?
- Если UI отличается от образа, согласуется ли изменение образа/подготовка пакета?

## Сквозная проверка и проекция подшага алгоритма

Сопоставить с будущим B02 (образ), B07 (часовой пояс), B08 (имя/ввод пароля),
B24 (не удалить нужные языковые возможности), B25/B27 (если нужен дополнительный
механизм). При изменении образа пересмотреть решение B01. Не объединять регион
и часовой пояс в одно предположение. Ожидаемое поведение/критерии конкретного
подшага формируются после выбора; установка для их проверки пока не назначена.

После подтверждения записать: выбранный режим и все значения → причины →
невыбранные варианты → условия ветвления → нужные реализации → проверки UI,
порядка ввода, формата и региона на выходе. До этого проекция не вносится в
алгоритмы как согласованный подшаг. Новых фактов установки нет.
