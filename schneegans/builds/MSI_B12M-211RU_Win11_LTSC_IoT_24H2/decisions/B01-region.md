# B01 — Region and language settings

**Источник:** [S01](../../../sources.md), форма `27237f82`, 2026-10-24.
**Решение:** пересматривается по полям. Язык отображения — **English**,
владелец подтвердил выбор на сайте. Первый Language — **English (United States)**, подтверждён владельцем.
Остальные поля ожидают последовательного разбора; прежнее «всё интерактивно» не считать актуальным выбором всего блока.
**Реализация:** значение UI выбрано владельцем в форме; XML ещё не получен.
**Проверка:** требует проверки практикой. Поля формы при практическом заполнении
сверить повторно; импорт/пресет не применялись. Это первая карточка, не готовый
ответ для сайта и не полный будущий файл установки.

## Назначение и поля

| Поле/режим | Варианты и смысл | Последствия, применимость и ветвление |
|---|---|---|
| Install Windows using these language settings | Явные настройки | Воспроизводимость, но требуют соответствия образу и согласования предпочтений |
| Select language settings interactively during Windows Setup | Выбор на установке | Подходит для сознательно оставленного выбора; меньше автоматизации; не считать пустоту явным интерактивным решением без проверки XML |
| Windows display language | Язык UI из справочника формы | Должен соответствовать образу; русские регион/клавиатура не добавляют языковой пакет |
| Language preferences and keyboard layouts | Один или несколько языков в порядке предпочтения | Первый задаёт начальный региональный формат; не путать с языком UI и SystemLocale |
| First language + Keyboard layout / IME | Язык и совместимая раскладка; справочники не равны друг другу | US отличается от US-International, Russian от фонетической; выбранная пара и порядок важны для ввода при установке/входе |
| Second language + Keyboard layout / IME | Не задано либо дополнительная пара | Для второго алфавита; не добавлять третью раскладку автоматически |
| Third language + Keyboard layout / IME | Не задано либо третья пара | Отдельный сценарий потребности, не обязательная настройка |
| Home location and device setup region | Географический регион | Не часовой пояс; может влиять на региональное поведение Windows/приложений; не определять по местоположению чата |

Полные справочники языков/регионов не перепечатываются: объяснены различия
полей, язык/раскладка/формат/регион рассматриваются отдельно. Фактические значения
enum/locale/keyboard-ID сверять в полученном XML. SystemLocale не угадывать по
надписи UI: если форма не даёт нужного различия, сначала разобрать результат,
затем согласовать дополнительный XML/сценарий, не внедрять его заранее.

## Применимость к MSI и существенные варианты

В контексте указан прежний en-US ISO. Без подтверждённого русского языкового
пакета выбор ru-RU UI нельзя считать реализованным. Старый XML сочетает en-US
на PE и ru-RU позже; это открытый вопрос, не пример для безусловного копирования.

Варианты обсуждения (не выбранные сценарии):
1. Доступный в образе английский UI, русские/английские средства ввода и
   согласованный формат — меньше языковых зависимостей.
2. Русский UI — нужен соответствующий образ/пакет и проверка LTSC; возможная
   дополнительная реализация только после решения владельца.
3. Интерактивный выбор — если вариативность важнее автоматизации этого блока.

Предварительная рекомендация: если фактический образ остаётся en-US без других
пакетов, не запрашивать отсутствующий UI. Это условный вывод, не выбор владельца.
Языки ввода, первый язык, регион и формат пока не определены.

### Проекция согласованного подшага алгоритма

**Цель B01:** оставить владельцу выбор языковых и региональных параметров,
не предопределяя их значениями генератора/старого XML.
**Критерии успеха B01:** в кандидате нет конфликтующих принудительных значений
B01; при проверке определено, какие параметры Setup действительно предлагает,
какие наследует и какие требуют отдельного интерактивного действия. Выбранные
при установке значения проверены после входа; доступны только языки образа/
подготовленных пакетов. Это не обещание пяти отдельных экранов OOBE.

**Рекомендованная реализация:** в блоке Region and language settings выбрать
`Select language settings interactively during Windows Setup`. Не задавать
скрытые/неактивные языковые поля как обязательные; после генерации проверить
реальный XML, включая specialize/oobeSystem и встроенные сценарии.
Не добавлять собственные подсказки/языковые пакеты/скрипты без отдельного решения.

**Ветвление и зависимости:** B02 должен сохранить возможность согласованного
взаимодействия; доступный UI ограничен образом, интерактивность не скачивает
отсутствующий пакет. B07 остаётся отдельным решением. B24–27 не должны удалить
нужные возможности или навязать значения. Если генератор/Setup не предоставляет
нужный выбор формата, региона или раскладок, зафиксировать конкретный пробел и
согласовать отдельный интерактивный этап; не возвращаться молча к фиксированным
значениям и не объявлять такой этап уже реализованным.

**Практика:** отложена до кандидата; проверить отсутствие принуждения статически,
затем фактические экраны и полученные значения. **Коррекция:** при пропущенном
выборе сохранить XML/логи/описание, обсудить минимальное дополнение.
**Подтверждение:** выбор режима уже принят; работоспособность ещё не подтверждена.
**Запись результата:** эта карточка и реестр; будущие проверки — в ревизию XML.
Номер шага в алгоритмах ещё не согласован, поэтому подшаг сохранён здесь как
проекция, не добавлен в произвольное место алгоритмов.

**Общая цель/критерии шага:** продолжают формироваться. В них добавлено требование
не навязывать языковые и региональные значения B01, а ограничения доступного UI
и непредоставляемых Setup экранов оставить видимыми. XML пока не получен.


## Текущее решение — B01, ревизия решения 2

Владелец вернулся к блоку и выбрал **English** в поле Windows display language.
Основание: корректное соответствие исходному en-US образу, без принудительного
ru-RU при неподтверждённых русских ресурсах. Это не запрет русского ввода и не
выбор США как географического региона. Не добавлять русификацию/сценарий смены
языка без отдельного решения. Изменение после установки: **возможно**, при
наличии подходящего пакета. Практическую инструкцию по изменению сейчас не давать.

Следующее поле — первый Language (в группе первой пары язык/раскладка).
По Locales.cs генератора оно задаёт **SystemLocale и UserLocale**, а не только
ввод. Раскладка Keyboard layout / IME выбирается отдельно. Влияние на старые
non-Unicode программы и числовые/временные форматы разобрать до решения.
Смешение English UI и ru-RU locale не запрещать автоматически, но проверить
с приложениями и будущими сценариями; не добавлять UTF-8 beta самовольно.
Точные значения и порядок языков не выбраны. Верхняя ветвь формы рассматривается
по полям; финальный набор и XML проверяются после завершения решений.

**Приоритет владельца:** корректная установка ОС и гармоничная интеграция выбора,
скриптов/команд/XML. Изменение после установки — только краткая оценка
«возможно / невозможно / трудно», не отдельная инструкция или новая задача.
Новые цель/критерии: язык UI соответствует доступному образу; нет навязанного
отсутствующего языка или несогласованных механизмов смены. Проверка практикой
и сверка фактического XML по-прежнему впереди.
