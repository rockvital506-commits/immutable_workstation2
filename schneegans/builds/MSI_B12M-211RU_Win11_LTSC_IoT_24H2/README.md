**Цель шага:** формируется, окончательная формулировка не принята. Текущее
требование B01 — соответствие UI исходному en-US образу, две согласованные
пары ввода и Lithuania без конфликтов; DMA-эффект не гарантирован.
**Критерии успеха шага:** формируются; общие проверки гайда не заменяют критерии
конкретного билда. Для B01: корректное соответствие UI образу и
отсутствие конфликтов с последующими языковыми решениями/скриптами. Уточнять после каждого решения.
**Сценарии:** не выбраны. **Номер/место шага в алгоритмах:** ещё согласовать;
подготовку answer-файла не считать новым прохождением инвентаризационного Шага 2.

Подтверждённые ранее ограничения не отменены; они будут рассмотрены в нужных
блоках. Старый XML не импортирован и не принят автоматически как новый набор
решений. Выявленные исследованием вопросы: язык UI/язык образа, роль ключа в
specialize и выбор редакции, разметка/WinRE, выбор диска Ventoy vs CMD сайта,
часовой пояс. Это вопросы для разбора, не новые выбранные настройки.
