# Ревизии кандидатов

Пока **ни одного кандидата не получено**; пустые site.xml/agent.xml не создаются.
После завершения решений формировать r001, r002 и т. д. по [регламенту](../../../workflow.md).
Ревизия содержит metadata.md, полученные артефакты, comparison.md и checks.md.
Наличие схемы имён не означает фактическое существование файлов.

Агент готовит кандидат до просмотра XML сайта. Site XML сохраняется без правок;
если не получен, указывать отсутствие. Исправления/промежуточные версии не
перезаписывать. Все сформированные обсуждаемые версии сохранять; реальные
секреты и приватные оригиналы — отдельно от Git, обезличивание маркировать.
Итог размещается в answer/ билда только после сравнения и согласования.
