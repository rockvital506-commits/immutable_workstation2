# Schneegans — развиваемый гайд по файлам ответов

**Цель:** разбирать генератор полностью в контексте каждой станции и получать
объяснимые, согласованные, проверяемые файлы ответов, а не универсальный пресет.
**Критерии успеха:** все блоки рассмотрены, решения и ветви прослеживаются,
версии сохранены, предположения отделены от результатов практики.

Регламент согласован владельцем 2026-10-24. Это база знаний **только Git**, не
новое содержимое разделов флешки и не установленная утилита. Новых бинарников,
ISO и исполняемых файлов ответов здесь сейчас нет. XML билда не заменялись.

## Разделение ответственности

Общий справочник объясняет механизм; карточка билда хранит решения; алгоритмы
билда содержат подшаг на каждый блок с обоснованием и дополнительными подшагами
согласованных реализаций. В `answer/` билда находится действующий итог.
Предварительные артефакты и сравнения — в `revisions/`, не второй «главный XML».

**Статусы:** решение — не рассмотрено / обсуждается / согласовано / пересмотрено;
реализация — не реализовано / в кандидате / в итоге;
проверка — требует проверки практикой / статически проверено / проверено в VM /
проверено на станции. Один статус не подменяет другой.
